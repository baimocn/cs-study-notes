# R 关键论断（≤150字，OCR 已修：ch02 全文"€/©/。/3吾言"系坏字已批量还原为"C语言/C程序"）

C1 一句话：**一切考题终归"求出表达式的值+写出变量终值"**。三条铁律——①常量先验合法性（0x/0前缀、e规则、单双引号）；②运算按优先级+结合性拆，同侧有 ++/-- 先判停先后；③赋值/转换"就左不就右"，窄化截高位。所有字节数按教材口径（VC++6.0/32位；16位TC另注），不与真机混写。

# I 骨架 + 记忆钩子

## 程序最小骨架（ch01/ch02 并入的骨架考点）
```c
#include <stdio.h>        /* 预处理命令：行首#，末尾无分号 */
int main(void)            /* 函数首部：末尾无分号 */
{                         /* 函数体开始 */
    int a, b;             /* 语句：必须以 ; 结尾 */
    a = 2;
    printf("%d\n", a);    /* printf 是库函数调用，不是 C 语句关键字 */
    return 0;
}                         /* } 之后不加分号 */
```
钩子【一鱼一刀一锅】：`#include` 是鱼贩（送货，不占灶）、main 是唯一的灶、`;` 是每道菜的收汁——没有收汁的菜（语句）出锅就报错；`}` 和函数首部是"锅沿"，锅沿不收汁。

## 钩子库（自造，直击考点）

1. **整型四兄弟长度表**（教材口径 VC++6.0/32位）：char 1 < short 2 < int 4 = long 4 < double 8；float 4 站中间。口诀"**一短四，二短二，四弟仨（int/long/float），八是 double，char 独苗 1**"。TC/16位口径：int 2、unsigned int 2——题干给"16位PC"必须换挡。
2. **常量三前缀**：光头=十进制，0 开头=八进制（只许 0~7，见 8/9 立即枪毙），0x 开头=十六进制。口诀"**戴0帽是八仙（0~7），戴0x帽十六仙（0~F），光头十仙**"。0123=83，0x123=291。
3. **'a' vs "a"**：单引号是独行侠（1字节，97）；双引号是拖油瓶（'a'+'\0'，2字节）。**字符串都是贪吃蛇，长度 n 占 n+1 节**——"China" 占 6 不占 5。
4. **转义字符看`\`**：\n 换行、\t 横跳、\0 空字符（值0，≠空格32）、\\ \\' \\" 三逃生；\101（八进制）='A'，\x46（十六进制）='F'。钩子"**反斜杠是密语接头暗号**"。\81 非法——八进制帮派不收 8。
5. **++ 前后钉**：`++i` 钉在前面——先加后用（先动手后说话）；`i++` 钉在后面——先用后加（先说话后动手）。`i+++j` 是贪心蛇：从左往右吞出最长的合法运算符 → (i++)+j。
6. **优先级天梯（考用 15 级压缩口诀）**："**括号最大，单目老二，乘除模三，加减四，移位五，大小六，等不等七，位与八，异或九，位或十，与十一，或十二，条件十三，赋值十四，逗号垫底十五**"。只有三种右结合：**单目、条件?:、赋值系**——口诀"**单目条件和赋值，一律从右往左啃**"。
7. **短路闸门**：`&&` 左假即停（0&&(++a)：a 冻住）；`||` 左真即停。钩子"**&&是洁癖，遇到假扭头就走；||是热心肠，遇到真就宣布散会**"。
8. **隐转方向标**：低→高单向阀 char/short → int → unsigned → long → double（float 必先升 double）；赋值反向"就左不就右"，长存短**砍高位**。钩子"**运算就高不就低，赋值就左不就右；高个子进小房间要低头（截断），矮个子进大房间白送（无害）**"。
9. **逗号万年老末**：逗号优先级垫底且取**最后一个**表达式的值；`a=2,3` 里 a 先被 2 占坑；`(a=2,3)` 才让 a=3。参数表/变量表里的逗号是**分隔员**不是运算符。
10. **补码一句话**：正数三码合一；负数**取反加一**（绝对值原码→反码→+1）。内存里整型一律住补码。

# E 考场步骤★

**表达式求值五步法**（拿到任何求值题按序执行）：

1. **括号圈地**：先算最内层 ( )；强转 (类型) 也在此层处理——(float)5/2 是先转 5 再除，(float)(5/2) 是先整除。
2. **单目点名**：! ~ ++ -- +取正 −取负 (强转) sizeof，全部右结合从右往左啃。**++i 与 i++ 判停**：
   - 前缀 `++i`：**本步立刻加 1**，后续一切引用用新值；
   - 后缀 `i++`：**先记旧值备用，等"引用点"过后 i 才变**——同层有多个 i++，各记各的旧值，i 终值=初值+自增次数；
   - `i+++i++` 这类**同一变量双副作用**：判停——按教材口径顺序作答（例3-14：先取 2 再取 3 → 值 5，i 终 4），并在草稿写"教材顺序口径"，不要与真机未定义纠缠。
3. **算术层**：* / %（同左结合，% 两侧必须整型、余数符号随被除数）→ + −。整除 5/2=2 想起"砍尾巴"。
4. **位/关系层**：<< >> → < <= > >= → == != → & → ^ → |。移位口诀"左移补0翻倍走，右移看符号（无符号补0，有符号补符号位）"；关系式只吐 1/0，连写 a>b>c 按 (a>b)>c 算。
5. **逻辑/赋值/逗号层**：&& → ||（短路闸门在此生效）→ ?: → = 复合赋值（右结合，右侧整体加括号 x*=y+3 即 x=x*(y+3)）→ 逗号（取最后一个）。最后回答两问：**表达式的值** + **相关变量的终值**——两问都要写全。

**求值题防错检查**（30秒）：% 两侧是否整数？/ 是否该出小数却整除？== 误写成 =？逗号是否被当运算符？sizeof 括号里是类型还是变量？

# B 边界★（失败模式与混淆表）

1. **: 与 ? 的歧义**：条件 `a?b:c` 中 ： 是运算符一部分；但 `case 1:` 的 ： 是标号、`::` 在 C 里不存在。看到 `x=a?b:c=d` 要拆成 `x=(a?b:(c=d))`（右结合+条件级高于赋值）。
2. **++ 连用的双口径**：`i++ + i++` 真机（C 标准）未定义行为、不同编译器结果不同；**教材按"先引用后自增、从左到右"给唯一答案（考试按教材口径写）**。考场上若选项出现"结果不确定/有歧义"，优先选教材例题同型值。
3. **隐式转换丢精度三连**：float 存 9.87654321 只剩 7 位；int a=99.1 变 99；long b=65536→int a 变 0（教材例题口径；32位 int 则为 65536）。负数强转/窄化按补码直接截位，不四舍五入。
4. **与 C2（if/while）陷阱分工**：C1 管 `=` 与 `==` 在表达式层的值（赋值表达式值为所赋之值）；C2 管 `if(a=0)`、`while(i-->)` 里控制流怎么走。C1 判"表达式值是多少"，C2 判"走哪条路"。
5. **与 C7（#define 宏）混淆表**：`#define N 10` 后 `N*N` 是 10*10（纯替换）；但 `#define SQR(x) x*x` 后 `SQR(a+1)` 展开成 `a+1*a+1`——那是 C7 的战场；C1 只需记住**符号常量定义行末无分号、习惯大写**，别把宏当变量。
6. **与 C5（指针）边界**：`*` 与 `&` 在 C1 只出现在优先级表第 2 级（取内容/取地址，右结合）；`int *p=a` 的含义辨析归 C5。位运算 `&`（双目、第8级）与取地址 `&`（单目、第2级）同符异义——看两侧有无操作数。
7. **% 的两禁**：两侧必须整型（4.0%2 非法）；余数符号随被除数（-4%3=-1、4%-3=1）。
8. **逗号两副面孔**：`int a=1,b=2;` 与 `f(x,y)` 里的逗号是分隔符；只有"表达式1,表达式2"整体出现时才是逗号运算符。
9. **sizeof 陷阱**：sizeof 是**运算符**不是函数（选择题考过"sizeof 属于__运算符"）；sizeof(3.14)=8（double 口径）；字节数按教材口径（VC++6.0：int/long/float 4；TC 16位：int 2），题干给 16 位就切 16 位答案。
10. **0 与 '0' 与 '\0'**：0 是整数零；'0' 是字符 0（ASCII 48）；'\0' 是空字符（值 0）。判字符串长度时 '\0' 计 1 字节但不计有效长度。

# E2 典型真题模板速解（对应练习题原题）

1. **练习一.6 型**（短路+赋值副作用）：`int a=0,b=0,m=0,n=0; (m=a==b)||(n=a==b);` → 左支 m=(a==b)=1，|| 已真短路，n 不变。答 m=1,n=0。
2. **练习一.10 型**（条件+自增）：`int x=100; x++>100?x+20:x+10;` → x++ 取 100，100>100 假；x 已变 101；取 x+10=111。
3. **练习二.8 型**（混合天梯）：`4&5-3&&5+!2` → 见 E 步骤4/5：算术先（2、5）→ 位与（4&2=0）→ 逻辑与（0&&5=0）。答 0。
4. **练习二.14 型**（强转不改原值）：`int i=2; float f=1.4; f=(float)i;` → i 仍 2（强转产生中间量），f=2.0。
5. **练习二.17 型**（条件短路性）：`int x=1,y=3,z; z=x>y?++x:y++;` → z=3, x=1, y=4（未选中支不执行）。
6. **练习二.11 型**（字符串字节账）：`"\\0568\034"` → \\ 是1字符、0、5、6、8 共5个有效字符 + \034（八进制转义1字符）= 6 有效 + \0 = 7 字节。
7. **练习二.3 型**（移位优先级）：`10<<3+1` → 10<<4=160。
8. **练习二.13 型**（表达式类型判断）：`10+'a'+i*f-d/e`（i int、f float、d double、e long）→ 全程就高：char→int→double，答案 double 型。
