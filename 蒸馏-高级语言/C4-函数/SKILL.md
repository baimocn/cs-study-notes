## I — 骨架 + 钩子

**一个函数 = 首部 + 函数体。** 首部定"进什么、出什么"；函数体用 C2 的控制流把活干完。

```c
返回类型 函数名(形参表)   /* 首部：末尾【不能】加分号 */
{
    数据定义语句;
    执行语句;             /* 有返回值则至少一条 return 表达式; */
}
```

- 调用前提：被调函数**先定义后调用**，或先给**声明**（原型，末尾加分号）。
- 四种数据传递：**值传递 / 地址传递 / 返回值 / 全局变量**。
- 变量四存储类型：**auto（默认）· static · register · extern**。

### 钩子
1. **传值=复印件，随便涂；传址=房钥匙，改得了真房。** 形参是普通变量→你改的是复印件，实参毫发无损；实参传的是数组名（首地址）→函数拿的是钥匙，改的就是你的原数组。
2. **static 局部=复读机只念第一遍。** 初始化语句只在第一次调用时执行一次，以后每次进来直接用上次的值；auto 局部=一次性纸杯，每次调用都换新（未初始化还是随机值）。
3. **return 是单程票**：只能捎回**一个**值，且只能从被调函数捎回主调函数。想"捎回"多个结果→用数组传地址或全局变量。

## A — 书中例题（含验证结论）

### A1 · 例6-9（p.195）：auto 与 static 对照 —— static 累加母题
```c
void auto_static(void)
{
    int var_auto = 0;         /* auto：每次调用都重新赋 0 */
    static int var_static = 0;/* static：只在第一次调用时赋 0 */
    printf("var_auto=%d, var_static=%d\n", var_auto, var_static);
    ++var_auto;
    ++var_static;
}
int main(void)
{
    int i;
    for (i = 0; i <= 2; i++) auto_static();
    return 0;
}
```
输出（三次调用）：`var_auto=0` 恒定；`var_static=0,1,2` 递增。
**读法**：每次进函数，`var_auto` 被重新初始化为 0；`var_static` 的初始化被跳过，保留上次退出时的值。static 未初始化则自动为 0。

### A2 · 例6-14（p.204）：递归阶乘 —— 栈表法母题
```c
float f(long n)
{
    if (n == 1) return 1.0;      /* 出口 */
    else return n * f(n - 1);    /* 递推式 */
}
/* main 中 x = f(4); → n! = 24 */
```
递归**两要素**：①出口条件（n==1 直接返回）②递推式（f(n) 用 f(n-1) 表示）。缺出口→无限递归。

### A3 · 例6-6（p.190）：值传递为什么换不动
```c
void change(int x, int y) { int z; z=x; x=y; y=z; }
int main(void) { int a=1, b=2; change(a, b); printf("%d%d", a, b); }
```
输出 **12** 不是 21。形参 x,y 是 a,b 的**复印件**，函数里换的是复印件，返回时形参内存即被收回。

### A4 · 例6-8（p.192）：数组名传参 = 传首地址
```c
float aver(int a[])   /* 一维长度可省略 */
{  int i; float av, s=a[0];
   for (i=1; i<5; i++) s += a[i];
   av = s/5;  return av;  }
/* main: int sco[5]; ...; av = aver(sco);  → 83.60 */
```
传的是 `sco` 的**首地址**（如 2000），a 与 sco 共享同一片内存；`a[i]` 改变 = `sco[i]` 改变。教材原话："数据并没有传递，而是数据的共享。"（首地址→指针的底层机制在 **C5** 展开）

### A5 · 例6-15（p.205）：static 局部变量把递归改循环
```c
long f(long n) { static long i = 1L; i = n * i; return i; }
/* main 循环调用 f(1) f(2) ... f(10)，i 依次保留 1! 2! ... 10! */
```
i 只初始化一次，每次调用 `i=n*i` 在上次结果上累乘——static 变量是函数的"记忆"。

## T — 触发题型 ★

| 题型 | 信号 | 动作 |
|---|---|---|
| 写函数体填空 | 给功能+调用语句，挖掉首部或 return | 先看调用处：`c=max(a,b)` 赋值给 int → 返回类型 int；再看实参个数定形参表；最后补 `return 表达式;` |
| 读递归写结果 | 函数体内出现 `f(n-1)` 或 `f(n/2)` | 用栈表法（见 E）逐层列出，回代求值 |
| 判断 static 行为 | 局部变量带 `static`，且函数被循环/多次调用 | 首次=初始值；以后每次=上次退出值；auto 变量每次都重置。逐次列表 |
| 值/地址传递判断 | 形参是变量 or 数组名/指针 | 变量→值传递（实参不变）；数组名→地址传递（实参跟着变） |
| 声明/定义辨析 | 考"哪句对" | 首部无分号；声明有分号；声明可省形参名 `int max(int,int);`；定义在主调函数之前可免声明 |
| 二维数组形参 | 问 `int a[][]` 对不对 | 第一维可省 `a[][4]`，**第二维不能省** |
| 重名屏蔽 | 全局与局部同名 | 局部作用域内全局被屏蔽；出作用域恢复 |

## E — 考场步骤 ★：递归跟踪栈表法

**判停条件：出现 return 且不再调用自身 → 到底了，开始回代。**

四步照搬：
1. **列表头**：画两列表格 `调用层 | 该层表达式`。
2. **下行（压栈）**：从 f(n) 开始，每层只写"f(参数) = 待定表达式"，直到触发出口那一层直接写出值。
3. **回代（回程）**：从最底层开始，把值代回上一层表达式，算出该层值，逐层向上。
4. **判停检查**：核对出口参数是否可能被跳过（如出口写 `n==1` 但实参从 0 开始递减 → 无限递归；递减步长与出口要配套）。

现场演示 `f(4)`（出口 n==1 返回 1，递推 f(n)=n*f(n-1)）：

| 下行：调用层 | 表达式 | 回代：逐层求值 |
|---|---|---|
| f(4) | = 4 * f(3) | = 4 * 6 = **24** |
| f(3) | = 3 * f(2) | = 3 * 2 = **6** |
| f(2) | = 2 * f(1) | = 2 * 1 = **2** |
| f(1) | 出口 = **1** | — |

数组递归同法。`fun(a,n) = fun(a,n-1) + a[n-1]`，出口 `n==0` 返回 0，数组 {1,2,3,4,5,6,7}：

| 调用层 | 表达式 | 回代 |
|---|---|---|
| fun(a,7) | = fun(a,6) + a[6]=+7 | = 21+7 = **28** |
| fun(a,6) | = fun(a,5) + a[5]=+6 | = 15+6 = 21 |
| … | … | … |
| fun(a,1) | = fun(a,0) + a[0]=+1 | = 0+1 = 1 |
| fun(a,0) | 出口 = **0** | — |

**static + 循环调用判停**：不压栈，只列表逐次调用，static 变量一列"上次退出值"、一列"本次退出值"，auto 变量每次写初始值。例6-9：var_static 退出值 0→1→2。

## B — 边界与失分点 ★

**三大失分点**
1. **数组参数等指针**：形参写 `int a[]`，系统不给数组分配内存，传的只是首地址。后果：①函数里改 a[i] = 改实参 ②在函数内对 a 做 sizeof 得不到数组总长（C5 讲透）。二维形参**第二维不能省**。
2. **extern 陷阱**：`extern int a;` 是**声明**已定义的全局变量（可出现多次、可在函数内），**定义**必须在函数外且只能一次；跨文件用 B 文件的变量，B 中定义、A 中 extern 声明。别把 extern 当成"定义新变量"。
3. **递归出口缺失/错配**：无出口→无限递归（栈溢出）；出口条件与递减方向不配套（如 `n>=1` 递减却出口 `n==1`，n=0 时失控）。

**其余易错**：函数首部误加分号=变成声明；无返回值函数必须写 void（否则返回不确定值）；return 只能带一个值；形参按普通内部变量对待（不能加 static）；auto 未初始化=随机值、static/全局未初始化=0；函数不能嵌套**定义**但能嵌套**调用**，main 不能被调用。

**混淆表**

| 场景 | C4 本单元答法 | 别写成 | 归属 |
|---|---|---|---|
| 函数为什么能改我的数组 | 数组名传参=传首地址，形参实参共享内存 | "`*p` 解引用逐元素改"等指针写法细节 | **C5 指针**（真正传递的底层机制） |
| 怎么真交换两个实参 | C4 值传递办不到（例6-6）；结论"要传地址" | `void swap(int *a,int *b){*a^=*b;...}` 的写法 | **C5** |
| 函数体里的 if/for/while | 只当"函数体由控制流搭成"用 | break/continue、循环边界推导 | **C2 控制流**（函数体骨架） |
| static 修饰谁 | static 局部变量：活全程、只函数内可用；static 全局：限本文件 | extern：扩展作用域到其他文件 | C4 内部对比，勿混 |
