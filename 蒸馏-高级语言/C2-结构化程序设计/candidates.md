## 池 2 · I 骨架+钩子池

- I-01 骨架：三种结构 → if 单/双分支 → 嵌套与 else-if → switch → while/do-while/for → break/continue → 循环嵌套。
- I-02 钩子候选（自造、非故事隐喻）：
  1. "else 就近配对：归离它最近、还没被认领的 if；花括号能改判"
  2. "break 中层跳不穿：只砸一层玻璃，外层照转"
  3. "do-while 起码跑一次：先干活后验收；while 先验收，可能一次不干"
  4. "switch 不加 break 是穿堂风：从入口一路穿到楼底"
  5. "for 三段式'初值；门槛；步子'：分号不能省，门槛空了永远进门"

## 池 5 · B 边界池

- B-01 while(i=0) 恒假 0 次 / while(i=1) 恒真死循环（= 与 ==）
- B-02 for 头后多分号 → 空循环体
- B-03 switch 漏 break 穿透；case 含变量非法；case 值重复非法
- B-04 do-while 尾分号必须；漏分号编译错
- B-05 continue 在 for 中仍执行表达式3，在 do-while 中跳向尾部条件判断
- B-06 嵌套中 break/continue 只作用最内层
- B-07 循环体/分支体为多条语句必须花括号
- B-08 边界衔接 C1：表达式求值作为循环条件（i++<4 的求值次序属 C1，"循环几次"属 C2）
- B-09 边界衔接 C4：递归出口=判停条件，循环可改递归
- B-10 边界衔接 C5：scanf(&x) 取地址、循环内传址/传值属 C5，循环结构本身属 C2
