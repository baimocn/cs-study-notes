# GLOSSARY — 数据库判据词表（SQL Server 2012 教材口径）

判据钩子 = "看到 X 就判对/判错"的一眼判据。定义以教材/SKILL.md 口径为准；真机差异只在钩子里一句话提示。

## 概念（关系模型/完整性）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 数据完整性 | 数据的正确性与一致性（精确性+可靠性）；关起来看，是保证库中数据"对得上、算得通"。 | 看到"精确性+可靠性"→对；写成"数据的保密性"→错（保密是安全性的事） |
| 实体完整性 | 主键属性列上的值不能为空且必须唯一（行行有身份证）。 | 填"主键可为空"→必错；答"它管行不管格"→对 |
| 域完整性 | 对某一列取值范围的约束：类型、范围、非空（格格有门槛）。 | 用 CHECK/DEFAULT/NOT NULL/数据类型实现的都归域完整性 |
| 参照完整性 | 不能在从表中引用主表中不存在的元组（外键值=主表真有）。 | 看到"从表插入主表没有的键值被拒绝"→就是参照完整性 |
| 用户定义完整性 | 针对具体应用语义的约束；其余三类均可承载它。 | 判"超出前三类的语义约束"→选它；四类完整性题必须答全四类 |
| PRIMARY KEY（主键） | 唯一标识元组的属性（组合）；唯一+非空，每表都应有一个，建时自动建唯一索引。 | 主键列=NULL →判错；主键先于 UNIQUE 索引成立→判对 |
| UNIQUE 约束 | 列内不重复，但允许 NULL。 | 唯一约束列可为 NULL（仅一行 NULL；主键不行）→ 答题用"约束≠索引"分 |
| CHECK 约束 | 布尔条件，拒绝非 TRUE 值；一个字段可挂多个。 | "CHECK 只能挂一个"→错；CHECK 不能引用其他表的列→对（要跨表就得触发器） |
| DEFAULT / NOT NULL | DEFAULT：没填自动补默认值；NOT NULL：不允许空值。 | "NULL 就是 0 或空格"→必错；IDENTITY 列不能绑 DEFAULT→对 |
| FOREIGN KEY（外键） | 本表列不是（或只是部分）本表码，却是另一关系的码；指向主表的主键/候选键。 | 外键列必须先确认被引用列是主表主键，否则建不起来 |
| 主表/从表 | 属性在 A 表当主键（老家）→A 主表；在 B 表当外键（借用）→B 从表。 | 键的老家=主表、借用处=从表；写反即错 |
| 参照三禁 | 禁从表插入主表没有的键值；禁删从表有对应记录的主表行；禁改主表键值致从表孤立。 | 插、删、改三个方向都不放行→判全才对 |
| 候选码/主码 | 唯一标识元组且不含多余属性的属性组；从中选定一个即主码。 | "唯一标识元组的属性（或属性组合）"填候选码/主码 |
| 函数依赖 | 一个属性组的值确定另一属性组的值，是语义范畴概念。 | "依赖可用数学证明"→错；看到"允许重名时姓名→年龄不成立"→对 |
| 范式链 1NF→4NF | 1NF 属性原子；2NF 消非主属性部分依赖；3NF 消传递依赖；BCNF 每个决定因素都含码；4NF 消非平凡非函数多值依赖。 | 口诀"1 拆原子、2 拆部分、3 断传递、BC 管主属性、4 斩多值" |
| 插入/删除/修改异常 | 合一表造成的四类问题（加冗余）：插不进、删带走、改一半、存重复。 | 看到示例是"学号为空被实体完整性拒绝的插入"→正是插入异常 |
| 规范化 | 通过分解使一个关系表示一事或一物（单一化）。 | "规范化就是合并几张表"→反了，是分解 |
| 三级模式 | 外模式（=子模式=用户模式，可多个）、模式（=逻辑模式，仅一个）、内模式（=存储模式，仅一个）。 | 视图→外模式；基本表→模式；索引→内模式，写反即错 |
| 两级映像与独立性 | 外模式/模式映像保逻辑独立性；模式/内模式映像保物理独立性。 | "映像夹住的两层变了、上层不动"=独立；逻辑/物理别配反 |
| 开销阶梯 | 完整性实现开销：数据类型 < 默认/规则 < 约束 < 触发器，选够用的最低档。 | 见"能用约束就不用触发器"→教材原话判对 |
| DB / DBMS / DBS | 数据库 DB/DBMS/DBS 三件套：DBMS 位于用户与操作系统之间；DBS 广义含 DB、DBMS、开发工具、应用、DBA 与用户。 | 填空"DBMS 位于___之间"→用户与操作系统之间 |

## 对象（库/表/类型/索引/视图）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| mdf/ndf/ldf | 主数据文件每库有且只有一个；次要数据文件 0~n 个；事务日志文件至少一个，记录全部操作事件可恢复。 | "一个库可以有多个主数据文件"→错；日志文件不属于任何文件组→对 |
| 系统数据库四兄弟 | master（核心信息，坏了服务器瘫痪）、model（模板库）、tempdb（临时对象，重启即清空）、msdb（任务调度/报警）。 | "tempdb 可以备份"→必错；改 master 后应及时备份→对 |
| 页与 8060B | 存储分配单位是页，8KB=8192B，其中 8060B 存数据；行不能跨页，一行各列之和≤8060B（大对象除外）。 | 填"一页 8KB"→对；"一行可以 8192B"→错，上限是 8060B |
| 分离与附加 | 分离=脱离实例但文件留磁盘；附加=CREATE DATABASE…FOR ATTACH 把 mdf 挂回服务器。 | 分离后"文件被删除"→错，文件还在磁盘 |
| char(n) vs varchar(n) | char 定长：1~8000，不足补空格；varchar 变长：按实际长度+2B。char 查询快，长度不固定用 varchar；n 省略默认 1。 | 学号/身份证选 char 不选 int——不参与运算、保留前导零 |
| nchar/nvarchar | unicode 家族，用法同 char/varchar 但 n 上限 1~4000（char 系 1~8000）。 | 看到 nchar(8000)→必错，容量减半上限 4000 |
| 整数四类型 | bigint(8B)/int(4B)/smallint(2B)/tinyint(1B)；tinyint 范围 0~255。 | tinyint 存负数→错；8-4-2-1 字节链填空 |
| decimal(p,s) | 精确数值：p=总位数（不含小数点，最大 38），s=小数位数（0~p，默认 0）；numeric 等价。 | p 含小数点→错；"需精确定小数用 float"→错，用 decimal |
| float/real | 近似数值型，float(n) n=1~53、real 4B；不能确定输出精确度。 | 见"金额字段建议 float"→判错（教材口径用 money/decimal） |
| money/smallmoney | 货币型，精确到万分之一（4 位小数）；money 8B、smallmoney 4B。 | "money 精确到分"→错，是万分之一 |
| bit | 只取 1、0 或 NULL；输入其他任何值按 1 处理；≤8 个 bit 字段共用 1B。 | bit 存 2 系统按 1 存→判对；bit 显示 3→不可能 |
| datetime vs smalldatetime | datetime：1753-1-1~9999-12-31，精确 3.33ms；smalldatetime：1900-1-1~2079-6-6，精确到分。 | "smalldatetime 也可以精确到毫秒"→错 |
| IDENTITY 标识列 | 一表只能有一个；系统按(种子,增量)自动赋唯一递增；不能用户更新、不能为空、不能绑默认值。 | IDENTITY 列手动插入值→错；排骨主键常配 IDENTITY+PRIMARY KEY |
| 规则/默认对象 | 独立于表一次定义多处绑定的对象；生命周期：创建→绑定→解绑→删除。 | DROP 前必须先解绑；一字段只能绑一个规则（CHECK 可多个） |
| 索引 | 保存表中一列/几列排序结构的数据库对象；索引之于表=目录之于书，避免全表扫描。 | "索引越多越好"→必错：占空间、建维护耗时、拖慢更新 |
| 聚集索引 | 数据行物理顺序与索引顺序完全相同，叶层=数据页；每表只能建一个（主键默认建聚集）。 | "一个表可建多个聚集索引"→必错（非聚集才可最多 249 个） |
| 非聚集索引 | 数据行不按索引键排序，叶层=索引行+行定位器；每表最多 249 个。 | 填空"非聚集最多___个"→249；省略 CLUSTERED 默认建非聚集 |
| 建索引原则 | 主键必建、外键可建、常查的列最好建；重复值多的列、text/image/bit 列不建。 | 见"给 bit 列建索引"→判错 |
| 临时表 | 表名前加 # 为局部临时表、## 为全局临时表。 | 判"#表是永久表"→错 |
| 视图 | 虚拟表：存 SELECT 定义不存数据，引用时动态生成；一切操作最终消解为对基表的操作。 | "视图里存了数据副本"→必错；基表删了视图也不能用了→对 |
| 视图四大优点 | 简化操作、多角度看同一数据、对重构库提供逻辑独立性、机密数据安全保护。 | 简答四条一条不能少；"提供物理独立性"→错（是逻辑独立性） |
| WITH CHECK OPTION | 通过视图 INSERT/UPDATE/DELETE 的行必须仍满足视图定义条件，否则拒绝。 | 见"改完的行从视图里消失了还被接受"→没开 CHECK OPTION |
| 可更新视图 | 一次 UPDATE/INSERT 的列必须属于同一基表；基表非空列须给值；修改须符合基表约束。 | 见一条语句同时更新两基表的列→必错（多表视图通常不可更新） |
| 复制空表 | SELECT…INTO 新表 WHERE 1=2（永假）：只复制结构不复制数据。 | "INTO 是into只建视图"→错；INTO 不能与 COMPUTE 连用 |

## 查询（SQL 关键字与子句）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 五子句顺序 | 书写：SELECT→FROM→WHERE→GROUP BY→HAVING→ORDER BY；执行：FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY。 | WHERE 里用 SELECT 别名→必错（别名还没诞生）；ORDER BY 里用→对 |
| WHERE vs HAVING | WHERE 作用于表选行；HAVING 作用于组选组。 | WHERE COUNT(*)>=4 →必错：查询进 HAVING，聚合是组属性 |
| GROUP BY | 分组列值相同的记录切一组，每组汇总一条；SELECT 列必须是分组列或聚合计算列。 | 见非分组列裸进 SELECT→必错 |
| DISTINCT | 加在字段列表前去重结果集中重复行（投影去重的 SQL 显式版）。 | "DISTINCT 去重发生在 WHERE 前"→错，发生在投影之后 |
| TOP n / PERCENT | 返回前 n 行/前 n%；无 ORDER BY 时"前 n 条"无确定语义。 | 见"TOP 3 必是最高三名"→只有配 ORDER BY 才成立 |
| BETWEEN…AND | 范围含两端：BETWEEN 后下限、AND 后上限。 | BETWEEN 80 AND 89 = [80,89] 含 89；教材例用 >=80 AND <89 是半开，两写法不等 |
| IN / IS NULL | IN：集合匹配；判空只能 IS NULL / IS NOT NULL。 | WHERE 备注=NULL →必错，IS 不能换 '='；NULL≠0≠空格 |
| LIKE 通配符 | %任意长串；_单个字符；[ ]括号内任一字符；[^ ]不在括号内任一字符。 | '周_' 匹配周某某两字名→对；'周%' 通配→错（_ 是 1 个字符） |
| ESCAPE | 换码字符使后面的通配符降级为普通字符。 | LIKE 'CC/_2014' ESCAPE '/' →'_' 变普通下划线 |
| SELECT INTO | 结果集落成新表；# 临时表。 | "SELECT INTO 修改已有表的数据"→错，它是造新表 |
| 聚合函数（集合函数） | COUNT/SUM/AVG/MAX/MIN；默认 ALL；SUM/AVG 只对数值列且忽略 NULL。 | 教材原词"集合函数"=聚合/聚集函数，三种叫法都对 |
| COUNT(*) vs COUNT(列) | COUNT(*) 全行数（含 NULL 行）；COUNT(列) 非空值个数；COUNT(DISTINCT col) 去重计数。 | "空表 COUNT(*) 返回 NULL"→错，返回 0 |
| 选择 σ / 投影 π | σ 水平分割取行→WHERE；π 垂直分割取列（自动去重）→SELECT 清单。 | "投影是取行"→错；σ 选择投影列（题目乱码 Os/兀→认出即可） |
| 并/交/差/笛卡儿积 | UNION（自动去重）/INTERSECT/EXCEPT；CROSS JOIN=广义笛卡儿积（不带 ON）。 | UNION ALL 保留重复→对；三算子要求列数相同、对应类型相同 |
| 最小完备集 | 并、差、笛卡儿积、投影、选择五操作；交可用差表示 R∩S=R-(R-S)。 | 填空五操作顺序；"交也属于最小完备集"→错，可由差导出 |
| 除运算 | 像集包含 S 的全部值；SQL 无直接算子，用 NOT EXISTS 双层嵌套模拟。 | 见"WHERE 查询里求'选了全部课程的学生'"→考除运算 |
| ORDER BY | ASC 升序（默认）/DESC；多列排序按列序逐级生效。 | "默认降序"→错；不写 ORDER BY 结果顺序无保证 |
| 内连接/等值连接/自然连接 | 连接=从笛卡儿积选满足条件的元组；自然连接=等值连接再去掉重复属性列。 | "自然连接结果保留全部重复列"→错；同名列引用须加表名前缀 |
| 外连接 | 结果=满足条件的行+相应表不满足的行（缺的一侧补 NULL）；LEFT 保留左表、RIGHT 右表、FULL 两边；OUTER 可省略。 | 一句话：内连接只留配上的，外连接把没配上的也留下、缺侧补 NULL |
| 自身连接 | 同表自连必须起两个别名。 | 见 ON first.教师编号=second.教师编号→先找 AS first,second，没别名即为错 |

## 函数

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| LEN | 返回字符表达式长度，不含尾随空格。 | 'abc  ' LEN=3→对；DATALENGTH 才含尾随空格（真机口径） |
| CHARINDEX / PATINDEX | 求子串/模式在串中的起始位置；找不到返回 0。 | 返回值>0 即命中；填"返回-1 表示未找到"→错 |
| SUBSTRING / LEFT / RIGHT | 取子串三件套；LEFT('command',4)='comm'。 | LEFT 第二参是个数不是下标 |
| REPLACE / UPPER / LOWER / LTRIM / RTRIM | 串替换、大小写、去左/右空格。 | LTRIM 只去左，RTRIM 只去右，两参连用才全去 |
| CONCAT | 串连接；NULL 当空串。 | CONCAT('hello',NULL,'world')='helloworld'，NULL 被"吞"→判对 |
| GETDATE / YEAR / MONTH / DAY | GETDATE 返回当前系统日期时间；YEAR/MONTH/DAY 返回 int。 | YEAR(GETDATE()) 参与算术→对；DATENAME 才返回字符串 |
| DATENAME vs DATEPART | DATENAME 返回字符串（如星期二）；DATEPART 返回整数。 | "DATENAME(weekday,…)=星期二"→对；考试里两者返回类型最常配反 |
| DATEFROMPARTS / EOMONTH | DATEFROMPARTS(2017,1,15)='2017-01-15'；EOMONTH 返回月末（第二参偏移月）。 | EOMONTH('2017-01-16',1)='2017-02-28'→判对；填"月末必须算闰年"是它们的本职 |
| CEILING / FLOOR | CEILING 向大取整、FLOOR 向小取整；负数方向不反转。 | FLOOR(-56.3)=-57、CEILING(-56.3)=-56→判对 |
| ROUND / POWER / SQUARE / SQRT / ABS | ROUND(56.34,1)=56.30（y 为负=小数点左侧舍入）；POWER(2,3)=8、SQUARE(5)=25、SQRT(16)=4、ABS(-12)=12。 | ROUND(56.34,-1)=60→对（左舍入）；"FLOOR(-56.3)=-56"→错 |
| CAST / CONVERT | 类型转换；CAST(x AS 类型)；CONVERT(类型,x[,style])——style 多一个参数管日期格式。 | 见 convert(varchar,出生日期,23) 去掉时间→判对；CONVERT 不用 style→合法但没格式 |
| TRY_CONVERT / PARSE / CHOOSE / IIF | TRY_CONVERT 转不动返回 NULL 不报错；CHOOSE(3,'A','B','C')='C'；IIF(3>2,'T','F')='T'（2012 新增）。 | 'ttt' 转 float 报错→用了 CONVERT；返回 NULL→TRY_CONVERT |

## 编程（事务/T-SQL）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 批处理与 GO | 批=一次发送并编译成一个执行计划的语句集；GO 是客户端批结束标记，不是 T-SQL 语句。 | "GO 是 T-SQL 语句"→必错；服务器收到的批中不含 GO |
| 语法错误 vs 执行错误 | 语法错误：整个批不能编译执行；执行错误：仅终止出错处到批末尾。 | 见"违反约束导致前面已执行语句被回滚"→执行错误不影响之前语句 |
| 变量 @ / @@ | 局部变量 @开头用户定义；全局变量 @@开头系统维护（32 个）只能读——本质是系统函数。 | "@@ROWCOUNT 是全局变量可读不可写"→对；局部变量跨批引用→错 |
| SELECT vs SET 赋值 | DECLARE 未赋值则 NULL；SET 一次只能赋一个变量，SELECT 一次可赋多个。 | "SET @a=1,@b=2"→必错；不能声明 text/ntext/image 变量 |
| PRINT vs SELECT | PRINT 输出到"消息"窗格；SELECT 输出到"结果"窗格。 | 看到"输出到结果窗格"→SELECT；别把两者写反 |
| 流程控制 | BEGIN…END、IF…ELSE、CASE（简单/搜索，无 ELSE 返回 NULL）、WHILE（BREAK 退出、CONTINUE 回头）。 | WHILE 内层 BREAK 只退出本层→判对；CASE 无 ELSE 返回 0→错，返回 NULL |
| 事务 | 要么全部成功完成、要么失败全部复原（回滚）的执行单元；目的=防并发访问异常。 | 填"事务的单位是物流/存储"→错；是 SQL 执行单元 |
| ACID | 原子性（全做或全不做）、一致性（完成/失败都处于一致状态）、隔离性（事务互不干扰）、持久性（成功后永久生效，掉电不丢）。 | 四属性对号：见"掉电不丢"选持久性；"互不干扰"隔离性 |
| 显式/隐式事务 | 显式：BEGIN TRANSACTION 定义；隐式：系统提供，一条语句即一个事务（CREATE/INSERT/SELECT 等）。 | "INSERT 自动算一个事务是显式事务"→错，隐式 |
| COMMIT / ROLLBACK / SAVE | COMMIT 提交永久生效（@@TRANCOUNT 减 1）；ROLLBACK 撤销到起点或保存点（至保存点不减少）；SAVE TRANSACTION 设回滚停止点。 | ROLLBACK 到保存点后 @@TRANCOUNT 不变→判对；COMMIT WORK 与 COMMIT 差别=WORK 不带参数 |
| @@TRANCOUNT / @@ERROR | @@TRANCOUNT=当前连接活动事务数；@@ERROR 记录最后一条语句的错误码，0=成功。 | IF @@ERROR<>0 必须紧跟出错语句——后续成功语句会清 0（高频陷阱） |
| 锁三兄弟 | 共享锁 S（SELECT 加、可共存、读完即放）；排它锁 X（写加、独占一切锁）；更新锁（UPDATE 定位读共享、改时升排它）。 | "一个资源可同时持两个排它锁"→必错；"共享锁期间可修改"→错 |
| 锁粒度 | 行→页→扩展盘区→表→数据库；粒度越小开销越大并发越高；升级判据=占比>2%。 | 填空粒度顺序；"粒度大并发度反而高"→反了 |
| 死锁 | 两事务循环等待对方资源。预防=一次/顺序封锁法；诊断=等待图有回路；解除=撤销代价最小者。 | 诊断钩子：事务等待图出现回路即死锁 |
| 存储过程 | 预编译 SQL 语句集存于服务器，按名称执行；编译代码存高速缓存；可接收输入参数并以 OUTPUT 返回值；返回状态值。 | "存储过程必须用 EXEC 带 EXEC 才能执行"→错——若它是批中第一条语句，EXEC 可省 |
| 存储过程五类型 | 系统（sp_，master 库）、本地、临时（# / ##）、远程、扩展（xp_，DLL），存储过程命名：sp_ 系统 / xp_ 扩展 / up_ 用户。 | xp_xxx 是扩展存储过程→对（钩：x=extended） |
| 输出参数 | 形参后加 OUTPUT；执行时实参也要对应变量加 OUTPUT。 | EXEC 名 @p,@avg OUTPUT →两处都要 OUTPUT，漏一处即错 |
| 触发器 | 附在表/视图上的特殊存储过程：事件+条件+动作；数据修改时自动执行。 | "触发器可以通过 EXEC 调用并传参"→必错：不可能按名直接调用、更不允许参数 |
| AFTER / INSTEAD OF | AFTER（=FOR）后触发，只能定义在表上、每操作可多个；INSTEAD OF 替代触发，表和视图都可定义、每操作仅一个。 | "视图上建 AFTER 触发器"→错；"INSTEAD OF 一个操作建两个"→错 |
| 虚表 inserted/deleted | 触发时系统自动建于内存的逻辑表，结束自动删；UPDATE=旧进 deleted 新进 inserted；DELETE 行只进 deleted。 | INSERT 只产生 inserted、DELETE 只产生 deleted、UPDATE 两张各一份；TRUNCATE 不触发 DELETE 触发器 |
| 触发器嵌套与递归 | 嵌套默认允许最多 32 层；递归默认禁用、最多 16 层。 | 见"触发 33 层自动回滚"→判对 |
| DDL 触发器 | 响应 CREATE/ALTER/DROP 等，只有 AFTER 一种响应时间；ON DATABASE 或 ALL SERVER。 | "DDL 触发器可用 INSTEAD OF"→错；题型=例 10.23 数据库级防删改表+ROLLBACK |
| 存储过程 vs 触发器 | 存储：显式 EXEC 调用、可用参数；触发：自动触发、不能调用不能传参、附在表/视图上。 | 凡带参数的直接排除触发器 |

## 安全

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| Windows 验证 vs 混合验证 | Windows 验证只认 Windows 用户；混合=Windows 用户+SQL Server 独立登录账号均可。 | 判断题：能否出现"SQL Server 登录账号"→能=混合；改验证模式须重启 SQL Server 服务才生效 |
| 登录名 vs 数据库用户 | Login 属服务器层、本身不能访问库；User 由登录名映射而来；一个登录名在一个库中只能对应一个用户。 | 两级门禁：有登录名≠能访问库；填"一库一登录可对应多个用户"→错 |
| sa 账号 | 超级账号，安装后密码为空，装完第一件事是设密码。 | "sa 密码安装时自动设好"→错 |
| 角色 | 权限的集合（类似 Windows 用户组）；服务器角色 9 个固定，数据库角色仅作用于单个库。 | public 人人必有、新用户自动加入；sysadmin 是服务器角色别算成数据库角色 |
| 对象/语句/隐含权限 | 对象权限=对表/视图/存储过程的操作权（SELECT/INSERT/UPDATE/DELETE/EXEC）；语句权限=CREATE TABLE 等 DDL 级与 BACKUP DATABASE；隐含权限=sysadmin、dbo 等预定义，不可设置。 | 归类陷阱：CREATE TABLE→语句权限；SELECT 表→对象权限；BACKUP DATABASE→语句权限 |
| GRANT / DENY / REVOKE | 授予（允许）/取消（不允许执行）/拒绝（即使被授予或经继承获得也不允许）。 | 账本口诀：GRANT 存入、REVOKE 划掉、DENY 盖冻章；"不允许可重新获得，拒绝后无法经角色再获得" |
| DENY 优先 | 用户继承角色权限，多角色取并集；但只要有一个 DENY 即为拒绝，权限冲突时 DENY 起作用。 | 见"用户并入一角色全 GRANT 但另角色 DENY"→最终判拒绝 |

## 备份与容灾

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 备份 vs 还原 | 备份=制作库结构、对象和数据的复制；还原=将备份加载回服务器的过程；未完成事务不还原。 | "备份就是复制 mdf/ldf 文件"→错，是先将日志写盘再按事务重建数据库 |
| 四种备份类型 | 两大类（数据库备份、文件和文件组备份）下四类型：完整、差异、事务日志、文件和文件组。 | 填"四种备份数据"→完整/差异/事务日志/文件和文件组，别漏第四种 |
| 差异备份 | 只备份最近一次数据库备份以来的变化，教材原话=增量数据库备份。 | 差异备份不能单独还原——必须先有完整备份打底 |
| 事务日志备份 | 记录事务、可还原到失败点；必须先有完整备份且按备份顺序依次重放。 | "跳过一次日志备份继续还原"→必错，顺序不可跳 |
| 还原顺序 | 先最近完整备份→再最近差异备份→最后按序还原其后各次日志备份。 | 题型=崩溃恢复四步（C3 题）：可能时先备活动日志，再按完整→差异→日志 |
| 三种恢复模式 | 简单（Simple，仅库/差异备份、回不到失败点）、完全（Full，+日志备份、可到失败点）、批日志（Bulk-logged，策略同完全、省批操作日志空间）。 | 题"要求还原到失败点"→必须完全还原模式+事务日志备份；简单模式做不到 |
| 备份四不允许 | 备份过程中不允许：创建/删除库文件、创建索引、执行非日志操作、收缩数据库。 | 备份已在跑→禁操作失败、备份继续；操作已在跑→备份被终止，两个方向别记反 |
| tempdb 与系统库备份 | 需定期备份 master、msdb、model；tempdb 不可备份（启动即重建、关闭即清空）。 | 见备份清单含 tempdb→必勾掉；master 损坏=服务器瘫痪 |
| 维护计划=自动定时备份 | 自动定时备份用维护计划功能（作业按周期执行），教材口径仅企业版提供。 | "标准版也能配维护计划自动备份"→按教材判错 |
| 备份设备 | 存备份的存储介质：硬盘、磁带或管道；备份设备到本地磁带机（不支持网络远程磁带机）。 | 磁带到"网络远程磁带机"→错；备份到本地磁盘文件时可不专门建设备 |
| 导入和导出向导 | SSMS 右键库→任务→导入/导出数据；一次设源与目标，复制表/视图数据或查询结果，前身 DTS。 | 导入前提=来源表结构与库中表结构一致，否则需在"列映射"里设置，直接导必失败 |
