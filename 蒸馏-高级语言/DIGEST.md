# 这册蒸馏在讲什么

《高级语言程序设计》这本教材的知识体系，是从"数据怎么表示"出发，一路修到"数据怎么落盘"的一条成长线。

先解决表示问题：C 语言里任何东西都是数——字符是数、真假是数、地址也是数。类型与表达式（C1）给了你"数怎么存、式子怎么算"的全部裁判规则；
再用选择与循环（C2）把裁判规则串成会走路的程序。
数据多起来，数组与字符串（C3）提供了第一个容器；而函数（C4）让代码能封装、能复用、能递归。
然后是全书的命门：指针（C5）——它揭开"数组名为什么改不动""函数为什么能改我的实参"这些前面所有单元悬而未决的谜底。
命门之后是高级封装：结构体与自定义类型（C6）把不同类型打包成新类型；
编译预处理（C7）在编译开始之前先做一层文本魔法；
最后，文件（C8）把一切成果落盘——打开、读写、关闭，三步走完数据的去留。

地基、骨架、容器、积木、命门、封装、魔法、落盘——八个论点拎完，一本书的骨架就完整了。

每个单元的 SKILL.md 是"单兵作战手册"，而这册 DIGEST 是"集团军作战图"。

使用方式：先在这里用方法论小节建立判据直觉——每节五拍（解决什么问题 / 核心逻辑 / 一例 / 何时失效 / 深入链接），五分钟过完一个武器库。
发现哪个判据手感生疏，顺末尾的链接跳回对应单元的 SKILL.md 看全量例题与题型清单。
它不替代刷题，替代的是刷题前的那遍"把刀磨齐"。

本册的剪裁标准只有一条：能不能构成失分点。
所有钩子、判据、反例都从八个单元的 verified 链路（候选→验证→蒸馏→盲测）里筛出来，
教材错的地方明确指正、明确标注"考试按教材"口径，不假夸、不注水。
考前最后一晚，你只需要这册的最后三节。

**八单元地图**（快速检索用）：

- C1 类型与表达式——求值五步法、天梯、三前缀、字节双口径。
- C2 结构化程序设计——else 配对、switch 穿透、表格跟踪法。
- C3 数组——下标从 0、初始化补 0、\0 尾巴、画格法与尾巴步。
- C4 函数——值址传递、static、递归栈表法。
- C5 指针（命门）——门牌链、三胞胎、swap 三兄弟、三问判停。
- C6 结构体——`.`与`->`、typedef、能抄不能比。
- C7 编译预处理——宏=文本代打、双括号铁律、三步法。
- C8 文件——读写对偶表、六模式、fseek 三兄弟。

## 一、地基：一切考题终归"求出表达式的值"（C1）

### 方法论 1：表达式求值五步法

- **它解决什么问题**：读程序写结果、表达式求值是本课程第一大题型——没有流程就是凭感觉，凭感觉必错。
- **核心逻辑**：
  1. 括号圈地：先算最内层 `( )`，强转 (类型) 也在此层处理。
  2. 单目点名：! ~ ++ -- sizeof，右结合从右往左啃；前缀 ++i 本步立刻加、后缀 i++ 先记旧值备用。
  3. 算术层：* / %（% 两侧必须整型、余数符号随被除数）→ + −；整除 5/2=2 砍尾巴。
  4. 位/关系层：<< >> → 关系（只吐 1/0）→ & ^ |；连写 a>b>c 按 (a>b)>c 算。
  5. 逻辑/赋值/逗号层：&& || 短路闸门 → ?: → 复合赋值（右结合、右侧整体加括号）→ 逗号取尾。
  - 最后回答**两问**：表达式的值 + 相关变量的终值——两问都要写全。
- **书中用法**：`4&5-3&&5+!2` → 算术先（2、5）→ 位与 4&2=0 → 逻辑与 0&&5=**0**。
- **何时失效**：同一变量双副作用（`i+++i++`）真机是未定义行为——按教材顺序口径作答，别跟编译器较劲。
- → 深入请读 C1-类型与表达式\SKILL.md

### 方法论 2：常量与字符串的"字节账"

- **它解决什么问题**：合法常量判别、字符串占几字节——填空/选择两栖高频。
- **核心逻辑**：
  - 三前缀：光头十进制、0 帽八进制（只许 0~7）、0x 帽十六进制。
  - 'a' 独行侠 1 字节；"a" 拖油瓶 2 字节——**字符串是贪吃蛇，长度 n 占 n+1 节**。
  - \0 是空字符（值 0）：计 1 字节但不计有效长度；'0' 是字符 0（ASCII 48），三者不混。
- **书中用法**："\\0568\034" → \\ 1 字符 + 0、5、6、8 + \034（八进制转义 1 字符）= 6 有效 + 尾巴 = **7 字节**。
- **何时失效**：字节数题必须先看题干口径——【双口径】16 位 PC/TC 的 int=2，32 位口径 int=4，长度表与例题在教材里并存两套。
- → 深入请读 C1-类型与表达式\SKILL.md

### 方法论 3：优先级天梯与三种右结合

- **它解决什么问题**："优先级最高/最低"、"结合方向"、混合式求值——天梯口诀一次压平全部选择项。
- **核心逻辑**：
  - 考用 15 级口诀：括号 1、单目 2、乘除模 3、加减 4、移位 5、大小 6、等不等 7、位与 8、异或 9、位或 10、与 11、或 12、条件 13、赋值 14、逗号 15。
  - 右结合只有三家：单目、条件 ?:、赋值系——"单目条件和赋值，一律从右往左啃"。
  - 关系值只有 1/0；连写关系式全左结合拆括号。
- **书中用法**：`i==j?(k=3):(m=-3)` 条件取真支=3；条件级高于赋值，两支括号不可省。
- **何时失效**：`i*=j%=k+=m/=2` 类复合赋值链从**右往左**逐个拆——从左读起全错。
- → 深入请读 C1-类型与表达式\SKILL.md

### 方法论 4：三种类型转换一杆秤

- **它解决什么问题**：自动转换、赋值转换、强制转换三套规则混在一道题里。
- **核心逻辑**：
  - 自动（隐式）：低→高单向阀 char/short → int → unsigned → long → double，float 必先升 double。
  - 赋值转换：就左不就右，长存短砍高位——不四舍五入、直接截断。
  - 强制转换：括号圈住谁、谁先被转，且**不改原变量的值**（产生中间量）。
- **书中用法**：`10+'a'+i*f-d/e` → 全程就高：char→int→double，答案 double 型。
- **何时失效**：float 只存 7 位有效数字——9.87654321 进 float 就剩前 7 位，"精确存小数用 float"是判断题口袋。
- → 深入请读 C1-类型与表达式\SKILL.md

## 二、骨架：控制流是程序的关节（C2）

### 方法论：表格跟踪法（现场照搬）

- **它解决什么问题**：一切"读程序写结果"的循环题，尤其嵌套循环——不画表就靠脑内模拟，必错。
- **核心逻辑**：
  1. 抄判停条件，盯死 `<=` 还是 `<`、条件里 i++ 是判前还是判后生效。
  2. 定列：每层控制变量一列 + 会变的变量各一列 + 走向列；**行高=内层层数**。
  3. 一行一步：每行只执行一次迭代。
  4. 标记跳转：continue 记 "C→"（for 跳表达式3，i++ 照走）；break 记 "B→"，划掉本层剩余行。
  5. 抄输出：printf 在体内逐行抄，在体外只抄终值。
- **书中用法**：双层 for 中 `if(j%2==0) continue; s+=i*j;`——按表格逐行走出来得输出 1,1 / 2,3 / 3,15、s=15。
- **何时失效**：题目问"循环执行几次/结束后 i 的值"时，别只抄输出——i 的终值=条件最后一次判假时已被自增的值（如 i++<4 结束后 i=5）。
- → 深入请读 C2-结构化程序设计\SKILL.md

### 方法论：分支的三条铁律

- **它解决什么问题**：elseif 配对错、switch 穿透、else-if 链——程序填空与改错的固定套路。
- **核心逻辑**：
  - **else 就近配对**：想改判，加花括号；缩进只是视觉效果。
  - **switch 不加 break 是穿堂风**：从命中入口无视所有标签一路抄到 break；找不到入口看 default。
  - **case 后必须常量表达式**、值互不相同；case 内嵌 if-else 后仍要 break 收口。
- **书中用法**：`switch(a=b==c+1)`——== 优先级高于 =，a 得 1，命中 case 1，执行后遇 break 收笔 → 输出 1。
- **何时失效**：教材例4-17 自己就栽在 else 挂错层（漏判 400 整除年）——把它当反面教材背。
- → 深入请读 C2-结构化程序设计\SKILL.md

### 方法论：程序填空补空三板斧

- **它解决什么问题**：程序填空——空在 if 条件、循环体、循环条件三种位置各有固定打法。
- **核心逻辑**：
  1. 空在 if( ) 里：回译题目要求的"输出 yes 的条件"——"同时整除"就用 && 连两个余零式。
  2. 空在循环体里：先认循环使命——累加填 `s+=…`（初值 0），累乘填 `fact*=…`（初值 1），计数填 `n++`。
  3. 空在循环条件里：找结束标志——读字符到换行填 `(ch=getchar())!='\n'`，读数到 0 填 `i!=0`；!= 与 == 写反即死循环或一次不跑。
- **书中用法**：`num%11==0 && num%13==0`（被 11 和 13 同时整除）；`fact*=i; sum+=fact;`（阶乘和）。
- **何时失效**：for 中省表达式 3 时，循环体内必须自己修正控制变量——这一步就是填空空位。
- → 深入请读 C2-结构化程序设计\SKILL.md

### 方法论：首判对照与等价改写

- **它解决什么问题**："while 与 do-while 输出为什么不同""for 改写成 while 后结果变吗"——循环三兄弟的判别题群。
- **核心逻辑**：
  - 首判区别：条件一开始为假时，while 一次不干（体 0 次），do-while 起码干一次（体 1 次）——sum=0 vs sum=1 的差就是这。
  - 等价改写：while 循环=for 省去表达式1、表达式3 的简化形式；switch 多分支完全可用 if/嵌套 if 改写——考题爱问"等价改写后输出是否相同"。
  - 循环三守恒：控制变量必须在循环前赋初值；n++ 既更新累加项又使循环趋于结束。
- **书中用法**：例4-27/4-29 sum=5050 三版本对照——条件首次为假时 while 版 sum=0、do-while 版 sum=1。
- **何时失效**：逆序输出这类题天然配 do-while（123→321）——先干活后验收的题型信号。
- → 深入请读 C2-结构化程序设计\SKILL.md

## 三、容器：数组是地址常量的始发站（C3）

### 方法论 1：二维数组画格法

- **它解决什么问题**："初值表不分行怎么填""a[i][2-i] 是哪条线""省行长能省列长吗"。
- **核心逻辑**：
  1. 抄定义，数初值个数。
  2. 按行优先填格，填到没初值，剩余格全补 0。
  3. 省行长：行长 = 初值个数 ÷ 列长（除不尽再加 1）；列长不能省。
  4. 问 a[i][j] 就读第 i 行第 j 列——**第 0 行是第一行**。
  5. 判停：格子填完、每问都有格子可读；禁止心算跳步。
- **书中用法**：`int a[3][3]={1..9}` 对角线累加 `s+=a[i][2-i]` → 3+5+7=**15**。
- **何时失效**：完全未初始化的 int a[5] 是垃圾值，"自动为 0"的说法就是一个口袋题——补 0 只在定义时初始化生效。
- → 深入请读 C3-数组\SKILL.md

### 方法论 2：排序双模板

- **它解决什么问题**：冒泡与选择排序的核心双循环边界条件——填空题最爱挖的就是这几个下标。
- **核心逻辑**：
  - 冒泡：外层 i:1~n-1 共 n-1 轮；内层 j:从 n-1 **递减到 i**（每轮 n-i 次相邻比较）；`a[j]<a[j-1]` 则交换。
  - 选择：外层 i:0~n-2；k 先记本轮起点，内层 j:i+1~n-1 遇更小改记 k=j；**整轮比完才交换一次** `if(k!=i){…}`。
  - 矩阵转置一句话：双重循环里 `y[j][i]=x[i][j]`，外扫行内扫列。
- **书中用法**：输入 23 56 89 41 63 → 冒泡输出 23 41 56 63 89；下标填空：外层共 **n-1** 轮、内层 j 从 **n-1** 到 **i**。
- **何时失效**：冒泡内层写成 j>i 或 j>=0 都会越界或漏比——边界是这题的全部答案。
- → 深入请读 C3-数组\SKILL.md

### 方法论 3：字符串 I/O 三组分工

- **它解决什么问题**：scanf %s / gets / puts 三件套的行为差异——混着答必错。
- **核心逻辑**：
  - scanf("%s",str)：遇空格**或**回车断、自动补 '\0'、str 前不加 &。
  - gets(str)：只认回车，可含空格。
  - puts(str)：输出后把 '\0' 换成换行；printf("%s") 不换行、可一次多个。
- **书中用法**：过滤字母程序——`if(是字母) str[j++]=str[i];` 循环结束**补 str[j]='\0'**。
- **何时失效**：scanf("%s",&str) 加了 & 反而错——数组名已是地址；这是判断题的固定送分/送命点。
- → 深入请读 C3-数组\SKILL.md

### 方法论 2：\0 尾巴一步定位

- **它解决什么问题**：strlen/sizeof/%s 三问共用同一个定位点，混着数必错。
- **核心逻辑**：
  - 逐格写数组内容，末尾明确画一个 '\0' 格。
  - strlen：数到第一个 '\0' **前**，不含尾巴。
  - sizeof：数到定义长度；省长度定义 = 有效字符 +1。
  - %s/puts：打印到第一个 '\0' 为止。
  - 三问全由"第一个 '\0' 在哪"一锤定音，答完即停不重数。
- **书中用法**：`char a[]="happy"`：strlen=5、sizeof=6、%s 打到 happy 为止；`char d[5]={'a','b','\0','d','e'}` 实串只有 "ab"。
- **何时失效**：自定义处理后**忘补 str[j]='\0'** 是过滤字符串题最常见丢分点——补尾巴不是习惯，是必答题。
- → 深入请读 C3-数组\SKILL.md

## 四、积木：封装与复用的分工（C4）

### 方法论 1：值传递 vs 数组名传参

- **它解决什么问题**："为什么函数换不动我的实参""为什么函数能改我的数组"——同一问题正反两面。
- **核心逻辑**：
  - 传值=复印件：形参是普通变量，函数里改的是复印件，返回时形参内存即被收回（例6-6 输出 12）。
  - 传址=房钥匙：实参是数组名时传首地址，形参实参**共享内存**——教材原话"数据并没有传递，而是数据的共享"。
  - 副产品：一维形参数组长度可省（int a[]），二维只能省第一维。
- **书中用法**：`aver(int a[])` 里 `a[i]` 累加的就是 main 的 sco——输出 83.60。
- **何时失效**：想"捎回两个值"时 return 办不到（单程票）——要么传地址（那是 C5 的主场），要么用全局变量。
- → 深入请读 C4-函数\SKILL.md

### 方法论 2：static 复读机与递归栈表法

- **它解决什么问题**：static 局部变量逐次调用怎么算；递归读程序怎么不晕——两套判停配套。
- **核心逻辑**：
  - static 局部=复读机只念第一遍：初始化只在第一次调用执行，auto=一次性纸杯每调用换新。
  - static+循环不压栈，只列两列：上次退出值、本次退出值（例6-9：var_static 0→1→2）。
  - 递归四步：列表头→下行压栈（每层只写"f(参数)=待定表达式"）→出口层写值→回代逐层向上。
  - 判停检查：递减方向与出口条件必须配套（n==1 出口遇 n 从 0 递减=无限递归）。
- **书中用法**：f(4)=4*f(3)=…→24（下行 f(4)→f(1)，回代 1→2→6→24）。
- **何时失效**：static 用来"把递归改循环"（例6-15 累乘）时——那是另一套机制（保留上次结果），别与递归混为一谈。
- → 深入请读 C4-函数\SKILL.md

### 方法论 3：定义/声明与存储类型四兄弟

- **它解决什么问题**：函数首部加分号错在哪、extern 与 static 全局各管什么——概念题固定四连。
- **核心逻辑**：
  - 首部末尾**不能**加分号；声明末尾加分号、可省形参名；定义在前可免声明。
  - 四存储：auto（默认，未初始化=随机值）/ static（局部只初始化一次；全局限本文件）/ register（寄存器，不取地址）/ extern（扩展作用域到其他文件）。
  - 定义必须在函数外且只能一次；extern 是声明不是定义。
- **书中用法**：`double add(double x, double y);` —— 带分号故是声明；`int max(int,int);` 合法（省形参名）。
- **何时失效**：main 不能被调用；函数不能嵌套定义但能嵌套调用——两条概念判断的经典否定式。
- → 深入请读 C4-函数\SKILL.md

## 五、命门：指针是全书的谜底（C5，篇幅最大）

### 方法论 1：门牌钩子链——指针的三层心智

- **它解决什么问题**：`&` 与 `*`、`*p=3` 与 `p=&y`、数组名与指针——所有指针题的"为什么"，都在一条钩子链上。
- **核心逻辑**：
  - 变量住地址，指针存门牌号——普通变量里放值，指针变量里放"别人家的门牌号"。
  - `&` 查门牌，`*` 按门牌进门；进门看见的是变量本身，可读可改。
  - `*p` 进去改家具，`p` 只是换门牌——这条直接解释 swap3 为什么无效。
  - 数组名=焊死在楼上的门牌（地址常量，a++ 非法）；指针=拿在手里的门牌（地址变量，p++ 挨家走）。
  - `p+1` 跨一户不是跨一米——按元素个数步进【双口径：教材 int=2 示例 3000+1→3002；32 位加 4 字节】。
- **书中用法**：例7-12 swap 三兄弟输出 `9,12 → 12,9 → 9,12`——换复印件无效、进门换家具有效、换门牌本身无效。
- **何时失效**：递出去的门牌本身也是值传递的复印件——被调函数**不能改实参指针变量**，但**能改它所指向的变量**（结论原书原话）。
- → 深入请读 C5-指针\SKILL.md

### 方法论 2：三胞胎判据——先问 ++ 作用在谁身上

- **它解决什么问题**：`*p++` / `(*p)++` / `*++p` / `++*p` 是指针单元的收口考，四写法两动作。
- **核心逻辑**：
  - `*p++` ≡ *(p++)：**取旧值，p 后移**——取完搬家。
  - `(*p)++`：括号强制先解引用，再对内容加 1——**屋里东西加一，p 不动**。
  - `*++p` ≡ *(++p)：**p 先移，取新值**——先搬再取。
  - `++*p` ≡ ++(*p)：内容加 1、p 不动——与第二式同果。
  - 分离三值：表达式值 / p 最终指向 / 变量最终值，每处表达式三值各写一格，绝不合并。
- **书中用法**（int a[]={5,6,7}, *p=a）：x=*p++ → x=5、a[0] 仍 5、p 指 a[1]；x=(*p)++ → x=5、**a[0] 变 6**、p 不动——表达式值同为 5，**动了 p 还是动了 a[0]**，下一句再访问就分道扬镳。
- **何时失效**：OCR 原稿此处印错（`(*px)++` 印成 `* 0)x++`）——以修复后的对比表为准，别照抄书页。
- → 深入请读 C5-指针\SKILL.md

### 方法论 3：指针题三问判停

- **它解决什么问题**：任何指针表达式都适用——指向谁？解引用了吗？移了几步？
- **核心逻辑**：
  1. 指向谁——找 p 最近的赋值，确定门牌对准哪户；`*(p-1)` 才是 a[1]（若 p=&a[2]）。
  2. 解引用了吗——有 `*` 动的是屋里；没 `*` 动的是门牌本身；声明处的 `*` 不算数。
  3. 移了几步——p++ 移 1 个**元素**；p1-p2 得**元素个数**；移完必须重答第 1 问。
- **书中用法**：例7-2 串长程序 `while(*p!='\0') p++; printf("%d",p-s)`——`p-s` 是指针减法=元素个数。
- **何时失效**：越界引用（p[-1]、*(p+20)）语法对、值不确定——读程序题答案就答"不确定/无意义"，不硬猜。
- → 深入请读 C5-指针\SKILL.md

## 六、高级封装：不同类型的打包（C6）

### 方法论：四格判停法

- **它解决什么问题**：结构体题从声明到访问全链路的判错——`->` 与 `.` 混用是数据结构前的最后一道坎。
- **核心逻辑**：
  1. 声明格：struct 后有无类型名？`;}` 在不在？嵌套成员的类型是否已在前定义？
  2. 定义格：三法选一；无名结构体之后不能再引用。
  3. 赋值格：字符串成员 strcpy；数组成员逐元素；同类型整体 `=` ✓、`==` ✗——**能抄不能比**。
  4. 访问格：左边是变量/数组元素 → `.`；是指针/地址 → `->` 或 `(*p).`——混用即判停。
- **书中用法**：`struct std_info *p=&student;` 三式等价 student.no：`p->no`、`(*p).no`；`*p.no` ✗——`.` 优先级更高，先算成 p.no。
- **书中对照**：指针走结构体数组 `(p++)->name` 先取后移、`(++p)->name` 先移再取——与 C5 三胞胎同构，顺序反答案反。
- **何时失效**：union/enum 这本教材 ch08 零收录——考纲若出现属超纲，按"考试范围按教材"裁定，不编书外例。
- → 深入请读 C6-结构体与自定义类型\SKILL.md

### 方法论：typedef 四用法与发别名四步法

- **它解决什么问题**：typedef 判断"造新类型还是发别名"、与 #define 的分水岭——简答/判断双料高频。
- **核心逻辑**：
  - 四用法：①基本类型（INTEGER x,y）②数组类型（ARRAY a, 长度写死）③结构体（STU stud,*p）④指针型（P_I p1,p2）。
  - 四步法：按定义变量写一遍 → 变量名换新名 → 最前加 typedef → 用新名继续定义。
  - 判停两连：只发别名不定义变量、不造新类型；与 #define 分水岭是**编译时 vs 预处理时**。
- **书中用法**：`typedef int ARRAY[10];` → `ARRAY a,b;` 等价 `int a[10],b[10];`——数组别名带着长度走。
- **何时失效**：`#define P_I int*` 的替换是字面的——`P_I p1,p2` 会被拆成 `int* p1, p2`（p2 不是指针）；typedef 一体成型的优势就是这类辨析。
- → 深入请读 C6-结构体与自定义类型\SKILL.md

## 七、编译前的魔法：宏与文件包含（C7）

### 方法论：宏计算三步法

- **它解决什么问题**：宏展开计算题是唯一"先替换后求值"的题型——把 C1 的求值顺序硬塞进替换是最大错误源。
- **核心逻辑**：
  1. 找目标：圈出宏调用，写宏定义原文，先核对有没有空格带进替身。
  2. 先替换后运算：实参**原样文本**塞进形参位置；禁止在替换阶段求值。
  3. 套 C1 优先级求值：把展开式当普通表达式算。
- **书中用法**：`#define LEN WID+20`，`x=LEN*3` → 80+20*3=**140**——不是想当然的 300；想 300 必须 `#define LEN (WID+20)`。
- **何时失效**：`#define S (a,b)a*b`——宏名与左括号间有空格，S 立即降级为无参对象宏，全盘报废；这是空格陷阱的判据。
- → 深入请读 C7-编译预处理\SKILL.md

### 方法论：宏 vs 函数四区别（简答必背）

- **它解决什么问题**：简答题最稳的答题框架，也是 MAX 宏陷阱题的理论底座。
- **核心逻辑**：
  1. 求值时机：函数先把实参表达式算出值再传；宏只把实参文本塞进形参位置。
  2. 类型：函数实参形参须定类型；宏形参无类型，什么都能塞。
  3. 目标程序：函数调用多少次不变长、占运行时间；宏每用一次展开一次、目标程序变长、不占运行时间。
  4. 检查：函数有类型检查；宏纯替换不做检查（预处理阶段语法检查在编译之后）。
- **书中用法**：`#define MAX(a,b) ((a)>=(b)?(a):(b))` 对照函数版 max——同一问题两种实现，宏是文本代打、函数是运行传值。
- **何时失效**：条件编译与 if 的区别别写反——#ifdef 没选中的段**目标程序里根本没有代码**；if 真假两路全产生代码。
- → 深入请读 C7-编译预处理\SKILL.md

## 八、落盘：文件三步走（C8）

### 方法论：读写对偶表——会一个等于会两个

- **它解决什么问题**：文件函数十几个记不完——对偶表把记忆量砍半。
- **核心逻辑**：
  - 四对偶：fgetc↔fputc（1 字符）/ fgets↔fputs（1 串）/ fread↔fwrite（数据块）/ fscanf↔fprintf（格式化）。
  - 判据口诀：**中间是干什么的、前面给地址、最后给 fp**——唯 fscanf/fprintf 的 fp 排**第一位**。
  - 返回值成对：fputc 成功返回刚写入的字符，fgetc 成功返回读到的字符、失败/到尾 EOF。
- **书中用法**：例10-5 文件复制——"r" 开源、判 NULL、`while((ch=fgetc(fpr))!=EOF) fputc(ch,fpw)` 对偶搬运、双 fclose。
- **何时失效**：fgets 与 gets 是对偶家族里的**分裂者**——gets 把回车换成 '\0'，fgets 保留 '\n' 再补 '\0'（读回须手动去尾）。
- → 深入请读 C8-文件\SKILL.md

### 方法论：六模式口诀与 fopen 题四步判

- **它解决什么问题**：模式串选择、"w 清空 vs a 追加"、程序分析题秒杀——全是模式语义题。
- **核心逻辑**：
  - 口诀：**读 r 写 w 添 a 追加，加 + 能读写，加 b 变二进制**。
  - 三模式互踩：r 必须已存在（不存在返 NULL）；w 清空重来；a 尾巴接着写。
  - 程序分析四问链：第一段是 w/w+ 吗（清空）？写完没关又重开吗（保留）？中间有 rewind 吗（没有就读不到想要的）？读写格式对齐吗（%d 粘连）？
  - fseek 起点：头 0 腹 1 尾 2；第 n 条记录=(n-1)*sizeof 定位；fseek(fp,0L,SEEK_SET) ≡ rewind。
- **书中用法**："w" 写 welcome → fclose → "a" 追加 "55" → rewind → fscanf 读 `%s` → 输出 **welcome55**。
- **何时失效**：缓冲文件系统必须 fclose 才落盘——不关就退出，尾部数据丢失；三个标准设备 stdin/stdout/stderr 恰恰**不该** fclose。
- → 深入请读 C8-文件\SKILL.md

### 方法论：fseek 定位与判尾两法

- **它解决什么问题**：fseek 填空计算题、随机读固定套路、"返回值别记反"的判断题群。
- **核心逻辑**：
  - 起点三兄弟：头 0 / 腹 1 / 尾 2；位移量 long——常数写 -2L、5L，表达式 (long) 强转。
  - 随机定位套路：`fseek(fp,(序号-1)*sizeof(类型),0); fread(&x,sizeof(类型),1,fp);`。
  - 判尾两法：文本 `while((ch=fgetc(fp))!=EOF)`；通用（二进制必须）`while(!feof(fp))`。
  - 返回值账：fclose 成功返 0；feof 到尾返非 0；fscanf 成功返个数、失败 EOF——与多数函数相反。
- **书中用法**：`fseek(fp,-3L*sizeof(char),SEEK_END)` 读倒数第 3 个字符 → 输出 b。
- **何时失效**：负位移从尾起算时先换算"倒数第 n 个"，方向一反就出界——答案"非法"而非硬读。
- → 深入请读 C8-文件\SKILL.md

## 陷阱与反例

以下八条从各单元 B 边界/失分点清单中挑选——每条都能让一道大题归零。交卷前逐条回扫。

### 陷阱 1：三胞胎——`*p++` 与 `(*p)++` 值同而走向异

- **陷阱**：只看表达式值就落笔。x=*p++ 与 x=(*p)++ 的 x 同为 5，但前者动了 p（指向 a[1]）、后者动了 a[0]（p 不动）——下一句再访问，答案分道扬镳。
- **为何掉进去**：把 `*++` 当成捆绑动作；忘了 ++ 作用在 **p** 上（门牌搬家）还是 **\*p** 上（屋里加一）。
- **预警信号**：读到 `*` 与 `++` 相邻，立即拆出右结合全等式标明两个动作，三值分离（表达式值/p 指向/变量值）逐格写。
- 同族：`*--p` / `--*p` 对称成立；口诀"取完搬家 / 屋里加一 / 先搬再取"。

### 陷阱 2：野指针接输入

- **陷阱**：`char *p; scanf("%s",p);` —— p 未赋值，存的是垃圾门牌，进门就砸（原书明确"运行时出错"）。
- **为何掉进去**：把"数组名即可当地址"的规则错误推广到未初始化的指针变量。
- **预警信号**：凡用指针接收输入，先看它有没有指向已分配空间（p=str 或 char a[80]; p=a）；方法三走完一遍后忘了 `p=&s[0]` 回位，也属同族。

### 陷阱 3：else 挂错层

- **陷阱**：嵌套 if-else 里想"year%100!=0 才闰"，else 却挂到了外层 if 上——整除 400 的年份（2000）被判平年（教材例4-17 原版即此错）。
- **为何掉进去**：缩进只是视觉效果，配对只看"离最近、未认领"。
- **预警信号**：看到嵌套 if 先画配对线再读逻辑；想改判——加花括号；判断题里这恰是"else 与哪个 if 配对"的标准考点。

### 陷阱 4：宏少括号——裸奔展开

- **陷阱**：`#define POWER(x) (x*x)`，POWER(a+b) → (4+6*4+6)=**34**，不是 100。
- **为何掉进去**：把有参宏当函数调用，忘了"替换是文本代打"——形参没有一层泡膜，整体没有一层保险。
- **预警信号**： 每个 #define 都验两件事：宏名与左括号间有没有空格、形参与整体有没有括号。`LEN*3` 类填空先写展开式再算——80+20*3=140。

### 陷阱 5：a[n] 越界与"未初始化=0"

- **陷阱**：`int a[3]; a[3]=6;` 或 `int a[5];` 直接输出 a[0]——前者越界破坏相邻数据、后者是垃圾值，两个都答 0 就是双杀。
- **为何掉进去**：把"部分初始化会补 0"推广成"没初始化也补 0"；把"下标从 0"理解成"a[n] 是合法的下一个"。
- **预警信号**：a[n] 是 a[n-1] 后面那格的越界元素；系统不检查越界（判断题"越界时报错"→错）；补 0 只在**定义时初始化**生效。

### 陷阱 6：else 与 switch 穿堂风

- **陷阱**：`switch(等级)` 里某 case 忘写 break，后面所有 case 的 printf 全部陪跑——等级 B 输出 70~84/60~69/<60/error 四行。
- **为何掉进去**：把 case 当成"分支判断"，忘了它只是入口标号，命中后一路穿透到 break。
- **预警信号**：程序分析题秒杀链第二问——从入口开始**无视所有 case 标签**一路抄语句，撞见 break 才收笔；找不到入口先看 default。

### 陷阱 7：do-while 尾分号 & while 头分号

- **陷阱**：`do{...}while(...)` 尾分号漏写→编译错；`while(条件);` 头分号多写→循环体变空语句死循环；`for(...);` 同族。
- **为何掉进去**：三条分号规则位置不同语义不同——do-while **必须**有、while/for **不能**有（在头后）。
- **预警信号**：改错题看到循环，先数分号：头、体、尾三处；再看 while(i=0)（赋值恒 0 一次不执行）与 while(i=1)（恒真死循环）。

### 陷阱 8：strlen vs sizeof 错位计数

- **陷阱**：`char a[]="happy"` 答 strlen=6 或 sizeof=5；`char str[7]="program"`（7+1=8 装不下）被判合法。
- **为何掉进去**：把"有效长度"与"占内存大小"焊在一起——strlen 不含 '\0'，sizeof 是定义总长。
- **预警信号**：字符串三问（strlen/sizeof/%s 输出）共用一个定位格：**第一个 '\0' 在哪**；先圈出来再答，不重数。附带：`char c[3]={'a','b'}` 补出尾巴恰好成 "ab"，`strcat` 会掉原尾巴再接。

| 传值=复印件 传址=房钥匙 | 数组名传参=共享内存（教材原文"数据的共享"） |
| static 复读机 | 初始化只念第一遍；auto 每次换新；static 未初始化自动 0 |
| 数组名=焊死的门牌 | 地址常量：a++、a="abc"、scanf 加 & 全非法 |
| 三胞胎 | *p++ 取完搬家；(*p)++ 屋里加一；*++p 先搬再取；++*p 屋里加一 |
| 指针三问 | 指向谁？解引用了吗？移了几步？ |
| .与-> | `.` 走变量、`->` 走地址；`(*p).成员` 括号不能省 |
| typedef vs #define | 编译时发别名 vs 预处理时文本代打 |
| 宏=文本代打 | 形参+整体双括号，宏名与左括号间无空格 |

## 如果只带走三句话

1. **数组名是焊死的门牌**——地址常量不能换、不能加，能换门牌的只有指针那一格；p 指谁、*p 动了屋里还是动了门牌，每一步都要问一遍。手感生疏 → 回 C3/C5。
2. **宏=文本代打，没括号就是裸奔**——先写展开式再求值；形参数量再少，里外两层括号一层都不能省。写不出展开式 → 回 C7。
3. **else 就近配对，想改判加花括号；字符串有尾巴 \0，strlen 不含尾巴 sizeof 含**——一个是分支层的物理定律，一个是字节层的物理定律，两条都是"教材自己都栽过"的铁证。判不清配对或长度 → 回 C2/C3。
