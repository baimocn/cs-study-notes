## 池5：边界易错池（B 区失分点候选）

| # | 失分点 | 说明 |
|---|--------|------|
| X-01 | **数组参数本质是指针**：教材说"传首地址、共享内存"，但"C 数组参数退化为指针"的准确机制在第七章（C5）。本单元只答到"传首地址"，底层用指针等价改写是 C5 内容 | 跨单元衔接 C5 |
| X-02 | extern 陷阱：extern 是**声明已定义的变量**，不是重新定义；extern int a; 在函数内出现多次合法；定义只能一次且在函数外 | C-22/C-27 |
| X-03 | 递归出口缺失→无限递归（栈溢出）；判停条件写错（如 n==1 但实参 0） | C-28/C-30 |
| X-04 | 函数首部误加分号 `double add(double x,double y);` —— 这是声明不是定义 | C-05 |
| X-05 | 形参不能声明为 static/auto/register（形参只能默认 auto）；练习选择题5-D 是错误项 | C-35 [B：教材正文"形参也是内部变量"+选择5选项排除] |
| X-06 | return 只能带回**一个**值；想要两个结果要用地址传递或全局变量 | C-07 |
| X-07 | 值传递函数想交换实参→失败（例6-6）；要真交换必须传地址（C5 详讲） | E-03 |
| X-08 | static 局部变量初始化语句在第二次调用时**被跳过**，不是重新赋值 | C-20 |
| X-09 | 未初始化：auto=随机值，static/全局=0（'\0'）——读程序题高频 | C-19/C-20 |
| X-10 | 二维数组形参第二维不能省；一维可省 | C-17 |
| X-11 | main 不能被其他函数调用；函数不能嵌套**定义**但可以嵌套**调用** | C-02/C-29 |
| X-12 | 无返回值函数不写 void → 返回不确定的值，不是"不返回" | C-06 |
| X-13 | floor 向下取整对负数：floor(-2.3)=-3.0 不是 -2.0 | C-33 |
