# D4 候选池（五候选）——连接与多表操作 + 数据库与开发工具协同

来源：ch12 全文（主）+ ch05 连接相关节（5.1 连接运算、5.3.1–5.3.6 连接查询，行 439–547）

## 候选1：ODBC 四层体系结构（概念考区 ★核心）

- 出处：ch12 §12.1.1
- 内容：ODBC 由四部分构成——①ODBC 数据库应用程序（application，调 ODBC 函数、递交 SQL）；②驱动程序管理器（driver manager，DLL，为应用加载/调用正确的 DBMS 驱动、检查调用参数合法性、提供单一入口）；③DBMS 驱动程序（DLL，建立与数据源的连接、提交 SQL、做数据格式转换、把错误转成 ODBC 标准错误代码）；④数据源（DSN，驱动与 DBS 连接的桥梁，数据源不是 DBS 本身）。
- 数据源三类：用户数据源（仅创建者、仅本机可用）、系统数据源（所有用户及服务方式运行的程序可用）、文件数据源（ODBC 3.0+，企业用户）。
- 关键辨析点：应用程序不能直接存取数据库；驱动程序管理器管"加载与调度"，驱动程序管"真正干活"。
- 钩子方向：四层 = "说话的 → 派活的 → 干活的 → 存货的"。

## 候选2：ADO 对象模型与核心三对象（概念考区 ★核心）

- 出处：ch12 §12.1.3、§12.4.2
- 内容：ADO（ActiveX Data Objects）构建于 OLE DB API 之上，面向对象、与语言无关。对象模型：Connection / Command / Recordset / Field，另有 Parameter、Error、Properties 集合；每个 Connection、Command、Recordset、Field 都有 Properties 集合。
- ASP 中最重要三个对象：connection（到数据源的连接）、command（可被数据源执行的命令）、recordset（数据源返回的记录集）；error 是数据源返回的错误信息，field 是 recordset 的列。
- ADO 一般流程：连接到数据源 → 给出命令及参数 → 执行命令 → 处理结果集 → 关闭连接。
- ADO 六大功能（独立创建对象、成批更新、支持带参数存储过程、不同游标类型、限制返回行数、多记录集）——可作次级考点。
- 钩子方向：三层链 "ADO → OLE DB → 数据库"；ADO 三成员 vs ODBC 四层 是天然混淆表。

## 候选3：连接类型分类与层次（内/等值/自然/θ/交叉）

- 出处：ch05 §5.1.3（行 87–97）+ §5.3.1–5.3.2
- 内容：连接 = 从两表广义笛卡儿积中选取满足条件的元组。层次：θ连接 ⊃ 等值连接（θ 为 =）⊃ 自然连接（等值连接去掉重复属性列，行+列两个角度运算）；交叉连接 = 笛卡儿积 = 非限制连接。图 5-3 层次图：F连接/θ连接/等值连接/自然连接。
- SQL 写法：`FROM 表1 [INNER] JOIN 表2 ON 表1.列=表2.列`；CROSS JOIN 不带 ON。等值连接结果 = 两表满足条件的交集部分；自然连接需去掉重复列且同名列引用要加表名前缀。
- 例题：例5.2（4 学生 × 3 专业 = 16 行笛卡儿积，8 列）、例5.28/5.29/5.30。

## 候选4：外连接三种——"外 = 保留没配上的"（★最强钩子区）

- 出处：ch05 §5.3.5（行 507–535），例5.32/5.33
- 内容：外连接结果集 = 满足连接条件的行 + 相应表不满足条件的行。左外连接保留左表没配上的行，右侧补 NULL；右外连接保留右表没配上的行，左侧补 NULL；完全外连接两边都保留。OUTER 关键字可省略。
- 例5.32/5.33 对照：`学生 LEFT JOIN 成绩` 保留 6 名无成绩学生（成绩列填 NULL）；换成 RIGHT JOIN 则这 6 人被舍弃、以成绩表为主体。
- 钩子方向：一句话——"内连接只留配上的，外连接把没配上的也留下来，缺的那一侧补 NULL"。

## 候选5：JOIN 实战写法——别名、ON、自身连接、复合条件、WHERE 改写

- 出处：ch05 §5.3.3/5.3.4/5.3.6，例5.31/5.34
- 内容：①自身连接必须给同一张表取两个别名（例5.31：教师任课 AS first/second，ON 教师编号相等 AND 专业代码不等）；②复合条件连接 = ON 后接多个条件（例5.34 三表连接 + 成绩 BETWEEN 70 AND 80）；③例5.34 可用 WHERE 多表写法等价改写（FROM 学生,课程注册,课程 WHERE ...）；④同名属性必须加表名前缀。
- 关联：ch05 §5.4 子查询与连接的替换关系（"某些嵌套查询可用连接运算替代，某些则不能"）——留给 D5/D6 不深挖。
