# C7 候选池（五池）— 编译预处理

来源：《高级语言程序设计（2017年版）》郑岩 ch09（原书 P297-307）。本章薄、无主干代码难题，但宏陷阱是必考点，未压缩源。

## 池1 核心概念池（I 候选）

- [K1] 预处理定位：编译预处理=对源程序进行编译**之前**，先处理各种预处理命令（以 `#` 开头的行），再将处理结果和源程序一起编译得目标代码。→ 不占运行时间。
- [K2] 三大预处理命令：宏定义（#define）、文件包含（#include）、条件编译（#ifdef/#ifndef/#if+#endif）。
- [K3] 无参宏：`#define 宏名 字符序列`；宏名是标识符（习惯大写）；宏定义不是语句，**行尾不能加分号**（分号会作为替换字符序列的一部分）。
- [K4] 宏替换=纯文本替换，预处理程序**不作任何语法/类型检查**；错误由编译程序在编译宏展开后的源程序时才发现。
- [K5] 双引号字符串内的字符即使与宏名重名，也不做宏展开。
- [K6] 宏作用域：从宏定义处（一般在函数外部/文件开头）到本文件结束；用 `#undef 标识符` 强制终止。
- [K7] 宏可层层引用已定义宏，展开是**逐层替换**（如 L=2*PI*R）。
- [K8] 宏定义的三大优点：提高可读性（符号常量 EOF/-1、NULL/0、MAX/31、STEP/2）、提高可修改性（一改全改）、避免重复书写。
- [K9] 有参宏：`#define 宏名(形参表) 字符序列`；宏调用 `宏名(实参表)`；实参可以是常量、变量或表达式；非形参字符原样保留。
- [K10] 有参宏的空格陷阱：宏名与左圆括号之间**不能有空格**，否则 `#define S (a,b)a*b` 中 S 被视为无参宏，`mul=S(x,y)` 展开为 `mul=(a,b)a*b(x,y);`。
- [K11] 有参宏不加括号陷阱：`#define S(r) 3.1415926*r*r`，`S(a+b)` → `3.1415926*a+b*a+b`（≠3.1415926*(a+b)*(a+b)）；正确写法 `#define S(r) 3.1415926*(r)*(r)`——**所有形参和整个字符序列都加括号**。
- [K12] POWER 对比例（书原文）：`#define POWER(x) ((x)*(x))`：a=4,b=6 时 POWER(a+b)=((4+6)*(4+6))=100；`#define POWER(x) (x*x)`：POWER(a+b)=(4+6*4+6)=34。
- [K13] MAX 例：`#define MAX(a,b) ((a)>=(b)?(a):(b))`，输入 23 56 输出 56；书中用 max(int x,int y){return(x>y?x:y);} 函数版对照。
- [K14] 文件包含：预处理时把被包含文件**整个内容复制**到 #include 命令出现的位置。
- [K15] include 两种格式差异：`"文件名"` 先到**当前源文件所在目录**找，找不到再到系统"包含文件目录"找；`<文件名>` **直接**到系统包含文件目录找。标准头文件用 `<>`。
- [K16] 一条 #include 只能包含一个文件；包含 n 个文件需 n 条命令。
- [K17] 头文件以 .h 为扩展名：用 scanf/printf 需 `#include <stdio.h>`；用 abs 需 `#include <math.h>`。
- [K18] include 允许嵌套（被包含文件内还可以再 include）；被包含文件内容改变后，所有包含它的源文件须**重新编译**。
- [K19] 条件编译：允许只对源程序一部分内容编译，不同条件产生不同目标程序；可提高可移植性，同一源程序产生不同版本（调试版/高效版）。
- [K20] 三种形式：#ifdef 标识符（已定义则编译程序段1）；#ifndef 标识符（**没**被定义则编译程序段1，与 #ifdef 功能相反）；#if 表达式（表达式非0则编译程序段1）。
- [K21] 条件编译 vs if 语句：不参加编译的程序段在目标程序中**没有对应代码**；if 语句无论真假全部产生目标代码。
- [K22] #if 的表达式在编译阶段计算值，**不能是变量**，必须是常量或 #define 定义的标识符（如 FLAG）。
- [K23] 有参宏 vs 有参函数四区别（书原文四条）：①函数先算实参值再传值，宏不计算实参、只做字符替换；②函数实参形参需定义类型且一致，宏形参无类型；③函数调用不使目标程序变长但每次调用占系统时间（现场保护/恢复），宏不占运行时间但每用一次目标程序变长；④函数调用需分配临时内存单元、进行值传递，宏展开不分配内存、不传值。

## 池2 例题池（A 候选）

- [E1] 【例9-1】宏逐层替换：PI 3.1415926, R 3, L 2*PI*R, S PI*R*R → length=18.85, area=28.27；展开后 L→2*3.1415926*3.0，S→3.1415926*3.0*3.0。
- [E2] 【例9-2】无参宏 PI 计算圆周长/面积/球体积；PI 改值只需改宏定义一处。
- [E3] 【例9-3】同一问题两种实现：宏 `#define MAX(a,b) ((a)>=(b)?(a):(b))` vs 函数 `int max(int x,int y){return(x>y?x:y);}`——宏 vs 函数的母题。
- [E4] 【例9-4】条件编译 LETTER 控制字母大小写转换（两段转换代码只留一段进目标程序）。
- [E5] 【例9-5】#ifndef TRANS + #if LETTER 双层条件编译改写例9-4。
- [E6] 习题·选择3：`#define P(x) x/x`，`printf("%d",P(4+6))` 输出 = 4+6/4+6 = **11**（未加括号陷阱+整除）。
- [E7] 习题·填空6：`#define WID 80`，`#define LEN WID+20`，`x=LEN*3` → 80+20*3=**140**（少括号陷阱计算题）。
- [E8] 习题·程序分析1：`#define A 4`，`#define B(x) A*x/2`，a=5，c=B(a) → 4*5/2=10，输出 **10.000000**（float）。
- [E9] 习题·程序分析3：`#define MAX(x,y,z) (x>y?(x>z?x:z):(y>z?y:z))`，a=3,b=4,c=5 → MAX(a,b,c)=5、MAX(a*b,b,b+a)=12、MAX(a,b+c,a*c)=15，输出 5,12,15。
- [E10] 习题·程序设计1：用有参宏求 m÷n 的余数；2：求两数之和的立方（必加括号）。

## 池3 题型池（T 候选）

- 填空：三种预处理命令名 / 预处理命令以 # 打头 / 宏定义行尾不加分号 / 宏作用域与 #undef / #ifdef 功能描述 / LEN*3 计算结果。
- 填空·宏展开计算：给宏定义+调用语句，写展开式或结果（K12、E6、E7、E8、E9）。
- 选择：宏名代替的是"字符串"（K4）；宏替换不检查类型、不占运行时间、宏名不必大写（大写只是习惯）；编译系统对宏命令的正式编译前处理。
- 改错：#define 行尾分号；宏名与左括号间空格；形参/整体缺括号；#if 用了变量。
- 简答：宏 vs 函数区别（四条垄断级考点）；预处理定位；条件编译 vs if 语句。
- 程序设计题（书中原题）：有参宏实现求余/立方。

## 池4 边界与失分池（B 候选）

- 宏名与左括号间空格 → 变成无参宏（K10），全句报废。
- 形参不加括号：S(a+b) 展开错（K11）；#define S(x) 类题若写 (x)^2 式的不对称括号同样错——括号必须成对且既包形参又包整体。
- 展开只替换不运算：不要试图在预处理阶段"先算宏参数的值"。
- 宏定义带分号：`#define PI 3.1415926;` → 展开成 3.1415926; 引发编译错。
- 字符串中的"宏名"不替换。
- 预处理阶段 vs 编译阶段混淆：#if 的表达式不能是变量；语法检查发生在预处理之后。
- include 双引号 vs 尖括号查找路径写反；一条命令包含多个文件。
- include 递归/重复包含：内容被展开多次导致重复定义或重复编译，需 #ifndef 展开件守护；被包含文件变化须重新编译（K18）。
- 条件编译配对错误（漏 #endif）；#ifdef 与 #ifndef 混用。

## 池5 钩子语料池（R 候选）

- 「宏是文本代打，没括号就是裸奔」——函数式宏每个形参+整体都要括号。
- 「宏是替换先治理，函数是治病后防守」——预处理在编译前完成替换；函数在运行时传值。
- 「#define 不加分号，分号是夹带的私货」。
- 「#include 双引号先串门（当前目录），尖括号direct直达官方（系统目录）」。
- 「#if 编译时算账，算不了变量」。
- 「不带括号的宏=考试送分陷阱，一改全改是它唯一的优点」。
