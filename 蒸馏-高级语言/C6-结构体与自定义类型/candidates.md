## 池1 概念池
| # | 候选 | 书锚 |
|---|---|---|
| K1 | 结构体类型定义三要素：①声明类型（struct 类型名 { 成员表 }；分号不能省）②用该类型定义变量/数组/指针 ③通过成员逐一赋值访问 | §8.1 P259 |
| K2 | 结构体类型是模板不占内存；定义变量时才按成员**定义顺序**依次分配内存 | §8.1 说明5 P259、例8-3 P261 |
| K3 | 成员类型可以是基本类型或构造类型；成员名可与程序变量重名，互不干扰 | §8.1 P259、§8.2 P264 |
| K4 | 嵌套定义：成员可为**已定义**的结构体类型；被嵌套类型必须先定义（date 必须在 person 之前） | §8.1 说明2、例8-2 P260 |
| K5 | 变量定义三法：间接定义法（先类型后变量，必须带类型名）/直接定义法（类型+变量同时，可再续用）/无名结构体（省略类型名，**此后无法再定义新变量**） | §8.2 (1)(2)(3) P262-263、例8-7 |
| K6 | 结构体定义位置：函数外→所有函数可用；函数内→仅本函数可用 | §8.1 说明4 P259 |
| K7 | 成员访问 "."：左侧必须是结构体**变量名或数组元素**，右侧是成员名；类型名.成员 是错的（std_info.sex ✗） | §8.2 一.1 P264 |
| K8 | 嵌套只能逐级访问到**最低一级**成员：student.birthday.year ✓；student.birthday 是结构体变量，一般不能整体引用 | §8.2 一.1 P265-266 |
| K9 | 结构体指针三等价：var.成员 ⇔ pointer->成员 ⇔ (*pointer).成员；(*p) 外圆括号不能省（* 优先级低于 .） | §8.4 一 P271 |
| K10 | -> 左侧必须是结构体变量/数组元素的**地址**或已指向的指针；优先级与 () [] . 同级，左结合 | §8.4 一.2 P271 |
| K11 | 结构体数组：每个元素都是结构体，三法定义同变量；初始化 {{…},{…}}；元素成员引用 = 数组名[下标].成员名 | §8.3 P267-268 |
| K12 | 指针指向结构体数组：p+1 指向**下一元素**而非下一成员；p->name ⇔ student[0].name；(p++)->name 先取值后移，(++p)->name 先移后取值 | §8.4 二 P273 |
| K13 | 自引用成员：成员类型可以是**本结构体类型的指针**（struct example *p ✓），不能是本结构体类型变量（struct example p ✗）——链表节点的雏形：数据成员 + next 指针 | §8.4 一、例8-14 P272、填空8 P288 |
| K14 | 函数间传递四法：全局变量 / 返回值（函数类型须为该结构体类型）/ 地址传递（高效）/ 值传递（整体复制、单向） | §8.4 三 P274-278 |
| K15 | typedef 四用法：①基本类型 ②数组类型（带长度）③结构体类型 ④指针型；只定义**类型别名**，不创造新类型、不定义变量 | §8.6 P282-284 |

## 池2 规则池（可出填空/判断的硬规则）
| # | 候选 | 书锚 |
|---|---|---|
| R1 | "." 是成员运算符，双目，优先级最高（与 () [] 同级） | §8.2 一.2 P264 |
| R2 | sizeof(结构体变量) = sizeof(该结构体类型) = **各成员字节数之和**（书内口径：char[20]+date12+long4=36） | 例8-3 P261 |
| R3 | 允许同类型结构体变量**整体赋值**（按成员顺序逐个复制）；除赋值外无其他整体操作 | §8.2 一.5 P265 |
| R4 | 不能对结构体变量整体输入/输出（printf("%d%s",student) ✗）；不能用 == / != 比较 | §8.2 一.3/一.6 P265 |
| R5 | 结构体初始化格式同数组：变量={初值表}；嵌套成员的初值是**子初值表**，初值类型须与成员一致 | §8.2 一 P263 |
| R6 | 成员地址：&变量.成员（普通成员）/ 数组成员名本身=首地址 / &成员数组[下标]；接它的指针类型须与该成员类型相同 | §8.2 一.2 P266 |
| R7 | 变量地址 &变量 只能存入**同一结构体类型**的指针变量；p=&student[0].name ✗（类型不符） | §8.2 一.3、§8.4 二 P266/273 |
| R8 | typedef 四步法：写变量定义体→变量名换新类型名→最前加 typedef→用新名定义变量 | §8.6 P282 |
| R9 | typedef 在**编译时**处理；#define 在**预处理时**做字符串替换——二者不同 | §8.6 说明2 P283 |
| R10 | 新类型名习惯大写但**非必须**（"必须大写否则编译错误"是错的说法） | §8.6、练习一.10 P287 |
| R11 | 值传递：形参是副本，函数内改形参**不影响**实参；地址传递：传地址，效率较高且可改实参 | §8.4 三、例8-19 P278、程序分析4 |
