# 操作系统 - 考试冲刺文档

## 考试题型
- 单选题（约20分）
- 填空题（约10分）
- 简答题（约30分）
- 应用题（约40分）

---

## 一、单选题高频考点

### 1. 基本概念
- 操作系统是**管理硬件、服务程序**的系统软件
- 操作系统的基本类型：批处理系统、分时系统、实时系统
- 操作系统的功能：处理机管理、存储器管理、设备管理、文件管理、用户接口

### 2. 进程管理
- 进程是**程序的一次执行过程**，是系统资源分配和调度的基本单位
- 程序是**静态的代码**，进程是**动态的执行**
- 进程的三种状态：**就绪、运行、阻塞（等待）**
- PCB（进程控制块）是进程存在的唯一标志
- 进程和程序的区别：进程是动态的、有生命周期；程序是静态的、可长期保存

### 3. 进程调度
- 高级调度（作业调度）：从外存选作业调入内存
- 中级调度（内存调度）：将进程换出到外存
- 低级调度（进程调度）：从就绪队列选进程分配CPU
- 常见调度算法：
  - FCFS（先来先服务）：简单，对短作业不利
  - SJF（短作业优先）：平均等待时间最短，但可能导致长作业饥饿
  - RR（时间片轮转）：适合分时系统
  - 优先级调度：可能导致低优先级饥饿

### 4. 进程同步
- 临界区：访问临界资源的代码段
- 同步：进程间的协作关系
- 互斥：进程间的竞争关系
- 信号量：用于进程同步的工具，P操作（wait）减1，V操作（signal）加1

### 5. 死锁
- 死锁的四个必要条件：互斥、占有并等待、不可剥夺、循环等待
- 处理策略：预防、避免、检测与恢复、忽略
- 银行家算法属于**避免**策略

### 6. 内存管理
- 逻辑地址（虚拟地址）：程序中使用的地址
- 物理地址：内存中的实际地址
- 地址重定位：将逻辑地址转换为物理地址
- 分页管理：将内存和进程地址空间分成固定大小的页
- 虚拟内存：让每个进程有独立的逻辑地址空间
- 页面置换算法：FIFO、LRU（最近最久未使用）、OPT（最佳）

### 7. 文件系统
- 文件的逻辑结构：有结构文件（记录式）、无结构文件（流式）
- 文件的物理结构：连续分配、链接分配、索引分配
- 目录结构：单级、两级、树形、无环图

### 8. I/O管理
- 程序查询方式：CPU主动查询，效率低
- 中断方式：设备主动通知CPU
- DMA方式：专门的控制器负责数据传输

## 三、简答题高频考点

### 1. 进程和程序的区别
- 进程是动态的，程序是静态的
- 进程有生命周期，程序可长期保存
- 进程可以并发执行，程序不能
- 进程是资源分配的单位，程序不是
- 一个程序可以对应多个进程

### 2. 进程的三种状态及转换
- 就绪 → 进程调度 → 运行
- 运行 → 时间片用完/高优先级进程到达 → 就绪
- 运行 → 等待I/O → 阻塞
- 阻塞 → I/O完成 → 就绪

### 3. 死锁的四个必要条件
1. 互斥：资源不能共享
2. 占有并等待：进程持有资源，又等待其他资源
3. 不可剥夺：系统不能强行收回资源
4. 循环等待：存在进程的循环等待链

### 4. 虚拟内存的实现原理
- 基于局部性原理
- 将进程的一部分装入内存，其余留在外存
- 当访问的页面不在内存时，产生缺页中断
- 从外存调入所需页面
- 如果内存满，按置换算法换出一页

### 5. 分页和分段的区别
| 分页 | 分段 |
|------|------|
| 物理单位 | 逻辑单位 |
| 页大小固定 | 段大小不固定 |
| 用户不可见 | 用户可见 |
| 一维地址空间 | 二维地址空间 |

## 四、应用题高频考点

### 1. 信号量与PV操作
生产者-消费者问题：
- 需要三个信号量：mutex（互斥）、empty（空位）、full（满位）
- 生产者：P(empty) → P(mutex) → 放入 → V(mutex) → V(full)
- 消费者：P(full) → P(mutex) → 取出 → V(mutex) → V(empty)

读者-写者问题：
- 读-读允许，读-写互斥，写-写互斥
- 第一个读者锁写者，最后一个读者解锁写者

### 2. 银行家算法
- 计算Need矩阵：Need = Max - Allocation
- 检查请求是否小于Need
- 试探分配
- 执行安全性算法，检查是否存在安全序列

### 3. 页面置换
- FIFO：置换最早进入内存的页面
- LRU：置换最近最久未使用的页面
- 计算缺页次数和缺页率

### 4. 磁盘调度
- FCFS：按请求顺序服务
- SSTF（最短寻道时间优先）：先服务离当前位置最近的
- SCAN（电梯算法）：先向一个方向服务到底，再反向

## 五、必背公式

1. **CPU利用率 = 1 - P^n**（P为I/O等待比例，n为进程数）
2. **缺页率 = 缺页次数 / 总访问次数**
3. **页号 = 逻辑地址 / 页大小**
4. **页内偏移 = 逻辑地址 % 页大小**
5. **物理地址 = 页框号 × 页大小 + 页内偏移**
