## V2 新题实测（书里没现成答案）

**新题 1（类型选型）**：设计"图书馆会员"表——会员号（13 位数字串，可能有前导 0）、姓名（≤4 汉字）、性别（男/女）、是否 VIP、押金（金额，精确到分）、办卡时间（精确到分）、累计借书量（0~255）。
→ 用 R2/R3/R4/R5/R8/R9/R10 可解：会员号 char(13)（数字串选型，X2 规则）、姓名 nchar(4)（汉字 unicode）、性别 nchar(1)、是否 VIP bit、押金 money、办卡时间 smalldatetime（精确到分够用）、累计借书量 tinyint。✅ 解出。

**新题 2（建库语句）**：建 teacher2 库：主数据文件初始 8MB、每次长 2MB、最大 80MB、放 D:\t2；日志文件初始 2MB、按 10% 增长、最大 20MB。
→ 用 F2/R12 可解：CREATE DATABASE teacher2 ON PRIMARY(NAME=teacher2_data, FILENAME='D:\t2\teacher2_data.mdf', SIZE=8MB, MAXSIZE=80MB, FILEGROWTH=2MB) LOG ON(NAME=teacher2_log, FILENAME='D:\t2\teacher2_log.ldf', SIZE=2MB, MAXSIZE=20MB, FILEGROWTH=10%)。✅ 解出。

**新题 3（存储估算）**：20000 行、每行 5000B 的表要多少空间、浪费多少？（ch03 练习题 5 后半问）
→ 用 R2 可解：每页 8060B 只装 1 行（5000×2=10000>8060），需 20000 页 ×8KB≈156MB；每页浪费 8060-5000=3060B，共浪费 20000×3060B≈58MB。✅ 解出（教材练习题无答案，本单元可复算）。

**新题 4（ALTER 改列）**：把"学生"表已有列"电话"从 char(8) 改为 varchar(15) 且不许为空。
→ 用 F4 可解：ALTER TABLE 学生 ALTER COLUMN 电话 varchar(15) NOT NULL。✅ 解出。
