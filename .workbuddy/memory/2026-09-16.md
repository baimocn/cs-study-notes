## 环境坑排查：WorkBuddy 报 `EPERM realpath '造物-数据库\db\自考题库.mdf'`
- **白墨现象**：客户端提示「部分会话资源加载失败：files: EPERM: operation not permitted, realpath '…\自考题库.mdf'」
- **根因（已核验，非猜测）**：该库被本机 SQL Server **实例 `MSSQL17.MSSQLSERVER`（sqlservr.exe PID 27512，服务账户 `NT Service\MSSQLSERVER`）以 ONLINE 状态独占持有** → 客户端索引工作区时对每个文件调 `fs.realpath`，被内核拒绝 → Node 映射为 EPERM
- **证据链**：
  1. `sys.master_files` 查到 `自考题库 | ROWS | D:\Desktop\计算机科学与技术\造物-数据库\db\自考题库.mdf | ONLINE`（.ldf 同），`sys.databases` 状态 `ONLINE / FULL / MULTI_USER`
  2. 文件属性 = 普通 `Archive`，**ReparsePoint=False**（排除符号链接/联接）
  3. `db` 目录 ACL 可读正常；**但 `icacls 自考题库.mdf` 报"拒绝访问"**、`.NET File.Open(…,'None')` 报"访问被拒绝" → 独占句柄特征（非 sharing violation）
  4. 两文件各 8388608 字节 = SQL Server 数据文件默认初始大小，佐证为在线库
  5. sqlcmd 连接串需 `-C`（信任证书，ODBC 18 默认强制加密）；拼字符串会撞排序规则冲突，需 `COLLATE Latin1_General_CI_AS_KS_WS`
- **影响**：对数据库**零影响**（库正常 ONLINE）；对工作区仅为一条噪音告警，不波及其他文件
- **⚠ 真实风险（非告警本身）**：数据文件放在**桌面工作区内**，SQL Server 官方不建议（用户 profile 权限继承 + 桌面/磁盘清理工具易误碰，白墨正好在做 D 盘整理）
