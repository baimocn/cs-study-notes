# GLOSSARY — 高级语言（C）判据词表（2017 年版教材口径）

判据钩子 = "看到 X 就判对/判错"的一眼判据。定义以教材/SKILL.md 口径为准。
**口径总标签**：凡涉 int 字节数的词条（标注【双口径】），教材长度表按 VC++6.0/32 位 int=4，教材例题/步进示例沿用 TC/16 位 int=2——题干显式给字节数按题干判，未给则考试按教材例题口径。

## 基础与类型（C1）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 最小程序骨架 | `#include <stdio.h>`（行首 #，末尾无分号）→ `int main(void)`（函数首部无分号）→ 函数体 `{}` → 语句以 `;` 结尾 | "printf 是 C 语言关键字"→错，是库函数调用；"`}` 后也加分号"→错，锅沿不收汁 |
| 整型四兄弟【双口径】 | char 1 < short 2 < int 4 = long 4 < double 8，float 4 站中间（VC++6.0/32位口径）；16 位 TC 下 int=2、unsigned int=2 | "int 永远 4 字节"→错，题干给"16 位 PC/TC"必须换挡 int=2；sizeof(int) 是运算符不是函数 |
| 常量三前缀 | 光头=十进制；0 开头=八进制（只许 0~7）；0x 开头=十六进制 | 0189 出现在整型常量→必错（八进制不收 8/9）；0123=83、0x123=291 |
| 'a' vs "a" | 'a' 是字符常量 1 字节（97）；"a" 是字符串 'a'+'\0' 占 2 字节 | 字符串都是贪吃蛇，长度 n 占 n+1 节："China" 6 字节不是 5；`''` 非法、`""` 合法占 1 字节 |
| 转义字符 | `\` 打头：\n 换行、\t 横跳、\0 空字符（值0≠空格32）、\\ \' \" 三逃生；\101（八进制）='A'、\x46='F' | \81 非法——八进制帮派不收 8；'0'(48) ≠ '\0'(0) ≠ 0 |
| ++ 钉前后 | `++i` 钉前先加后用；`i++` 钉后先用后加；`i+++j` 贪心蛇从左吞出最长合法算符 →(i++)+j | 操作数是常量/表达式（3++、--(−i)）→非法，++/-- 只吃变量 |
| 同变量双副作用 | `(i++)+(i++)` 教材按"先引用后自增、从左到右"给唯一答案（例3-14：值 5、i 终 4）；真机（C 标准）未定义行为 | 选项出现"结果不确定/有歧义"→优先选教材例题同型值；考试按教材顺序口径写 |
| 优先级天梯 | 括号1 > 单目2 > 乘除模3 > 加减4 > 移位5 > 大小6 > 等不等7 > & 8 > ^ 9 > \| 10 > && 11 > \|\| 12 > ?: 13 > 赋值14 > 逗号15 | "10<<3+1"→160（+ 先于 <<）；唯一右结合三家：单目、?:、赋值系——从右往左啃 |
| 短路闸门 | && 左假即停（右支不执行）；\|\| 左真即停 | `0&&(++a)` → a 冻住不变；`(m=a>b)&&(n=a>b)` 左假后 n 保持原值 |
| 赋值与类型转换 | 运算就高不就低（char/short→int→unsigned→long→double，float 必先升 double）；赋值就左不就右，长存短砍高位直接截断，不四舍五入 | int a=99.1 → 99（丢小数）；【双口径】long 65536→int：教材例题口径 k=0（16位砍高 16 位），32 位口径 k=65536 |
| (float)5/2 vs (float)(5/2) | 强转括号圈住谁、谁先被转：先转 5 再除=2.5；先整除再转=2.0 | 强转不改原值：`f=(float)i` 后 i 仍是 2 |
| % 两禁 | 两侧必须整型；余数符号随被除数 | 4.0%2 非法；-4%3=-1、4%-3=1 |
| 位运算四件套 | & 留位、\| 置位、^ 翻位、~ 全反；左移补 0，右移无符号补 0、有符号补符号位 | 取低 4 位用 `x&0x0F`；248>>2=62 |
| 补码 | 正数三码合一；负数取反加一（绝对值原码→反码→+1），内存里整型一律住补码 | unsigned 65535+1 → 环绕回 0（教材 unsigned 0~65535 口径） |
| 逗号两副面孔 | 参数表/定义表里是分隔员；"表达式1,表达式2"整体出现才是运算符，取最后一个 | `a=2,3` 先 a 被 2 占坑；`(a=2,3)` 才让 a=3 |
| sizeof | 运算符（不是函数）；变量名可省括号、类型不可省【双口径】 | "sizeof int 合法吗"→非法；sizeof(3.14)=8（double 口径） |

## 控制流（C2）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| else 就近配对 | else 归"离它最近、还没被认领的 if"；缩进只是视觉效果 | 想改判——加花括号；教材例4-17 是最佳反面教材（else 挂错层漏判 2000 年） |
| switch 穿堂风 | case 只是入口标号不做判断，命中后一路穿透到 break；case 后必须常量表达式且值互不相同 | 漏 break→从命中 case 吃到楼底（含 default）；多 case 共用一组语句合法 |
| break vs continue | break 砸穿一层；continue 只废本次——for 中跳去表达式 3（i++ 照走），while/do-while 跳回条件 | "continue 后循环变量还加吗"→for 中加；"嵌套循环中的 break 跳到哪"→只跳最内层 |
| do-while | 先干活后验收，起码跑一次；while(表达式) 后的分号必须写 | "至少执行一次"→do-while；漏尾分号直接编译错 |
| while 空体死循环 | `while(条件);`/`for(...);` 分号让循环体变空语句 | while(i=0) 一次不执行（赋值恒0）；while(i=1) 恒真死循环 |
| for 三段式 | 初值；门槛；步子——两个分号不能省；省表达式2=永远真=死循环（须体内 break/goto/return 兜住） | for 省表达式3 → 体内必须自己修控制变量 |
| 累加器/累乘器 | 累加初值必须 0，累乘初值必须 1 | 填空把初值行挖空——fact=1 还是 =0 一眼定生死 |
| 表格跟踪法 | 行/步跟踪变量值：行高=内层层数；continue 记 "C→"（for 跳表达式3）、break 记 "B→" 划掉本层剩余行 | 判停三问：条件是 <= 还是 <？条件里 i++ 何处生效？体内有无 continue/break？ |
| 增量条件自增点 | `while(i++<4)` 比较用旧值、i 先加 → 结束后 i=5 | "循环结束后 i 的值"= 条件最后一次判假时已被自增过的值 |

## 数组与字符串（C3）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 下标从 0 | int a[3] 合法引用 a[0]~a[2]；a[n] 永踩界——它是 a[n-1] 后面那格，值不确定 | "数组下标越界系统给出出错信息"→错，系统不检查；二维"第 1 行"=代码第 0 行 |
| 定义 vs 引用的方括号 | 定义时 `int a[10]` 10 是长度（整型常量表达式、int a[n] 变量→错）；引用时 a[i] 的 i 可变量 | `int a[n]`（n 变量）定义→错；`a[i]` 引用→对 |
| 初始化补 0 | 定义时部分赋值，未给的数值型补 0、字符型补 '\0'；初值个数>长度→编译错 | `int a[4]={1,2}` → {1,2,0,0}；完全未初始化 int a[5]=(垃圾值) 不是 0 |
| 二维画格法 | 元素按行优先连续存；分行/不分行初始化结果相同；只能省行长不能省列长 | 行长=初值个数÷列长（除不尽再加 1）；`a[i][2-i]` 逐个 i 代入画副对角线，别惯性代主对角线 |
| 数组名=焊死的门牌 | 数组名是首地址**常量**：不可赋值、不可自增（`a++`、`a="abc"` 全错）；scanf("%s",str) 不加 & | `str1==str2` 比的是地址不是内容；比内容必须 strcmp |
| '\0' 尾巴 | 字符串常量末尾自动加 '\0'，占 1 字节不算有效字符；%s/strlen 都停在第一个 '\0' | `char c[3]={'a','b'}` → 补出尾巴恰好成 "ab"；`char d[5]={'a','b','\0','d','e'}` 实串只有 "ab" |
| strlen vs sizeof | strlen=从第 0 格数到第一个 '\0' **前**（不含尾巴）；sizeof=数组定义总长（省长度定义=有效字符+1） | `char a[]="happy"`：strlen=5、sizeof=6；`char str[7]="program"` ✗（7+1=8 装不下） |
| scanf %s vs gets | scanf("%s",str) 遇空格或回车断、自动补 '\0'、str 前不加 &；gets(str) 只认回车、可含空格 | 读带空格整行用 gets；gets/scanf %s 混用交接题（C3-E1 母题）看"谁结尾" |
| puts vs printf %s | puts 输出后把 '\0' 换成换行；printf %s 不换行可一次多个 | puts(s) 自带换行；自定义过滤字母后必须补 `str[j]='\0'`——忘补尾巴是最常见丢分 |
| strcmp/strcpy/strcat | strcmp 逐字符比 ASCII，相等返 **0**；strcpy 连 '\0' 一起复制；strcat 掉原尾巴接新串留一个 '\0' | "字符串能用 = 整体赋值"→错，只能 strcpy 复制 |

## 函数与作用域（C4）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 首部 vs 声明 | 函数定义首部末尾**不**加分号；函数声明（原型）末尾加分号、可省形参名 | "int max(int,int); 是定义"→错，是声明；定义在主调函数之前可免声明 |
| 传值=复印件 | 形参是普通变量时实参被复制一份，函数内怎么改实参毫发无损（例6-6 输出 12 不是 21） | 值传递=单向；"函数能否交换两个 int 实参"→值传递办不到 |
| 传址=房钥匙 | 实参传数组名/地址时形参实参共享同一片内存（教材："数据的共享"）；形参数组一维长度可省 | `void f(int a[])` 内改 a[i]= 改实参 sco[i]；二维形参 `a[][4]` 第一维可省、**第二维不能省** |
| static 复读机 | static 局部变量只在第一次调用时执行初始化，以后每次进来用上次的值；未初始化自动 0 | auto 局部=一次性纸杯（未初始化随机值）；static+循环调用逐次列表：上次退出值→本次退出值 |
| return 单程票 | 只能捎回**一个**值、只能从被调捎回主调；函数不能嵌套定义但能嵌套调用，main 不能被调用 | "return 返回两个值"→错；想带回多个结果→传地址或全局变量 |
| extern 声明 | `extern int a;` 是**声明**已定义的全局变量（可多次、可在函数内）；定义必须在函数外且只能一次 | extern ≠ 定义新变量；跨文件：B 定义、A extern 声明 |
| 重名屏蔽 | 局部变量作用域内全局同名变量被屏蔽；出作用域恢复 | 班牌盖住校牌——函数内同名取局部，函数外恢复全局 |
| 递归两要素 | ①出口条件 ②递推式；缺出口→无限递归 | 栈表法四步：列表头→下行压栈→回代→核对出口与递减方向配套（期 n==1 出口遇 n 从 0 起递减=失控） |
| 形参四禁 | 形参按普通内部变量对待：不能加 static、不能是表达式；形参是自动分配的普通变量 | "形参可以是表达式"→错（实参才可以）；"static 形参"→非法 |

## 指针（C5，命门单元）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 指针=存门牌的变量 | 指针变量存**地址**；变量地址=起始门牌号 | `p=3000;` 整数当地址→错（唯一例外 0/NULL）；`double *p=&a` 而 a 是 int→类型必须一致 |
| & 与 * 互逆 | & 查门牌（取地址，对象须是已定义变量/数组元素）；* 按门牌进门（解引用，对象须是地址） | `&a`（数组名取址）错、`&a[i]`（元素取址）对；`p=&a[8]` 对、`p=a[8]` 错 |
| 两个星号分离 | `int *p,i;` 里 * 是**声明标记**（变量名是 p 不是 *p）；`*p=3;` 里 * 是解引用动作 | 判据口诀：左边查身份（声明），右边查动作（解引用） |
| `*p` 改家具，`p` 换门牌 | `*p=3` 动的是所指那户；`p=&y` 只换记门牌、原屋不动 | `*p=3` 后 p 不变成 3；swap3 换形参指针本身=实参 9,12 不动 |
| 指针运算边界 | 允许 p±n、p++/p--、同类型指针相减（=**元素个数**非字节差）；禁止指针相加/乘除/赋整数 | px=&str[4],py=&str[2] → px-py=2；把 2 答成字节差=掉陷阱 |
| p+1 跨一户【双口径】 | 指针加减按**元素个数**步进，字节数=元素大小：教材 TC int=2 示例 3000+1→3002；32 位口径 +1 加 4 字节 | 步进只对连续空间（数组）有意义；遇 scanf("%s") 未赋值的指针=野指针，进门就砸（原书明确"运行时出错"） |
| 三胞胎（四行反例） | `*p++`≡*(p++)：取旧值、p 后移；`(*p)++`：所指内容+1、p 不动；`*++p`≡*(++p)：p 先移、取新值；`++*p`≡++(*p)：内容+1、p 不动 | int a[]={5,6,7},*p=a：x=*p++ → x=5、p 指 a[1]；x=(*p)++ → x=5、**a[0] 变 6**、p 不动——表达式值同，动了 p 还是动了 a[0]，下一句分道扬镳 |
| 四等价 | p 指一维数组首地址时：a[i] ≡ *(a+i) ≡ p[i] ≡ *(p+i) | *(a+i) 合法（a 是地址常量）、a++ 非法；方法三第二遍循环前必须 p=&s[0] 重新归位否则越界 |
| 指针数组 vs 数组指针 | int *p[4]：[] 优先级高，4 个元素各是指针；int (*p)[4] 书仅选项级提及 | [] 先于 *：先 [] 后 *=装指针的数组 |
| swap 三兄弟 | swap1 值传递换复印件无效；swap2 `*px` 进门换家具有效；swap3 换各自门牌（也是复印件）无效 | 结论（原书）：被调函数不能改实参指针变量，**能**改实参指针所指向的变量；调用处必须给地址 swap(&x,&y) 或指针变量 |
| 字符串指针 vs 字符数组 | char *p="abc" ✓（p 存串首地址）；char a[80]; a="abc" ✗（数组名常量）；数组存串本体、指针只存门牌 | 未赋值指针接输入 → 野指针；p-s 是指针减法=元素个数（例7-2 串长=7） |
| FILE* vs char*（对偶） | 文件指针指向文件结构体，不自增；字符指针可 p++ 逐字符走 | fp 的位置移动交给 fgetc/fseek；别把 fp 传给 strlen/strcpy |

## 结构体与预处理（C6+C7）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| 结构体三要素 | ①声明类型（`struct 名 {成员表};` 分号不能省）②定义变量（三法：先类型后变量/同时/无名）③逐成员赋值访问 | 无名结构体之后不得以"struct 名"续用；类型名≠变量名（std_info.sex 判停） |
| . 走变量、-> 走地址 | `.` 左边站变量本人；`->` 左边站指针/地址；等价式 p->成员 ≡ (*p).成员，圆括号不能省 | `*p.sex` ✗（`.` 优先级高于 `*`，先算成 p.sex）；混用即判停——最高频失分点 |
| 能抄不能比 | 同类型结构体可整体赋值 s1=s2 ✓；整体比较/整体输入输出 ✗ | `s1==s2` 判错；数组成员输入不加 &（s2.name 本身就是地址）、字符串成员必须 strcpy |
| 结构体指针步进 | p+1 走**一个元素**；`(p++)->name` 先取 stu[0].name 后移；`(++p)->name` 先移再取——顺序反答案反 | 与三胞胎同构的"取完搬家 vs 先搬再取"结构体版 |
| typedef 发别名 | 按定义变量写一遍→变量名换新名→最前加 typedef；四用法：基本类型/数组/结构体/指针；不造新类型、不定义变量 | typedef vs #define：前者编译时处理能定义类型别名；后者预处理时字符串替换 |
| 值传递复印件（结构体版） | 形参结构体是副本，函数内改副本实参不动（例8-19 时序 27,3,30→18,5,23→27,3,30）；要真改传 &arg 配 `q->a` | "函数不能返回结构体"→错（返回结构体合法）；自引用成员只能是本类型指针（链表节点雏形） |
| 宏=文本代打 | #define 纯字符替换、不做任何检查、不占运行时间；行尾不加分号；双引号里的"宏名"不替换；#undef 随时终止 | `#define PI 3.14159;` 分号被当替换字符展开→编译错 |
| 双括号铁律 | 有参宏：宏名与左括号间**不能有空格**；所有形参+整个字符序列均加圆括号 | POWER(x) x*x 版：POWER(a+b)→a+1*a+1=34 ✗；((x)*(x)) 版=100 ✓——没括号就是裸奔 |
| 空格陷阱 | `#define S (a,b)a*b`：S 与括号间有空格 → S 成无参对象宏，(a,b) 一并进替换串 | 看到"宏名后空格+括号"→按无参宏处理，展开 mul=(a,b)a*b(x,y); |
| 宏计算三步法 | ①找目标写宏定义原文 ②实参**原样文本**塞进形参位置（禁止提前求值）③套 C1 优先级求值 | `LEN*3`（LEN=WID+20）→ 80+20*3=**140** 不是 300 |
| 宏 vs 函数四区别 | 函数先求实参一次、有类型检查、目标程序不变长、调用占运行时间；宏不求实参（文本塞入，副作用可能重复求值）、无类型、字符串替换目标程序变长、不占运行时间 | 求最值：宏 MAX(j,k) vs 函数 max(--i,k)——宏版 --i 可能被求值两次 |
| 三大预处理命令 | 宏定义 #define、文件包含 #include（"" 先查当前目录再查系统目录；<> 直达系统目录）、条件编译 | "预处理命令只能位于文件首部"→错（函数外任何位置）；一条命令只含一个文件 |
| 条件编译 | #ifdef 已定义选段1 / #ifndef 未定义选段1（方向相反）/ #if 表达式非 0 选段1 且**编译阶段**求值不能是变量；都靠 #endif 收尾 | #ifdef 与 #ifndef 方向写反→全错；没被选中的段在目标程序里**根本没有代码**（区别于 if 全产生代码） |

## 文件（C8）

| 术语 | 定义（教材口径） | 判据钩子（一眼判对错） |
|---|---|---|
| C 文件=流式文件 | 字符（文本）/字节（二进制）序列，不是记录序列；ANSI C 只用缓冲文件系统 | 缓冲区没满不落盘→**必须 fclose** 否则尾部数据丢失 |
| fopen 六模式 | "读 r 写 w 添 a 追加，加 + 能读写，加 b 变二进制"：r 文件必须已存在（不存在报错返 NULL）；w 清空重来（自动创建）；a 尾巴接着写（自动创建）；+ 只合并读写权限不清空豁免 | 修改非空文件选 "r+"；"写操作后原有数据必定被覆盖"→错（a 追加不覆盖）；新二进制只写文件="wb" |
| 读写对偶表 | fgetc↔fputc（1字符）/ fgets↔fputs（1串）/ fread↔fwrite（数据块）/ fscanf↔fprintf（格式化）——返回值也成对 | 判据口诀：中间是干什么的、前面给地址、最后给 fp——唯 fscanf/fprintf 的 **fp 排第一位** |
| fseek 头 0 腹 1 尾 2 | 起点参数：0=SEEK_SET 文件头、1=SEEK_CUR 位置、2=SEEK_END 文件尾；位移量 long（常数写 -2L/5L、表达式 (long) 强转） | `fseek(fp,-20L,2)`=从尾前移 20 字节；`fseek(fp,20L,2)` 出界非法；第 n 条记录=(n-1)*sizeof 定位 |
| rewind | 拨回文件头 ≡ fseek(fp,0L,SEEK_SET)；rewind 只动指针不写数据 | 顺序读到尾后想重读必须 rewind（例10-10 唯一考点）；"rewind 能向文件写数据"→错 |
| EOF vs feof | EOF 是符号常量 -1，文本文件判尾；feof(fp) 到尾返回**非 0**，二进制必须用它 | fclose 成功返回 **0**（与多数函数相反）；fputc 成功返回**刚写入的字符**不是 1；fscanf 成功返回读入数据个数 |
| fopen 判 NULL | 标准写法 `if((fp=fopen(...))==NULL)` 整体赋值表达式比较 | 写成 `if(fp=fopen(...))` 逻辑反了还丢判据；路径 `\` 必写 `\\` |
| 文本 vs 二进制 | 文本按 ASCII 存（占空间多、有转换开销、可显示）；二进按内存原样存（省空间省时间、不能直接显示） | int a=10000：文本=5 个 ASCII 字节、二进制=原样字节；两格式互不兼容、读回模式配错全乱 |
| 三个标准设备文件 | stdin/stdout/stderr 系统自动开自动关，不许 fopen/fclose；可用作现成 fp（如 fputs(s,stdout)） | fputs 写文件舍 '\0' 不换行（想要换行自己 fputc('\n',fp)）；puts 才把 '\0' 换 '\n' |
| w 清空 vs a 追加 | 程序分析秒杀链第一问：第一段用 w/w+ 不管原件有什么全清空；写完没关又用 a/a+/r+ 打开内容保留 | `a+` 指针在尾（读需先 rewind）；`r+` 指针在头；没有 rewind 第二次读从上次停处继续 |
