## C1 四种备份类型：各自备份什么 —— 通过

**V1① 书中原表述**（§11.4.2，OCR 已修，"数据库备份一完整"的一=破折号）：
①完整备份：包括所有的数据以及数据库对象；过程是先将事务日志写到磁盘上，再根据事务创建相同的数据库、数据库对象并复制数据；速度慢、占空间大，常安排在晚间；未完成事务及备份过程中发生的事务不备份；从备份开始到还原开始之间的修改无法还原。②差异备份：将最近一次数据库备份以来发生的数据变化备份起来，实际上是一种增量数据库备份；数据量小、备份还原时间短；增加差异次数可降低丢失风险，但无法像事务日志那样提供到失败点的无损失备份。③事务日志备份：对数据库发生的事务进行备份，包括从上次事务日志备份、差异备份和完全备份之后所有已完成的事务；空间与时间开销远小于数据库备份；可还原到失败前一点；还原时必须有一个完整数据库备份且按顺序重放。④文件和文件组备份：对数据库文件或文件组进行备份；仅还原损坏的文件/文件组故还原快；还原时要求有自上次备份以来的事务日志保证一致性，故文件备份后应再进行日志备份。

**V1② 教学重构**：**完整=全家福（数据+对象全拍）；差异=只拍新来的（相对最近一次完整备份的变化增量）；日志=监控录像（记动作，可逐帧回放到失败点）；文件/文件组=按房间拍（单间受损单间修，但必须配日志录像保证一致性）。**

**V2 新题**：周一 0:00 做完整备份，周三 0:00 做差异备份，周三 12:00 数据库损坏。差异备份里包含周一周二写入的数据吗？为什么？
自答：包含。差异备份针对"最近一次数据库备份"（周一 0:00 的完整备份）以来的全部变化——周一周二的变化都在其中，不因周二是否另有备份而重置；差异基准只在新的完整备份后归零。✅ 可迁移，正中"差异=增量"语义。

**V3'**：极高。练习题 5 原题（"数据备份的类型有哪几种？适合什么样的数据库？为什么？"）；四类型"各自备份什么"是填空/选择/简答通吃的主干考点。

## C2 完整备份链与还原顺序 —— 通过

**V1① 书中原表述**（§11.4.2 之 2、3，OCR 已修）：还原综合方案时"先还原最近一次的数据库备份，接着进行差异备份的还原，最后进行事务日志备份的还原"。使用事务日志还原时"必须有一个完整的数据库备份，而且事务日志备份还原时必须按一定的顺序进行"——如上周末做完整备份、周一到周末每天一次日志备份，还原时"首先还原数据库备份，然后按照顺序还原从周一到周末的事务日志备份"。若希望还原到失败时刻且能访问事务日志文件，先备份当前活动事务日志，再按上述顺序还原。

**V1② 教学重构**：**还原必须从全家福开始放——完整备份是链条第一环；差异接在完整之后（跳过中间各份差异，只取最近一份）；日志按录制顺序逐盘连放、一环不跳。口诀：完整打底 → 最近差异 → 依序日志。**

**V2 新题**：日志备份 L1、L2、L3 按时间生成，还原时能否只还原 L3？能否先 L2 后 L1？
自答：都不能。日志还原必须以完整备份打底，且必须按备份顺序（L1→L2→L3）重放；跳过 L1（无完整打底）或颠倒顺序（L2 先于 L1）都会失败——日志重放是顺序依赖的。✅ 可迁移，正中 R2。

**V3'**：极高。练习题 7 应用题的得分骨架；"还原第一步做什么"是常见选择/填空；"日志不能单独恢复"是判断题陷阱。

## C3 三种恢复模式与备份配置的对应 —— 通过

**V1① 书中原表述**（§11.4.3，OCR 已修）：三种还原模式——简单还原（Simple Recovery）：还原时仅使用数据库备份或差异备份，不涉及事务日志备份，只能还原到上一次备份的状态，无法还原到失败点；常用备份策略=先数据库备份、后差异备份。完全还原（Full Recovery）：通过数据库备份和事务日志备份将数据库还原到失败时刻，几乎不造成数据丢失，是对付存储介质损坏的最佳方法；SELECT INTO、创建索引等批操作都写入日志；策略=完整备份+差异备份+事务日志备份；要还原到失败点必须对失败前正在运行的事务进行备份。批日志还原（Bulk-logged Recovery）：性能优于前两者，尽最大努力减少批操作（SELECT INTO、批装载、创建索引、WRITETEXT/UPDATETEXT 等）所需日志空间；备份策略与完全还原基本相同。

**V1② 教学重构**：**模式决定你能回到哪——简单=回到上一次快照（日志不留档，认赌服输）；完全=回到失败那一秒（日志全留档）；批日志=完全的省空间版（批操作少记，备份配方同完全）。模式与配方一一对应：简单↔完整+差异；完全↔完整+差异+日志。**

**V2 新题**：银行转账系统要求故障后不丢任何已提交转账，应选哪种恢复模式？若选错为"简单"，事故后果是什么？
自答：完全还原（Full Recovery）——只有它配合日志备份能把数据库还原到失败时刻。若选简单模式：只利用数据库/差异备份，只能回到最近一次备份时刻，两次备份之间提交的转账全部丢失，且无法恢复到失败点。✅ 可迁移。

**V3'**：极高。练习题 6 原题（"提供了哪几种数据库恢复方式"）；模式↔策略搭配是简答高频；英文名对照是填空点。

## C4 练习题 7 型崩溃恢复应用（含活动日志尾）—— 通过

**V1① 书中原表述**（§11.4.2 之 2）：多数情况下希望还原到失败时刻，方法：①如果能够访问数据库事务日志文件，则应备份当前正处于活动状态的事务日志；②还原最近一次数据库备份；③还原最近一次差异备份；④按顺序还原自差异备份以来进行的事务日志备份。如果无法备份当前正在进行的事务，只能还原到最后一次事务日志备份的状态，而不是数据库的失败点。

**V1② 教学重构**：**崩溃恢复四步：先抢录像（备份活动日志尾）→放全家福→放最近的"新来的"→依序放录像。抢不到录像（日志文件已毁）→止步于最后一次日志备份，4:50 前的几分钟数据认损。**

**V2 新题**（书外新题，同练习题 7 结构变体）：周日 0:00 完整、每天 0:00 差异、每小时日志；周四 9:35 崩溃且日志文件完好。写出还原序列。
自答：①备份当前活动事务日志（9:00 后的尾）；②还原周日 0:00 完整备份；③还原周三 0:00 差异备份（最近一次）；④依序还原周四 0:00、1:00、2:00…9:00 的日志备份；⑤应用第①步的日志尾，前滚到 9:35。数据零损失（未提交事务除外）。✅ 可迁移，比练习题 7 多走一步"应用日志尾"。

**V3'**：极高。练习题 7 是本章计算型应用题独苗，"先备份活动日志"这步是最大失分点（漏答即丢顺序分）。

## C5 备份过程约束与系统数据库备份 —— 通过

**V1① 书中原表述**（§11.4.1、§11.5.1 之 2，OCR 已修）：支持在线备份，可一边备份一边其他操作；但备份过程中不允许：创建或删除数据库文件、创建索引、执行非日志操作、自动或手工缩小数据库或数据库文件；操作正在进行时启动备份则备份被终止，备份中执行则操作失败而备份继续。备份或还原中断可从中断点重新开始。需定期备份的系统数据库：master、msdb、model；不可能备份 tempdb——每次启动实例时重建，关闭时永久删除其中所有数据。

**V1② 教学重构**：**备份期间"动结构"全被拉黑（建删文件、建索引、收缩）；tempdb 是"一次性草稿纸"——开机新领、关机销毁，无东西可备。要备的是三本"户口册"：master（服务器户口）、msdb（任务调度）、model（新建库的模板）。**

**V2 新题**：为什么 tempdb 不能备份？某DBA 坚持每晚备份四个系统数据库，错在哪？
自答：tempdb 在实例每次启动时重建、关闭时永久删除全部数据，不存在可备份的持久内容，备份无意义；错在 tempdb——需备份的系统数据库只有 master、msdb、model 三个。✅ 可迁移，正中 R7/X3。

**V3'**：中高。"三个可备一个不可备"是填空/判断点；备份四禁操作是简答次高频；杀伤力真实但频率低于 C1-C4。

## C6 导入导出工具定位与操作要点 —— 通过

**V1① 书中原表述**（§11.9，OCR 已修）：导出/导入都在 SSMS 右键数据库→任务→"导出数据/导入数据"，打开"导入和导出向导"：先选数据源（如 SQL Server Native Client 11.0 + 服务器 + 库），再选目标（如 Microsoft Excel + 文件路径），然后选"复制一个或多个表或视图的数据"或"编写查询以指定要传输的数据"，勾选源表，必要时"编辑映射"调整列映射，执行完成。导入时数据来源表结构要与库中相应表结构一致，不一致须在"列映射"对话框详细设置否则导入出错。注意：数据导出导入功能只在企业版或开发版才有，且必须安装至少 SP1 补丁。

**V1② 教学重构**：**一句定位：导入导出=在"源"和"目标"之间搬数据（SQL Server↔Access/MySQL/Excel 等多种数据库和文件），向导管路线，列映射管对接。备份是"自救"（生成 .bak 只能被 RESTORE 读），导入导出是"外交"（换成别人能读的格式）——.bak 与 .xls 是两种完全不同的产物。**

**V2 新题**：要把 student 库的"学生"表交给同事用 Excel 做统计，应该用备份还是导入导出？产物各是什么？
自答：用导出（导入和导出向导：源=student 库→目标=Microsoft Excel→勾选"学生"表→执行）。产物是 .xls 文件，Excel 可直接打开。若用备份，产物是 .bak 备份文件，只能经还原进入另一台 SQL Server，Excel 无法读取。✅ 可迁移，正中"备份≠导入导出"辨析。

**V3'**：中低但真实。选择/判断点："导出向导能选哪些目标""源表结构不一致怎么办""企业版限制"；教材对 DTS 着墨少，按"定位一句+操作要点"保留，不展开。
