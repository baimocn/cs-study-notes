## I 骨架池

1. 数组 = 相同类型有序数据集合；元素=同类型变量；先定义后使用。
2. 定义四要素：类型符 / 数组名（标识符规则）/ 长度=整型**常量**表达式（int a[n] n为变量→错）/ 方括号是语法不是可选项符号。
3. 下标从 0 起：合法范围 0 ~ 长度-1；**a[n] 非法**；系统不检查越界（L51-53、例5-2、单选3 答案C）。
4. 数组占连续内存；字节数=长度×每元素字节数（short a[3] → 6 字节，图5-1）。
5. 引用：数组名[下标]；下标可整型常量/变量/表达式（填空1：从 0 开始；单选12：a[5] 对，a[10]/a[-1]/a[5*3]=a[15] 越界）。
6. 数组是整体不能整体参与运算、不能整体赋值（x={…}、x[4]={…}、x=y 全错，L138-144）；**数组名=首地址常量，不可赋值**（填空2）——C5 铺垫，不展开。
7. 初始化规则：
   - 全部赋初值→长度可省 `int a[]={1,2,3,4}`；
   - 部分→其余数值型=0、字符型='\0'（`int a[4]={1,2}`→{1,2,0,0}）；
   - 初值个数>长度→编译错（`int a[4]={1,2,3,4,5}` 错）；
   - 未初始化定义→**垃圾值**（double c[6] 无初值，无默认 0）；
   - 数组名不可赋值（R-3）。
8. 二维数组：
   - 定义 [行长][列长]，元素个数=行×列；**按行优先存放**（L343-344）；
   - a[i][j] 的一维位置 = i*n+j（m 行 n 列，行、列号从 0）；
   - 可视作“元素是一维数组的数组”（x[0]/x[1]/x[2] 各是长 4 的一维数组）；
   - 越界：a[3][4]、a[0][4]、a[3][0] 非法（例5-10）；
   - 初始化：分行 {{1,2,3},{4,5,6}} / 不分行按行优先 {1,2,3,4,5,6} / 部分赋值未给=0 / **省行长不省列长**（int a[][4]=…→行长=初值个数÷列长度，有余数加1，教材 L451-457）/ 分行部分赋值也可省行长（{{1},{2,3}}→2 行）。
9. 字符数组与字符串（\0 拿捏·红线独立条目）：
   - 字符串末尾自动加 '\0'，占 1 字节但不计入有效字符；
   - 数组长度 ≥ 字符个数+1：char str[8]="program" ✓，char str[7]="program" ✗（L604-605“定义为5在[刀则会出错”OCR 修复为 str[7]）；
   - 三种等价写法：{'p',…,'\0'} / {"program"} / "program"（L607-610）；
   - 字符方式部分初始化未给值='\0'（char c[3]={'a','b'} → c[2]='\0'，**恰好构成字符串 "ab"**，L630-632）；
   - 中途遇 '\0' 即截断：char d[5]={'a','b','\0','d','e'} → 实际字符串 "ab"（L633-636）；
   - 定义后不能 str="abc" 整体赋值，只能 strcpy（L621-624）。
10. 字符串 I/O 差异表：
    - scanf %s：遇**空格或回车**即结束；自动补 '\0'；**str 前不加 &**（数组名已是地址，L754-759）；printf("%s") 遇 '\0' 停（str[10]="123\0ab\0ef" → 输出 123，L775-777）；
    - gets：**仅回车**结束，可含空格；gets 保证数组足够大（L794）；
    - puts：输出后 '\0' 换成 '\n'（自动换行）；一次一个串；printf %s 不自动换行、一次可多个（L807-810）。
11. string.h 五函数：strcpy（连 '\0' 一起复制，覆盖原内容）/ strcat（去掉被连接串的 '\0'，新串末尾留一个）/ strcmp（逐字符按 ASCII 比，==0 相等；**禁止 str1==str2、禁止关系运算符**）/ strlen（**不含 '\0'**）/ strlwr / strupr（均需 #include <string.h>）。
12. strlen vs sizeof（教材 L933-936 换算 + 填空5/单选7）：
    - char str1[10]={"China"} → strlen=5（有效字符数，不含'\0'），sizeof=10（数组定义长度）；
    - char a[]="happy" → 占 6 字节（5+1）；
    - int a[5]={0,2,4} → 占 10 字节（5×2），strlen 不适用（非字符数组）。
13. 数组名 vs 指针（C5 边界，此处只一句）：数组名是**地址常量**，不能被赋值或自增；指针变量是可以被赋值的地址变量——完整边界表在 C5。

## A1 例题池（书中例题，≥2 段原样带出）

- **例5-4** 一维数组赋值逆序输出：for(i=0;i<=9;i++) a[i]=i; for(i=9;i>=0;i--) printf("%d ",a[i]); → `9 8 7 6 5 4 3 2 1 0`
- **例5-7 冒泡排序**：外层 i: 1~n-1（共 n-1 轮），内层 j: n-1→i 每轮 n-i 次，相邻比较 a[j] 与 a[j-1]，前大后小则交换。
  ```c
  for (i=1; i<=n-1; i++)
    for (j=n-1; j>=i; j--)
      if (a[j] < a[j-1])
      { temp=a[j]; a[j]=a[j-1]; a[j-1]=temp; }
  ```
  输入 23 56 89 41 63 → 输出 23 41 56 63 89。
- **例5-8 选择排序**：外层 i: 0~n-2；k=i 起记录最小值下标，内层 j=i+1~n-1 若 a[j]<a[k] 则 k=j；轮末 if(k!=i) 交换 a[i] 与 a[k]。
- **例5-11 矩阵转置**：x[3][4] → y[4][3]，y[j][i]=x[i][j]，双重 for 外行内列。
- **例5-12 学生成绩统计**：float score[M][N]（M=5 学生，N=4 门），行累加求个人平均、列累加求课程平均——二维数组“按行按列”双向遍历的标准模板。
- **例5-18 字符数组过滤**：双下标 i/j，字母前移 str[j++]=str[i]，末尾补 str[j]='\0'——“j 是新串尾巴计数器”范式。
- **例5-19 子串计数**：外层扫主串，内层逐字符比对子串，substr[k+1]=='\0' 即命中一次。
- **例5-20 strcmp 分支 + strcat**：res=strcmp(str1,str2)，>0 则 strcat(str2,str1) 否则 strcat(str1,str2)。

## E 考场步池

- **二维数组题·画格法**：
  1. 抄下定义 `int a[3][3]={…}`；数初值个数；
  2. 按行优先顺序往格子里填数，**填完有效初值，剩余格全填 0**（部分初始化）；
  3. 省行长时：行长 = 初值个数 ÷ 列长度（有余数 +1）；
  4. 题目问 a[i][j] → 在第 i 行第 j 列的格子里读值（**第 0 行是第 1 行**，行、列号都从 0 数）；
  5. 涉及 a[i][2-i] 等表达式 → 逐个 i 代入画对角线；
  6. 判停：格子填完且每问都有格子可读 → 写答案，不再心算。
- **字符数组题·尾巴步**：
  1. 写下数组内容，**末尾画一个明确的 '\0' 格**；
  2. strlen：从第 0 格数到**第一个 '\0' 前**，不含 '\0'；
  3. sizeof / 内存：数到定义长度（省略长度 = 有效字符 +1）；
  4. printf %s / puts：从第 0 格打印到**第一个 '\0'** 停（'\0' 后面的内容全忽略）；
  5. 判停：第一个 '\0' 位置圈出来，三个问题（strlen/sizeof/%s输出）都用这同一位置回答 → 停。
