## I 知识骨架 + 钩子

### 骨架（五层）
1. 三种基本结构：顺序、选择、循环——任何复杂程序只靠这三者组合、嵌套。
2. 选择结构：if（单分支）→ if-else（双分支）→ 嵌套/else-if 链（多分支）→ switch（多分支直配）。
3. 循环结构：while（当型）、do-while（直到型）、for（次数型）；goto+if 也能凑循环但不提倡。
4. 循环控制：break 终止整个本层；continue 只终止本次。
5. 嵌套规则：内层必须完整包在外层体内，不许交叉，允许并列。
6. 等价转换：switch 实现的多分支完全可用 if/嵌套 if 实现；while 循环是 for 省去
   表达式1、表达式3 的简化形式——三者可互相改写，考题爱问"等价改写后输出是否相同"。

### 钩子（背这五句，考试直接兑现）
- **else 就近配对**：else 归"离它最近、还没被认领的 if"；想改判，加花括号。
- **break 中层跳不穿**：break 只砸穿一层，外层循环照转。
- **do-while 起码跑一次**：先干活后验收；while 先验收，可能一次不干。
- **switch 不加 break 是穿堂风**：从命中的 case 入口一路穿到楼底。
- **for 三段式"初值；门槛；步子"**：两个分号不能省；门槛（表达式2）省了=永远真=死循环。

## A1 书中例题（已验证，含指正）

### 例1 例4-17 闰年（嵌套 if + else 配对）
```c
int year, leap = 0;
scanf("%d", &year);
if (year % 4 == 0) {
    if (year % 100 != 0) leap = 1;      /* 教材嵌套版：见下方指正 */
}
else {
    if (year % 400 == 0) leap = 1;
}
if (leap) printf("%d is a leap year.", year);
else      printf("%d is not a leap year.", year);
/* 正确紧凑版：if((year%4==0 && year%100!=0) || year%400==0) ... */
```
> **指正（不假夸）**：教材嵌套版对整除 400 的年份（如 2000）误判为平年——else 挂在
> 外层 if 上，只有 year%4!=0 才进 else，此时 year%400==0 永远不成立。正确写法是把
> 内层 if-else 整体放进外层 if 之内。这恰是"else 就近配对"的最佳反面教材。
> 考点：leap 旗标法（0/1 两态）+ 逻辑优化。

### 例1.5 例4-18 象限判断（else 配对的正面示范）
```c
if (x > 0)
    if (y > 0) printf("1st quadrant\n");     /* 内层 if */
    else       printf("4th quadrant\n");     /* 这个 else 配内层 if（就近） */
else
    if (y > 0) printf("2nd quadrant\n");
    else       printf("3rd quadrant\n");
```
> 考点：两个 else 都按"就近未配对"规则各归其主，缩进只是视觉效果不参与配对；
> 若想让 else 配外层，必须给内层加花括号。边界提醒：x==0 或 y==0 时该程序仍会
> 落进某一分支（如 x=0,y=5 输出 2nd quadrant），数学上坐标轴不属于任何象限——
> 程序未处理退化情形，读程序题遇到 x=0 输入要按**分支走向**作答而不是按数学定义。

### 例2 例4-20 月份天数（switch 标准型）
```c
switch (month) {
    case 1: case 3: case 5: case 7:
    case 8: case 10: case 12: days = 31; break;   /* 多 case 共用一组 */
    case 4: case 6: case 9: case 11:  days = 30; break;
    case 2: if ((year%4==0 && year%100!=0) || year%400==0) days = 29;
            else days = 28;  break;               /* case 内嵌 if 也要 break 收口 */
    default: printf("month is error\n");
}
printf("year=%d,month=%d,days=%d\n", year, month, days);
```
> 考点：case 入口标号不判断、共用语句组、default 位置无关、case 2 内嵌 if-else 后
> 仍需 break。教材运行示例疑为输入 2049,2（"23"系 OCR 混入，见 verified.md 三-3）。

### 例3 例4-27/4-29/4-30 三循环对照
```c
/* while：先判后执行，n=1 时条件 n<=100 先成立才累加，sum=5050 */
int n = 1, sum = 0;
while (n <= 100) { sum += n; n++; }

/* do-while：先执行后判断，尾部分号必须 */
do { sum += n; n++; } while (n <= 100);

/* 首判区别：条件一开始为假 n<1 ——
   while 版：循环体 0 次，sum=0；do-while 版：循环体 1 次，sum=1 */

/* do-while 实战（例4-30 逆序输出）：123 → 321 */
do { r = i % 10; printf("%d", r); i /= 10; } while ((i / 10) != 0);
```
> 考点：循环控制变量必须在循环前赋初值；n++ 既更新累加项又使循环趋于结束。

### 例4 例4-35 百钱百鸡（双重循环穷举）
```c
for (x = 1; x <= 20; x++)            /* 公鸡最多 20 只 */
    for (y = 1; y <= 33; y++) {      /* 母鸡最多 33 只 */
        z = 100 - x - y;             /* 鸡雏由约束推出，三重降二重 */
        if (z % 3 == 0 && 5*x + 3*y + z/3 == 100)
            printf("cock=%d,hen=%d,chicken=%d\n", x, y, z);
    }
/* 教材输出 3 组解：(4,18,78)(8,11,81)(12,4,84) */
```
> **指正**：枚举起点 x=1、y=1 漏掉解 (0,25,75)；若允许不买公鸡/母鸡，完整解 4 组。
> 考点：穷举变量上界由方程推出（x≤20、y≤33）、降维思想。

### 例5 例4-37 素数（嵌套 for + break 只跳内层）
```c
for (i = 11; i <= 100; i += 2) {     /* 步长 2 只扫奇数，外层 45 次 */
    for (j = 2; j <= i - 1; j++)
        if (i % j == 0) break;       /* 只跳出内层！ */
    if (j >= i) {                    /* 素数：内层自然耗尽后 j==i */
        printf("%6d", i);
        if (++counter % 10 == 0) printf("\n");
    }
}
```
> 考点：break 后 j<i、素数时 j==i 的"自然耗尽"判定；11~97 共 21 个素数，每 10 个换行。

## A2 触发题型（★=高频）
- ★**读程序写结果**：switch(赋值表达式) 判入口；do-while+continue 计数；for+break+continue
  混合跟踪；while vs do-while 首判对照。→ 配套题见 test-prompts.json trig-01~05。
- ★**程序填空**：补 if 条件（闰年/被 11 和 13 同时整除）、补循环体（累乘器 fact*=i;
  sum+=fact;）、补循环条件（(ch=getchar())!='\n'）。→ trig-06/07。
- ★**改错**：switch 漏 break 穿透；while 头后多分号变死循环；do-while 尾分号缺失；
  break 写在循环/switch 之外。→ trig-08/09。

**填空题补空三板斧**（程序填空的通用拆法）：
1. 空在 if( ) 里 → 回读题目要求的"输出 yes 的条件"，翻译成关系/逻辑表达式；
   "同时整除"= 两余数都为 0 用 && 连接：`num%11==0 && num%13==0`。
2. 空在循环体里 → 先认循环使命：累加填 `s+=…`，累乘填 `fact*=…`，计数填 `n++`；
   累乘器初值必须为 1，累加器初值必须为 0（填空常把初值行挖给你补）。
3. 空在循环条件里 → 找"结束标志"：读字符到换行填 `(ch=getchar())!='\n'`，
   读数到 0 填 `i!=0`；注意 != 与 == 别写反，写反直接变死循环或一次不跑。

## E 考场步骤★：表格跟踪法（现场照搬）

**适用**：一切"读程序写结果"的循环题，尤其嵌套循环。

1. **抄判停条件**：把"继续循环的条件"原样抄在草稿表头。盯死两处：是 `<=` 还是 `<`；
   条件里的自增/自减是在判断**前**还是**后**生效（如 `i++<4` 先比较后自增）。
2. **定列**：每层循环的控制变量各占一列 + 循环体内会变的变量各占一列 + 一列"动作/走向"。
   **行高=内层层数**：两层嵌套时，外层每转 1 轮，下面挂内层的 N 行（内层每迭代一次记一行）。
3. **一行一步**：每行只执行一次循环体迭代，改哪个变量就动哪格，其余照抄上行。
4. **标记跳转**：遇 continue 写"C→"（for 跳去表达式3，i++ 照走；while/do-while 跳回条件）；
   遇 break 写"B→"（跳出本层，把本层剩余行全部划掉）。
5. **抄输出**：printf 在循环体内→逐行抄；在循环外→只抄终值一次。
6. **判停**：条件列一旦为假即停；for 先判表达式2 再决定是否执行体（体可能一次都不跑）。

**示范**（trig-03 题源：`for(i=1;i<=3;i++) for(j=1;j<=i;j++){ if(j%2==0) continue; s+=i*j; } printf("%d,%d\n",i,s);` 循环外再打印 s）

| 步 | i | j | j%2 | s | 走向 |
|---|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 1 | s+=1，j++ |
| 2 | 1 | 2 | — | 1 | j=2>1 内层止 → 打印 **1,1** |
| 3 | 2 | 1 | 1 | 3 | s+=2，j++ |
| 4 | 2 | 2 | 0 | 3 | C→j++ |
| 5 | 2 | 3 | — | 3 | 内层止 → 打印 **2,3** |
| 6 | 3 | 1 | 1 | 6 | s+=3，j++ |
| 7 | 3 | 2 | 0 | 6 | C→j++ |
| 8 | 3 | 3 | 1 | 15 | s+=9，j++ |
| 9 | 3 | 4 | — | 15 | 内层止 → 打印 **3,15**；i=4 门槛假，全停 |

终输出：`1,1` `2,3` `3,15`，最后 `s=15`。

**判停三问**（动笔前自检，防 80% 的跟踪失分）：
1. 继续条件里是 `<=` 还是 `<`？差一个等号，循环次数差一轮，输出全变。
2. 条件中的 `i++` / `++i` 何时生效？`while(i++<4)` 比较用旧值、i 先加；`while(--x>0)` 先减再比。
3. 循环体内有没有 continue/break？有→第 4 步的标记动作必须执行，不能只算变量。

**switch 穿透速判**（读程序写结果的 switch 题专用，30 秒出答案）：
1. 先算 switch(表达式) 的值——表达式里若有赋值/比较混合（如 `a=b==c+1`），先按
   C1 优先级算出值再入场。
2. 拿该值找 case 入口；找不到入口看有没有 default。
3. 从入口开始**无视所有 case 标签**一路往下抄语句，直到撞见 break 才收笔。
4. 输出 = 沿途抄到的所有 printf 的拼接，顺序即代码顺序。
   例：`switch(a=b==c+1)` 中 b==c+1 先算（== 优先级高于 =），a 得 1，命中 case 1，
   执行 d=1 后遇 break 收笔 → 输出 1。

## B 边界★：失分点清单 + 跨单元边界表

### 失分点清单（考前最后一遍）
1. **while(i=0)**：赋值不是比较，值恒 0 → 循环体一次不执行；while(i=1) 恒真死循环。
2. **for 头多分号**：`for(i=0;i<10;i++);` 循环体是空语句，后面的 {} 只执行一次。
3. **switch 漏 break**：从命中 case 穿透执行后续所有 case 和 default；case 后必须是常量
   表达式（不能含变量），各 case 值必须互不相同。
4. **do-while 尾分号**：while(表达式) 后的分号必须写，漏了直接编译错。
5. **continue 的去向**：for 中跳到表达式3（i++ 照常执行）；do-while 中跳到尾部条件判断。
6. **嵌套只跳一层**：break/continue 只作用于包含它的最内层循环/switch。
7. **多条语句不加花括号**：if/else、循环体的复合语句必须花括号，否则只管第一条。
8. **while 头后分号**：`while(条件);` 循环体变空语句 → 死循环（与 2 同族，位置不同）。
9. **switch 嵌套的 break 归属**：内层 switch 的 break 只跳内层；内层执行完后若想不再
   穿透外层 case，必须再写一个 break（例4-21 中 case 'A' 内嵌 switch 后的 break 就是干这个的）。
10. **goto 慎用**：goto+if 可凑循环（例4-26 sum=5050），但结构化设计主张限制使用，
    卷面上"滥用 goto 导致可读性差"是标准扣分话术。
11. **for 省段后的责任转移**：省表达式3 → 循环体内必须自己修正控制变量；省表达式2 →
    体内必须有 break/goto/exit()/return，否则死循环。

### 跨单元边界表
| 邻单元 | 判据（怎么分流） | 例 |
|---|---|---|
| C1 表达式求值 | 只问表达式的值/短路/自增次序 → C1；问"循环执行几次/输出什么" → C2 | `while(i++<4)` 跑几次=C2；`i++<4` 本身怎么求值=C1 |
| C4 函数递归 | 出口条件+自调用 → C4；同一问题若用循环改写 → C2 | 阶乘 for 版=C2，递归版=C4；递归出口≈判停条件 |
| C5 指针作参数 | scanf(&x) 取地址、循环内传址改实参 → C5；循环结构本身 → C2 | `while(...){scanf("%d",&i);}` 的 &i 归 C5，循环骨架归 C2 |
