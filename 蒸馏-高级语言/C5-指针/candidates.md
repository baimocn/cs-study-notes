## P1 概念定义池

- C-01【核心】指针是一种数据类型；指针是存放数据的内存单元的地址。P222
- C-02【核心】内存按字节编号，编号即"地址"；变量占多字节时，第1字节的地址 = 变量地址（起始地址）。P222
- C-03【核心】直接访问：按变量名查符号表得地址直接存取；间接访问：通过指针变量取得地址再存取（书中"甲乙丙"类比——候选中记录，钩子改用"门牌号"操作化表述，不用故事隐喻）。P222-223
- C-04【核心】指针变量 = 专门存放其他变量地址的变量。定义格式：`数据类型符 *指针变量名[=初始地址值],…;` P224
- C-05【核心】声明中的 `*` 只标记"p 是指针变量"，只对紧邻的那一个变量名起作用：`int *p,i;` 中 i 是普通 int 变量。P224（"指针变量必须在其名字前使用 *，指针变量名是 p 而不是 *p"P225）
- C-06【核心】"数据类型符"不是指针自身存放数据的类型，而是其所指向变量/数组的类型；类型必须一致：`int a; double *p=&a;` 错。P224
- C-07【核心】指针变量可存放变量、数组、函数的地址（数组和函数在内存连续存放）。P223
- C-08【核心】数组名 = 地址常量（数组首地址）；指针变量 = 地址型变量（值可变）。P229。→ 钩子候选："数组名是焊死的门牌，指针是拿在手里的门牌"
- C-09【核心】指针变量初始化可用：已定义变量的地址、已初始化的同类型指针变量、0 或 NULL。0 是唯一可直接赋给指针变量的整数；NULL 表示不指向任何地址。P224-225
- C-10【备】指针变量的作用：程序简洁高效、表示复杂数据结构、动态分配内存、获得多于一个的函数返回值。P222（第四点与 C4 swap 呼应）
- C-11【备·判据】二级指针：书正文未讲解，仅练习单选第8题 D 选项出现 `int **p;`（用于与指针数组 `int *p[4]`、`int (*p)[4]` 辨析）。→ 不展开讲，只保留辨析判据。
- C-12【备·判据】void*：书未出现 void* 相关内容。→ 淘汰，不引入（红线：书无勿引入）。
- C-13【核心】指针数组：元素均为指针的数组，格式 `数据类型符 *数组名[长度];`；因 [] 优先级高于 *，先成数组再与 * 结合。P244
- C-14【备】指针型函数：返回值是指针（地址）的函数，函数名前加 `*`；只能用指针变量/指针数组元素接收返回值，不能用数组名接收。P242-243
- C-15【备】`char s[][10]`（二维字符数组，每行10字节，存字符串本体）vs `char *nation[]`（指针数组，每元素只存一个字符串首地址）。P245

## P2 规则运算池

- R-01【核心】& 取地址运算符：单目、右结合；对象必须是已定义的变量或数组元素，**不能是数组名**（&a 错）。P226-227
- R-02【核心】* 指针运算符：单目、右结合；对象必须是地址（已赋值指针变量/变量地址/数组元素地址），不能是整数或非地址变量；`*p` 代表 p 所指向的变量本身（左值右值都行）。P226-227
- R-03【核心】& 与 * 互逆。设 int x,*p=&x：`*&x`✓（=x）、`*&p`✓（=p）、`&*p`✓（=&x）；`&*x`✗（x 不是指针）。P227 例7-4
- R-04【核心】给指针赋值：只能赋地址型表达式（&变量、&数组元素、数组名、同类型指针、NULL/0）；`p=3000;` 错——C 不允许把整数当地址。P225
- R-05【核心】指针法 vs 下标法四等价（p 指向一维数组首地址）：`*(p+i)` ≡ `*(a+i)` ≡ `p[i]` ≡ `a[i]`。前两种指针法，后两种下标法。P229
- R-06【核心】指针 ± 整数：实际移动 `n*sizeof(类型)` 字节。书例：int 指针 3000，+1 → 3002（**教材口径 int=2字节**）；char 指针 2000 +1→2001；float 指针 2000 +1→2004。P229/P232-233
- R-07【核心】数组名不能 ++ / --（地址常量）；指针变量可以。P229、P245（指针数组名同理不能自增自减）
- R-08【核心】指针可进行的算术运算仅 4 类：p±n、p++/++p、p--/--p、同类型指针相减 p1-p2（结果是**数据元素个数**不是地址差，如 int *px=&str[4],*py=&str[2]，px-py=2，py-px=-2）。指针与整数乘除无意义，p1+p2 无意义。P232-233
- R-09【核心】关系运算：同类型指针可比较（前者小后者大，判断指向前后）；与 NULL 比较判断是否空指针；不指向同一数组的两指针比大小无实际意义。P233
- R-10【核心·三胞胎】* 与 ++/-- 优先级相同、从右至左结合：
  - `*++px` / `*(++px)`：先 px+1，再取新地址内容
  - `*px++` / `*(px++)`：先取 px 当前内容，再 px+1
  - `++*px` / `++(*px)`：px 所指**内容**加1，px 不动
  - 同理 `*--px`、`*px--`、`--*px`
  （书 P233 明确列出全部条目）
- R-11【核心】指针作函数参数：传递本质仍是**值传递**（传的值是地址），形参与实参指向同一变量；被调函数**不能改变实参指针的值**，但**能改变实参指针所指向的变量的值**。P238-240
- R-12【核心】形参为指针变量时实参必须是地址表达式（&a、数组名、指针变量名）；形参是数组名时也接收首地址——形参/实参 4 种组合（数组名/指针变量两两搭配）本质相同。P240
- R-13【核心】字符串指针赋值：`char *p; p="abc";` ✓（把串首地址给 p，不是把字符串给 p）；同一指针可先后指向不同字符串。P234
- R-14【核心】用 %s 输出指针：从所指字符起逐个输出直到 '\0'；其他类型数组不能 `printf("%d",array)` 整体输出。P234-235
- R-15【备】指针数组元素用法：赋值 `p[i]=地址表达式`、引用 `*p[i]`、参与算术/关系运算。P244
- R-16【备】例7-20/7-21 综合用法：`scanf("%d",p+i)`、`*(a+j)>*(a+j+1)` 冒泡、指针遍历 `for(;p<s+N;p++)`。

## P3 易错陷阱池

- T-01【核心】野指针/未初始化：指针变量定义后其值不确定，**必须先赋值后使用**。`char *p; scanf("%s",p);` ✗ 运行时出错——p 没指向任何已分配空间。正确：`char str[10],*p=str; scanf("%s",p);` P225、P237
- T-02【核心】声明 vs 解引用两个 * 含义分离：`int *p,i;` 里 * 是声明标记；`*p=3;` 里 * 是解引用取内容。P224
- T-03【核心】越界不检查：`short a[20],*p=a;` 则 `*(p-1)`、`*(p+20)`、`p[-1]`、`p[20]` 语法全对、值不确定；写越界会破坏其他内存。P229-230
- T-04【核心】swap 三兄弟（例7-12）：swap1（值传递，交换形参副本，实参不变）；swap2（`temp=*px;*px=*py;*py=temp;` 交换所指内容，实参真交换）；swap3（`temp=px;px=py;py=temp;` 只交换形参指针的指向，实参 a、b 不变）。P238-240
- T-05【核心】字符串赋值差异：`char *p; p="...";`✓ vs `char a[80]; a="...";`✗（数组名是地址常量不能整体赋值）。P237
- T-06【核心】字符指针 vs 字符数组三区别：①存储内容：数组存字符串本体，指针只存首地址；②赋值方式：指针可整体赋串，数组只能定义时初始化；③数组名常量不可变，指针变量可变。P236-237
- T-07【核心】& 不能作用于数组名（R-01）但数组名本身可直接赋给指针（`p=a;`✓）；&*x 当 x 非指针时错（R-03）。
- T-08【备】`int *pointer=array, array[10];` 错——赋初值时数组尚未定义（先定义后使用）。P229
- T-09【备】指针型函数返回地址只能由指针变量接收，数组名不能接收。P243
- T-10【备】`p3=a; l=*p3;` 中 *p3 代表 a[0]；*(p+0) 即 *p。P227
- T-11【备】三胞胎陷阱延伸：`(*px)++` 改的是内容；`*px++` 改的是指针。读程序题最大失分点。
- T-12【备】scanf 配套：`scanf("%d",&num)` 里 & 不可丢；用指针时可写 `scanf("%d",p)`（p 已指向 num）或 `scanf("%d",s+i)`（指向数组元素时）。
- T-13【备】指针减法结果是元素个数（带符号），不是字节差——填空题陷阱。
- T-14【备】教材口径 int=2 字节（R-06），现代编译器 int=4 字节；考试步进题以题干给定类型和字节数为准，答题前先确认元素大小。

## P5 题型考法池

- Q-01【核心·读程序写结果】三胞胎：`*p++` vs `(*p)++` vs `*(p++)`——如练习程序分析题1（q=&a[1]; for(i=0;i<5;i++,q++) printf("%6d",*(q+i));）P252；练习填空6/8（(*p)+? ++(*p) 值）。
- Q-02【核心·读程序写结果】swap 判别：练习单选12（fun(&y,&x) 先打印 2 1 再改 x,y → 4 3）、单选13（swap3 型只换指向 → 3 6）。P251
- Q-03【核心·写函数】编写 void swap(int *p1,int *p2) 交换所指整数（练习程序设计题3）；字符串连接 strncat(str1,str2)（设计题2）。
- Q-04【核心·填空】声明 vs 解引用左右值：& 的对象必须是____；* 的对象必须是____（填空1）；p=&a[8] 写法（填空3）；指针作参数传递方式是____传递（填空10）。
- Q-05【核心·单选】指针数组辨析：`int *p[4]` vs `int (*p)[4]` vs `int *p` vs `int **p`（单选8）；char str[] 与指针的叙述对错（单选14）。
