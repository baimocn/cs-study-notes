# 人工智能与大数据导论 - 考试冲刺文档

## 考试题型
- 单选题（约20分）
- 填空题（约10分）
- 简答题（约40分）
- 论述题（约30分）

---

## 一、单选题高频考点

### 1. 人工智能基本概念
- 人工智能（AI）：让机器模拟人类智能的技术
- AI的三大学派：符号主义、连接主义、行为主义
- 图灵测试：判断机器是否具有智能的标准

### 2. 机器学习
- 机器学习：让机器从数据中学习规律
- 监督学习：有标注数据（分类、回归）
- 无监督学习：无标注数据（聚类、降维）
- 强化学习：通过试错获得奖励

### 3. 监督学习算法
- 线性回归：预测连续值
- 逻辑回归：二分类
- 决策树：基于规则的分类
- 支持向量机（SVM）：寻找最优分隔超平面
- K近邻（KNN）：基于距离的分类
- 朴素贝叶斯：基于概率的分类

### 4. 无监督学习算法
- K-Means聚类：将数据分成K个簇
- 主成分分析（PCA）：降维
- 关联规则：发现数据中的关联

### 5. 深度学习
- 神经网络：模拟人脑的计算模型
- 激活函数：ReLU、Sigmoid、Tanh
- 反向传播：训练神经网络的算法
- 卷积神经网络（CNN）：图像处理
- 循环神经网络（RNN）：序列数据处理
- 生成对抗网络（GAN）：生成新数据

### 6. 大数据
- 大数据的4V特征：Volume（量大）、Velocity（高速）、Variety（多样）、Value（价值密度低）
- 分布式计算：多台电脑一起干
- Hadoop：分布式存储和计算框架
- Spark：基于内存的计算框架
- MapReduce：分布式计算模型

### 7. 自然语言处理（NLP）
- 词嵌入：将词转换为向量
- 文本分类：情感分析、垃圾邮件检测
- 机器翻译：自动翻译
- 问答系统：自动回答问题

### 8. 计算机视觉
- 图像分类：识别图片中的物体
- 目标检测：定位图片中的物体
- 图像分割：将图片分成不同区域
- 人脸识别：识别图片中的人脸

## 三、简答题高频考点

### 1. 人工智能的定义和发展阶段
- 定义：让机器模拟人类智能的技术
- 发展阶段：
  - 第一次浪潮（1956-1970）：符号主义，专家系统
  - 第二次浪潮（1980-2000）：连接主义，神经网络
  - 第三次浪潮（2010至今）：深度学习，大数据驱动

### 2. 监督学习和无监督学习的区别
| 监督学习 | 无监督学习 |
|---------|-----------|
| 有标注数据 | 无标注数据 |
| 分类、回归 | 聚类、降维 |
| 需要人工标注 | 不需要人工标注 |
| 例：垃圾邮件检测 | 例：用户分群 |

### 3. 深度学习的优势
- 自动提取特征，不需要人工设计
- 能处理非结构化数据（图像、语音、文本）
- 随着数据量增加，性能持续提升
- 可以迁移学习，复用已有模型

### 4. 大数据的关键技术
- 分布式存储：HDFS、GFS
- 分布式计算：MapReduce、Spark
- 数据仓库：Hive
- 实时处理：Storm、Flink
- NoSQL数据库：MongoDB、HBase

### 5. 神经网络的基本结构
- 输入层：接收数据
- 隐藏层：提取特征（可以多层）
- 输出层：输出结果
- 激活函数：引入非线性
- 权重和偏置：可学习的参数

### 6. 卷积神经网络（CNN）的特点
- 局部连接：每个神经元只连接输入的一部分
- 权重共享：同一个卷积核在不同位置共享权重
- 池化操作：降低特征维度
- 适合处理图像数据

### 7. 大数据的应用场景
- 电商推荐：根据用户行为推荐商品
- 金融风控：识别欺诈交易
- 医疗健康：疾病预测、药物研发
- 智能交通：交通流量预测、自动驾驶
- 城市管理：智慧城市、公共安全

### 8. 人工智能的伦理问题
- 算法偏见：训练数据不均衡导致的歧视
- 隐私保护：个人数据的收集和使用
- 责任归属：AI决策的责任由谁承担
- 就业影响：自动化对就业市场的影响

## 四、论述题高频考点

### 1. 人工智能对社会的影响
**正面影响：**
- 提高生产效率
- 改善生活质量
- 推动科技创新
- 解决复杂问题

**负面影响：**
- 就业结构变化
- 隐私安全风险
- 算法歧视问题
- 伦理道德挑战

### 2. 大数据时代的机遇与挑战
**机遇：**
- 数据驱动的决策
- 个性化服务
- 新的商业模式
- 科学研究的新方法

**挑战：**
- 数据安全和隐私
- 数据质量问题
- 技术人才短缺
- 法律法规滞后

### 3. 深度学习的发展趋势
- 模型越来越大（GPT、BERT）
- 应用越来越广（医疗、自动驾驶）
- 技术越来越成熟（迁移学习、联邦学习）
- 与其他技术融合（AI + IoT、AI + 区块链）

### 4. 如何应对AI带来的就业变化
- 学习AI相关技能
- 培养创造力和批判性思维
- 终身学习，适应变化
- 发展人机协作能力
