## 二、教学-考试适配"三改刀"

这套蒸馏对原书做的三类改造（证据：PIPELINE_STATE"三处改刀"、九份 SKILL/verified、三份验收报告）：

1. **口径统一为考试优先（V3' 淘汰刀）**：候选条目一律过"会造成失分才配留"的 V3' 审——纯常识（"数据是信息的载体"）、纯操作（SSMS 逐击步骤）、考区外围（BDE/IDAPI、数据库产品简介）全部淘汰或降级；连带完成全书内容再分配（ch11 拆成 D8/D9、ch05 拆成 D3/D4，D2 淘汰的"恢复模式"经裁定改判 D9）。
2. **补真机实测 + 教材存疑双层处置**：每个单元市面上少见的做法是对照 SQL Server 真机语义核教材——冲突处统一记"**考试按教材记 / 实操按真机**"双层口径（如 @@TRANCOUNT 减 1 vs 归 0、非聚集索引 249 vs 999、恢复模式版本限制），GUI 没写的语法帧按标准语义补入并诚实标注"补充非原文"；引文一律免责标注出处与删节。
3. **钩子化重写 + 诱饵盲测验收**：全部知识按"记忆钩子"重写（四类完整性=行/格/表/人、ACID=全做或全不做·账目不坏·排队不串·停电不丢、备份四类型=全家福/新来的/监控录像/按房间拍），跨单元归属全部配混淆表；再由独立验收官跑 test-prompts.json 诱饵盲测（should_trigger/decoy/edge 三轨，全卷 97 条），诱饵必须 100% 不误触发，实测 95/97 通过（97.9%）全部放行——诱饵题同时兼任后续"记忆账本"的抽测题源。

### (b) 教材与真机/现实冲突点清单

以下每条均出自 9 份 verified.md 的"教材存疑"段落（及验收报告就此发出的复查指令），处理口径一律执行"考试按教材记 / 实操按真机"双层标注：

| # | 冲突点 | 教材说法 | 真机/现实表现 | 处理口径（**考试按教材记**） |
|---|---|---|---|---|
| 1 | ch07 §7.1 参照完整性表述 | "禁止会导致从表中相应值孤立的主表中的**外键**值改变" | 术语配用错误——被禁改的是主表**被参照键（主键）**，不是"外键" | 引用时保留原文并加注勘误；考试按教材原句表述作答 |
| 2 | ch11 §11.1.3 表读权限 | "一般情况下，任何用户都具有数据表或视图的数据的读权限" | SQL Server 默认 public **不自动授予 SELECT**，读权限须显式授权 | 考试按教材表述，实操勿照搬 |
| 3 | ch11 表 11-1 进程角色描述 | Processadmin 的全称与职能照抄 Setupadmin（"Setup Administrators，可管理连接服务器和启动过程"） | 标准语义 Processadmin = 管理 SQL Server 服务器进程，两行描述不应重复 | 记住角色名即可，不引用其可疑描述；考试按教材名单出题口径记 |
| 4 | ch11 §11.3.3 权限继承例句 | "Role1 无 INSERT 权限，User1 取得 INSERT 权限，则 User1 最终也取得……"语序脱落、指代不清 | 正确语义应为"角色无权 + 用户直接获权 → 并集中仍为允许" | 考试按补全后的并集语义作答（原文语病不产出题点） |
| 5 | ch11 §11.9 导入导出版本限 | "数据导出导入功能只在企业版或开发版才有，且必须安装至少 SP1 补丁" | SQL Server 2012 各版本（含 Express 等）均带导入导出向导 | 考试按教材"企业版/开发版 + SP1"口径作答，实操勿照搬 |
| 6 | ch11 §11.4.3 批日志性能 | "批日志还原在性能上要优于简单还原和完全还原模式" | 过强——其优势**仅限减少批操作日志空间**，读性能与完全还原相同 | 考试按教材"性能优"作答，本单元按原文限定"减少批操作日志空间"收录 |
| 7 | ch11（磁带机介质） | "SQL Server 2012 只支持备份到本地磁带机，不支持网络远程磁带机" | 2012 实际支持备份到网络介质，该说法为陈旧表述 | 降级为词条留痕；考试若考按教材答，实操勿照搬 |
| 8 | ch09 §9.2.2 ROLLBACK 与 @@TRANCOUNT | "不带保存点回滚到事务开始点，@@TRANCOUNT **减 1**" | SQL Server 2012 真机：无保存点的 ROLLBACK 回滚**最外层**事务并将 @@TRANCOUNT **置 0**（嵌套时不是逐层减；单层时两者数值巧合相同）（验收 D7-06，出自 Microsoft Learn） | **考试按教材记"减 1"**，实操按真机是"归 0"；保存点回滚不影响 @@TRANCOUNT 两处均一致 |
| 9 | ch06（非聚集索引上限） | 非聚集索引每表最多 **249** 个 | SQL Server 2005 之后口径：SQL Server 2008+ 真机为 **999**（教材是 2005 时代口径）（验收 D5-S1） | **考试按教材记 249**；实操按真机 999（防上机踩坑） |
| 10 | ch06（聚集索引空间估计） | 聚集索引≈**1.2 倍**数据大小 | 教材独门口径，真机无此定数（实际取决于填充因子与维护开销）（验收 D5-S4） | **考试按教材记 1.2 倍** |
| 11 | ch08 §8.1 日期字面量 | '01/15/2017' 类日期串按年/月/日解析，例题默认如此 | 解析依赖 SET LANGUAGE/DATEFORMAT——mdy 下成立，dmy 下该串转换失败（验收 D6-T4） | **考试按教材日期串/mdy 口径记** |
| 12 | ch11 §11.4.2 差异备份基准 | 差异备份基准="最近一次**数据库备份**以来发生的变化" | 真机语义：差异基准=最近一次**完整**备份（中间只是差异数据不触发基准重置）（验收 D9-ST1） | **考试按教材"最近一次数据库备份"记**；两处口径按教材统一 |
