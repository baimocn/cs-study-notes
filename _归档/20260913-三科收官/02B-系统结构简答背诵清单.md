## 一、简答题（30分主力，背这些就够）

### 1. 冯·诺依曼结构的特点（5条）
1. 程序和数据存放在**同一存储器**中（存储程序思想）
2. 指令和数据用**二进制**表示
3. 指令由**操作码 + 地址码**组成
4. 指令**按顺序**执行
5. 以**运算器**为中心
（钩子：存储程序、二进制、操作码地址码、顺序执行、运算器中心）

### 2. 冯·诺依曼瓶颈及解决方案
- **瓶颈**：取指令和取数据**共用一条总线**，不能同时进行，限制了速度
- **解决**：哈佛结构（指令与数据分开存储）；现代CPU在**缓存层**采用哈佛结构

### 3. RISC 和 CISC 的区别（对比表）
| 维度 | RISC | CISC |
|------|------|------|
| 指令数量 | 少 | 多 |
| 指令长度 | 固定 | 可变 |
| 寻址方式 | 少 | 多 |
| 访存方式 | 仅LOAD/STORE可访存 | 多种指令可访存 |
| 流水线 | 效率高 | 效率低 |
| 编译 | 适合编译器优化 | 适合手写汇编 |
| 代表 | ARM / MIPS | x86（Intel/AMD）|

### 4. 流水线的基本原理
1. 将指令执行过程分成**多个阶段**（如取指、译码、执行、写回）
2. 每个阶段由**独立部件**完成
3. 多条指令的**不同阶段可以重叠执行**
4. 提高CPU的**吞吐率**
（钩子：分阶段、独立部件、重叠执行、提高吞吐）

### 5. 流水线的三种冲突
1. **数据冲突**：后续指令需要前面指令的结果（还没算完就要用）
2. **控制冲突**：遇到跳转指令，不知道该取哪条后继指令
3. **结构冲突**：多条指令同时争用同一硬件部件
- **解决**：数据前递（数据冲突）/ 分支预测（控制冲突）/ 插入气泡、加资源（结构冲突）

### 6. 缓存（Cache）的工作原理
1. 基于**局部性原理**（时间局部性：刚用过可能再用；空间局部性：附近数据可能用）
2. CPU访问数据**先查Cache**
3. **命中**：直接从Cache读取（快）
4. **缺失**：从内存读取，并加载到Cache
5. 内存满时按**替换策略**（LRU/FIFO/LFU）替换

### 7. Cache 地址映射方式（三种）
1. **直接映射**：主存块只能映射到Cache的**一个固定位置**（简单，冲突率高）
2. **全相联映射**：主存块可映射到Cache的**任意位置**（灵活，查找慢）
3. **组相联映射**：先**分组**，组内**全相联**（折中，实际最常用）

### 8. 存储层次（填空/简答）
- 层次：**寄存器 → L1缓存 → L2缓存 → L3缓存 → 内存 → 硬盘**
- 规律：速度递减、容量递增、成本递减；局部性原理是缓存机制的基础

## 二、应用题公式总纲（45分）

### 1. CPU性能计算
```
CPU时间 = 指令数 × CPI × 时钟周期时间
        = 指令数 × CPI ÷ 频率
时钟周期 = 1 / 频率
MIPS = 频率 / (CPI × 10⁶)
```

### 2. 阿姆达尔定律
```
加速比 = 1 / [(1 - Fe) + Fe / Se]
Fe = 可改进比例，Se = 改进倍数
（瓶颈：受不可改进部分限制）
```

### 3. 流水线计算（n条指令，k段）
```
流水线周期 = max(各级时间)   ← 取最慢一级的时间
总拍数 = k + n - 1
吞吐率 = n / (k + n - 1) × 流水线周期（没给各级时间时周期算1）
加速比 = (k × n) / (k + n - 1)
效率 = 加速比 / k = n / (k + n - 1)   ← 等于吞吐率（自检符）
```

### 4. 缓存命中率计算
```
命中率 h = 命中次数 / 总访问次数
缺失率 = 1 - h
平均访问时间 = h × 命中时间 + (1-h) × 未命中时间
         （或 = 命中时间 + 缺失率 × 缺失代价，看题目给法）
```

### 5. 指令格式设计（新发现，别漏！）
```
可表示的指令数 = 2^(操作码位数)
各地址字段可表示的范围 = 2^(地址码位数)
例：操作码4位 → 最多 2⁴ = 16 种指令；地址码6位 → 2⁶ = 64 个寻址范围
```

## 三、必背小点（选择/填空）

- 冯诺依曼核心：**存储程序**
- CPU = **运算器 + 控制器**
- 指令周期：**取指、译码、执行、写回**
- CPI = 每条指令平均需要的时钟周期数
- 流水线加速比受限于**最慢一级**（瓶颈段）
- 缓存命中率越高，CPU效率越高
- 虚拟存储器 = **主存 + 辅存**
- RISC特点：指令长度**固定**、数量**少**
