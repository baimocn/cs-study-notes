## I · 骨架 + 钩子
**钩子（本单元三个，考试时在心里过一遍）：**
- **结构体是不同类型的打包**——类型不同的相关数据塞一个盒子，各成员按定义顺序依次占位。
- **`.` 走变量，`->` 走地址**——`.` 左边站的是变量本人；`->` 左边站的是门牌号（指针/地址）。见到指针想拿成员，条件反射写 `->`，或给 `*p` 套圆括号再用 `.`。
- **typedef 是发别名，不是造新人**——`typedef int INTEGER;` 只是给 int 起了个大名，没有创造新类型，也没定义任何变量。

骨架：
1. 定义类型：`struct 类型名 { 成员表 };`——分号不能省；类型只是图纸，不占内存（K1/K2）。
2. 定义变量：先类型后变量 / 类型变量同时 / 无名结构体（此后不能再定义，K5）。
3. 赋值：逐成员赋（字符串用 strcpy），同类型变量可整体赋值 `s1=s2`（R3）。
4. 访问：变量用 `.`，嵌套逐级点到底；指针用 `->`，数组指针 `p+1` 走一个元素（K7-K12）。
5. 自定义：typedef 四用法发别名（K15）。

## A1 · 书中例题精讲（例8-8 赋值/输出，例8-13 typedef 前置版指针访问）
**例8-8（P265）成员赋值 + 整体赋值：**
```c
struct std_info { int no; char name[10]; char sex; int score[3]; };
struct std_info s1, s2;
s1.no = 1;                    /* 逐成员赋值，普通变量一样用 */
strcpy(s1.name, "LiWei");     /* 字符数组成员：必须 strcpy，不能 s1.name="LiWei" */
s1.sex = 'F';
s1.score[0] = 82;             /* 成员是数组：下标照用 */
scanf("%d %s %c %d", &s2.no, s2.name, &s2.sex, &s2.score[0]);
s1 = s2;                      /* 同类型整体赋值：合法，按成员顺序复制 */
```
输出 `no=1,name=LiWei,sex=F,...`。考点三连：数组成员输入**不加 &**（s2.name 本身是地址）；整体赋值 ✓；若写 `s1==s2` ✗（R4）。

**例8-13（P271）指针三等价：**
```c
struct std_info student = {"000102","ZhangYi",'f',{2000,9,20}};
struct std_info *p = &student;
p->no                    /* 方式二：指针的标准动作 */
(*p).sex                 /* 方式三：*p 等于 student 本身，圆括号不能省 */
p->birthday.year         /* 嵌套：-> 点混用，逐级走到底 */
```
三式等价于 `student.no / student.sex / student.birthday.year`。`*p.sex` ✗——`.` 优先级高于 `*`，先算成 `p.sex`，p 不是变量（T3）。

**例8-15（P273）指针走结构体数组：**
```c
struct std_info stu[2], *p;
p = stu;                        /* p 指向 stu[0] */
p->no = 100;                    /* 等价 stu[0].no=100 */
strcpy((*p).name, "ZhangYi");
(*(p+1)).no = 101;              /* p+1 指向 stu[1]：走一个元素，不是一个成员 */
strcpy((p+1)->name, "HaoLin");
```
指针步进两兄弟（判停高频）：`(p++)->name` 先取 stu[0].name 的值、后移；`(++p)->name` 先移到 stu[1]、再取值。顺序反 → 答案反。

**例8-19（P278）值传递是复印件（读程序题的时序模板）：**
```c
struct data { int a, b, c; };
void func(struct data parm) {        /* 形参是副本 */
    printf(...); parm.a=18; parm.b=5; parm.c=parm.a+parm.b;
    printf(...);                     /* 副本内：18,5,23 */
}
int main(void) {
    struct data arg; arg.a=27; arg.b=3; arg.c=arg.a+arg.b;  /* 27,3,30 */
    printf(...); func(arg);          /* 复制一份给 parm */
    printf(...);                     /* 回来：arg 仍是 27,3,30 */
}
```
输出时序：`27,3,30 → CALL → 27,3,30 → 18,5,23 → RETURN → 27,3,30`。要真改实参：传 `&arg`，形参写 `struct data *q`，函数内 `q->a=…`。

## A1b · typedef 四用法对照（例8-23/8-24 + §8.6）

## A1b · typedef 四用法对照（例8-23/8-24 + §8.6）
```c
typedef int INTEGER;          /* ①基本类型：INTEGER x,y; ⇔ int x,y; */
typedef int ARRAY[10];        /* ②数组类型（长度写死）：ARRAY a,b; ⇔ int a[10],b[10]; */
typedef struct { char name[20]; int age; } STU;   /* ③结构体：STU stud[100], *p; */
typedef int *P_I;             /* ④指针型：P_I p1,p2; ⇔ int *p1,*p2; */
typedef char *P_C[5];         /* ④变体：指针数组类型，P_C p3; ⇔ char *p3[5]; */
```
四步法口诀（§8.6）：**按定义变量写一遍 → 变量名换成新名 → 最前面加 typedef → 用新名继续定义**。
判停两连：typedef 只发别名不定义变量、不造新类型；与 #define 的分水岭是**编译时 vs 预处理时**（R9）。

## A2 · 触发题型 ★
**填空**：成员访问点/箭头选择——`p` 是 `struct student *`，填 `p->age` 或 `(*p).age`；`&data.a` 让指针指向成员（填空8 口径）；无名结构体之后能否续用（不能，例8-7）。
**读程序写结果**：
- 结构体数组求和/平均：`sum+=stu[i].score`，输出 `average:90.75` 类（程序分析1）。
- 指针级联：`x[3]={1,x+1,2,x+2,3,NULL}; p=x; printf("%d,%d", p->num, p->next->num);` → `1,2`（程序分析2，自引用成员=链表节点雏形）。
- 值传递 vs 指针传递：fun1(s) 改副本不动实参、fun2(&s) 解引用真改 → 输出 `25,24`（程序分析4）。
- typedef 结构体作返回值：`st2=fun(st1)` 复制返回，fun 内改 a 不影响 st1（程序分析5）。
- 指针步进：`(p++)->name` 先取 student[0].name 再后移；`(++p)->name` 先移到 student[1] 再取——顺序反答案反（K12/T5）。
**简答**：结构体与数组的区别——数组元素**类型相同、按下标访问**；结构体成员**类型可不同、按名字访问**；数组不能整体赋值，同类型结构体变量可以整体赋值（但不能整体比较）。typedef 与 #define：前者编译时处理、能定义类型别名；后者预处理时字符串替换。

## E · 考场步骤：结构体题四格判（判停）
拿到任何结构体题，按四格顺序判，每格不通过即判停改错：
1. **声明格**：struct 后有无类型名？分号 `};` 在不在？嵌套成员的类型是否**已在此前**定义？（例8-2）
2. **定义格**：三法选一；无名结构体之后不得再以"struct ×"引用；类型名 ≠ 变量名（`std_info.sex` 判停，T1）。
3. **赋值格**：字符串成员用 strcpy；数组成员逐元素；同类型整体赋 `=` ✓、比较 `==` ✗ 判停；嵌套初值写成子表 `{2000,9,20}`。
4. **访问格（判停主战场）**：左边是**变量/数组元素** → `.`；左边是**指针/地址**（`&变量`、数组名、p）→ `->` 或 `(*p).`。混用即判停。指针指成员时类型必须与该成员相同（T4）。
判停后按格回改，不通过不进入下一格。

## B · 边界 ★
**失分点**：
- `->` 与 `.` 混用（最高频）：`p->成员` ✓ / `p.成员` ✗ / `student.成员` ✓ / `student->成员` ✗。
- 整体操作：`s1=s2` ✓（同类型）；`printf("%d",s1)` ✗；`s1==s2` ✗——**整体赋值合法、整体比较非法**，一句话记"能抄不能比"。
- 共用体"只看最后写入成员"等考点**本教材 ch08 未收录**（union/enum 全章零出现），自考按书命题，本单元不设此类题；若真题出现属超纲，回到 ch07/ch09 之外的取证流程处理。
- 值传递复制：函数内改形参结构体不影响实参；要真改传地址（例8-19 → 程序分析4）。
- scanf 成员：`scanf("%d",&p->age)`——缺 & ✗；`scanf("%s",pup[0].name)` 不加 &（数组名即地址）。
- 变量定义三法续用陷阱：直接定义法（类型+变量同时）之后还能续用类型名；无名结构体之后 `struct c = {…}` ✗（例8-7）。
- 嵌套初值表：`{"000102","ZhangYi",'f',{2000,9,20}}`——外层一个大表，嵌套成员自带子表；初值类型与成员不一致即错（R5）。
- 函数返回结构体合法（例8-17/8-24）：`struct std_info input(void){ … return s; }`——"函数不能返回结构体"是错的说法（T9）。

**混淆表（相邻单元）**：
| 症状 | 真考点 | 判法 |
|---|---|---|
| `p->a` / `(*p).a` / `*p.a` 三选一 | **C6**：-> 是指针拿结构体成员的专属动词 | C5 只管"p 存地址"本体；一旦问"拿成员用什么符号"，判 C6 |
| `a[i]` vs `s[i].成员` 同题面 | **C3** 只问下标越界/下标从0；**C6** 问成员名路径 | 题面给"成员名.字段"判 C6；只给纯下标算值判 C3 |
| `s1=s2` 能不能整体赋 | **C6**（同类型结构体 ✓）；C3 数组整体赋值 ✗ | 见类型名 struct 判 C6 |
| 函数传"整个结构体"改不改实参 | **C6** 值/址传递（K14）；若问普通 int 传参判 **C4** | 形参写 `struct xx s` 判 C6 |
| `typedef int ARRAY[10]` | **C6** 四用法之二（数组别名）；纯 #define 替换判 **C7** | 看关键词 typedef 还是 #define |
