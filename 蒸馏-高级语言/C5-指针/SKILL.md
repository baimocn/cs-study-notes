## I · 骨架与钩子链

### 指针到底是什么

指针 = 存**地址**的变量。变量住内存，系统给每字节编号，编号就是门牌号；变量的地址 = 它占的那排房间的**起始门牌号**。

**钩子链（本单元主线）**：
1. **变量住地址，指针存门牌号**——普通变量里放"值"，指针变量里放"别人家的门牌号"。
2. **`&` 查门牌，`*` 按门牌进门**——`&num` 是"查 num 的门牌"，`*p` 是"拿着 p 里的门牌按门铃进去"，进去看见的就是变量本身（可读可改）。
3. **`*p` 进去改家具，`p` 只是换门牌**——`*p=3` 改的是屋里东西；`p=&y` 只是让 p 换记另一家的门牌，原屋毫发无损。这条直接解释 swap2/swap3。
4. **数组名=焊死在楼上的门牌，指针=拿在手里的门牌**——数组名是地址**常量**，不能 `a++`；指针是地址**变量**，可以 `p++` 挨家走。
5. **`p+1` 跨一户，不是跨一米**——指针加减按**元素个数**步进，跨多少字节由类型大小定（int 指针 3000+1→3002，教材口径 int=2 字节）。
6. **swap 传址 = 把家门牌号递给装修队**——传值是"抄一份家具清单回家改"（主人家没事）；传址是"把门牌给他"，他按门牌进门真改了。但注意：递出去的门牌本身也是**复印件**（值传递），装修队把复印件扔了换别家，你家不动——所以 swap3 无效。

### 声明与解引用：两个 `*` 要分离

- `int *p, i;`——这里 `*` 是**声明标记**：只贴给 p，"p 是指针"；i 是普通变量。指针变量名是 p，**不是 \*p**。
- `*p = 3;`——这里 `*` 是**解引用运算符**："进 p 所指的门"。
- 同一个星号，定义处是"身份标签"，语句中是"进门动作"，判题先分清它站在哪。

### 四等价（指针法与下标法）

p 指向一维数组首地址时：`a[i] ≡ *(a+i) ≡ p[i] ≡ *(p+i)`。
数组名是地址常量 → `*(a+i)` 合法、`a++` 非法；指针变量 → 四式全通。

### 指针运算的边界

- 允许：`p±n`、`p++/p--`、**同类型指针相减**（结果是**元素个数**，不是字节差：px=&str[4],py=&str[2]，px-py=2）。
- 不允许/无意义：指针±指针相加、指针与整数乘除、给指针赋整数值（`p=3000;` 错；唯一例外 0/NULL）。
- 步进只对**连续空间**（数组）有意义；步进幅度 = n × sizeof(元素类型)。
- 关系运算：同数组内比前后（前者小）；与 NULL 比判空；不同数组比大小无意义。

### 字符串指针 vs 字符数组

- `char *p="abc";` ✓——p 存的是**串首地址**，串本体在系统分配的空间里。
- `char a[80]; a="abc";` ✗——数组名是常量，不能整体赋值；只能在定义时初始化 `char a[80]="abc";`。
- 数组存**串本体**；指针只存**一个门牌**。数组名不可变，指针可随时指向别的串。
- 未赋值的指针是野指针：`char *p; scanf("%s",p);` ✗ 运行时错——p 里是垃圾门牌，进门就砸。

### 指针数组（书末节）

`int *p[4];`——[] 优先级高于 *，先成数组再与 * 结合：4 个元素，每个都是指针。存多个字符串首地址时排序**只换门牌不搬家**（例7-18 strcmp 后交换 s[i]）。辨析：`int *p[4]`（指针数组）≠ `int (*p)[4]`（指向数组的指针，书仅选项级提及）。

### 节奏地图

第一节 指针与指针变量（&/*互逆）→ 第二节 指针和数组（四等价+运算）→ 第三节 指针和字符串（指针 vs 数组）→ 第四节 指针和函数（swap 传址）→ 第五节 指针数组 → 第六节 综合实例。

## A1 · 书中例题

### 例7-12（P238-240）：swap 三兄弟——传址必含 ★

```c
void swap1(int x,int y)          /* 值传递：抄清单 */
{ int temp; temp=x; x=y; y=temp; }
void swap2(int *px,int *py)      /* 传址：进门换家具 */
{ int temp; temp=*px; *px=*py; *py=temp; }
void swap3(int *px,int *py)      /* 传址：却只换了自己手里的门牌 */
{ int *temp; temp=px; px=py; py=temp; }
int main(void)
{ int a=9,b=12,*p1=&a,*p2=&b;
  if(a<b) swap1(a,b);   printf("%d,%d\n",a,b);   /* 9,12  无效 */
  a=9;b=12; if(a<b) swap2(p1,p2); printf("%d,%d\n",a,b); /* 12,9 有效 */
  a=9;b=12; if(a<b) swap3(&a,&b); printf("%d,%d\n",a,b); /* 9,12  无效 */
  return 0; }
```
输出：`9,12` → `12,9` → `9,12`。
（审计注：原书此程序运行结果行缺失，输出由图7-2/7-3/7-4 内存分配图推演，机制描述与原书文字一致。）
- swap1：形参是 a、b 的**复印件**，换复印件不影响原件。
- swap2：px、py 拿到 a、b 的门牌，`*px` 进门真换值 → a=12,b=9。
- swap3：px、py 互换了**各自存的门牌**，但门牌也是复印件——主调函数里的 p1、p2 和 a、b 纹丝不动。
- 结论（原书）：被调函数**不能改变实参指针变量的值**，但**能改变实参指针所指向的变量的值**。

### 例7-7 方法二/三（P231-232）：*(s+i) 与 s[i] 等价 ★

```c
/* 方法二：地址法——*(s+i) 就是 s[i] */
for(i=0;i<N;i++) scanf("%d",s+i);     /* s+i 是 s[i] 的门牌 */
for(i=0;i<N;i++) sum+=*(s+i);
/* 方法三：指针自增遍历——效率最高 */
p=s;
for(;p<s+N;p++) scanf("%d",p);
p=&s[0];
for(;p<s+N;p++) sum+=*p;
```
10 个成绩 12 45 78 23 56 89 41 52 63 74 → 平均 53.00。
- 原书说明：下标法编译时要换算成 `*(s+i)` 重新算地址，指针法 p 直接挨家走、不必重算，所以快。
- 方法三第二遍循环前必须 `p=&s[0]`（重新指回首地址）——指针是**可搬家**的，走完不回头就成野指针式越界。

### 例7-2（P225）：指针遍历字符串

```c
char s[256]; char *p;
scanf("%s",s);  p=s;
while(*p!='\0') p++;                 /* 按门牌逐户走，直到 \0 */
printf("The string length is %d\n",p-s);  /* 减法=元素个数 */
```
输入 welcomd → 长度 7。两考点：`p-s` 是指针减法（结果为元素个数）；`*p!='\0'` 是串遍历判停标准写法。

## A2 · 触发题型 ★

### 题型1：读程序写结果——三胞胎（收口考）

**判分核心：先看 ++ 作用在 p 上还是 *p 上。**

| 写法 | 拆解（右结合） | 效果 | 口诀 |
|---|---|---|---|
| `*p++` ≡ `*(p++)` | 先取 `*p`（旧户），后 `p+1`（搬到下一户） | **取旧值，p 后移** | 取完搬家 |
| `(*p)++` | 括号强制先 `*p`，再对**内容**加1 | **所指内容+1，p 不动** | 屋里东西加一 |
| `*++p` ≡ `*(++p)` | 先 `p+1`，再取新户内容 | **p 先移，取新值** | 先搬再取 |
| `++*p` ≡ `++(*p)` | 内容加1 | 同 `(*p)++` | 屋里加一 |
| `*p--` / `*--p` / `--*p` | 同上三条的减号版 | 对称成立 | — |

**独立反例（设 int a[]={5,6,7}, *p=a;）**：

| 语句执行后 | a[0] | a[1] | p 指向 | 表达式值 |
|---|---|---|---|---|
| `x=*p++;` | 5 | 6 | &a[1] | x=5 |
| `x=(*p)++;` | **6** | 6 | &a[0] | x=5 |
| `x=*++p;` | 5 | 6 | &a[1] | x=6 |
| `x=++*p;` | **6** | 6 | &a[0] | x=6 |

反例差异收口：`*p++` 与 `(*p)++` 表达式值同为 5，**但一个动了 p、一个动了 a[0]**——下一句再访问，结果分道扬镳。读程序必须跟踪"p 指谁 + a 里存什么"两条线。

### 题型2：写函数——传址改实参

模板（练习题3原题）：
```c
void swap(int *p1,int *p2)
{ int temp; temp=*p1; *p1=*p2; *p2=temp; }
/* 调用：swap(&x,&y); 或 int *px=&x,*py=&y; swap(px,py); */
```
判分点：①形参写 `int *`；②中间变量是 **int 不是 int\***；③函数体内每处带 `*`；④调用处给**地址**（&x 或指针变量）。
扩展考法（例7-13）：`void f(char *s1,char *s2)` 接收数组名也成立——**形参指针变量 ≡ 形参数组名**，四种组合本质都是传首地址。

### 题型3：填空——声明 vs 解引用左右值

- `int *p=&x;` 定义时 `*p` 作**左值**放声明处=标记；`*p=3;` 语句中作左值=往门里写。
- 高频填空（原书填空1）：& 的运算对象必须是**已定义的变量或数组元素**；* 的运算对象必须是**地址**。
- 高频填空：`int a[10],*p;` 把 a[8] 的地址赋给 p → `p=&a[8];`（& 作用到**元素**，不能 &a）。
- 高频填空（原书填空10）：指针作参数的传递方式本质是**值**传递（传的是地址值）。
- 判别口诀：**左边查身份（声明），右边查动作（解引用）；动作看对象（地址？变量？）**。

## E · 考场步骤 ★

### E1 指针题三问判 chain（每题必走）

1. **指向谁？**——找 p 最近的赋值/初始化（`p=&x`、`p=a`、`p=&a[2]`），确定门牌对准哪户。`p=&a[2]` 时 `*p` 是 a[2]，`*(p-1)` 才是 a[1]。
2. **解引用了吗？**——语句里有没有 `*`？有 `*` 动的是**那户屋里**；没 `*` 动的是**门牌本身**。声明处的 `*` 不算数。
3. **++/移了几步？**——`p++` 移 1 个**元素**（字节数=元素大小）；`p1-p2` 得**元素个数**；`*p++` 取旧再移、`(*p)++` 只改内容。移动后必须重答第 1 问。

### E2 判停（三问答完再落笔）

- p 的当前指向 = ? （画两个格子：**p 指哪** + **屋里存什么**，每走一步更新一次）
- 遇到 `*p++` 类：先标"取旧值"，再移指针，**两件事写两行**不合并。
- 数组名出现：检查是否被 ++ / 被赋值（`a++`、`a="..."` 立即判错，常量不能动）。
- 遇 scanf/printf 的指针参数：scanf 要**地址**（p 已是地址，&num 才补 &）；printf %s 送指针、%c 送 `*p`。
- 越界引用（p[-1]、p[20]）：语法对、值不确定——读程序题若出现，答案答"值不确定/无意义"而非硬猜。
- 步进题先确认元素大小：教材口径 int=2 字节（3000+1→3002），题干若明示其他字节数按题干走。

### E3 swap 类判停

- 函数体里动的是 `*px`（内容）→ 实参真变；动的是 `px`（门牌）→ 实参不变。
- 实参给了地址吗？`swap2(p1,p2)` ✓ / `swap2(a,b)` ✗（int 传给 int* 编译不过）。

## B · 边界与混淆

### B1 失分点清单（本单元直接命中的）

1. 野指针：`char *p; scanf("%s",p);` 未赋值就用——原书明确"运行时出错"。凡用指针接收输入，先让它指向已分配空间（如 `p=str`）。
2. `p=3000;` 整数当地址——错。指针只能接收地址型表达式或 0/NULL。
3. `double *p=&a;` 而 a 是 int——类型必须一致。
4. `&a`（数组名取址）——错；`&a[i]`（元素取址）——对。
5. `char a[80]; a="abc";`——数组名常量不能整体赋值。
6. 越界不检查：p[-1]、*(p+20) 语法通过、值不确定，写入会破坏别的内存。
7. 指针减法答成字节差——答案是元素个数（可负）。
8. `int *pointer=array, array[10];`——赋初值时数组还没定义，先定义后使用。
9. 用数组名接收指针型函数返回值——错，函数名是常量收不了地址，必须用指针变量。
10. `*p=3` 后以为 p 变成 3——p 不动，动的是它指向的那户。

### B2 书外边界（书无勿展开）

- 函数内 malloc 不释放、动态内存管理：**书无此内容，不引入**。
- 二级指针 `int **p`：书仅单选选项出现，正文零讲解——只保留"与 `int *p[4]` 辨析"的判据，不展开。
- 指向函数的指针：书明确"不涉及"，不引入。
- void*：书无，不引入。

### B3 混淆表

| 混淆点 | C5 本貌 | 易混单元 | 拆弹 |
|---|---|---|---|
| 数组名偏移 vs 指针算术 | 两者都按**元素**步进：a+1 加 sizeof(元素) 字节 | C3 数组 | C3 只教 a[i] 下标语义；C5 指出下标法编译时被换算成 *(a+i)。拆弹：算 `a+i` 的**地址数值**时乘元素大小，算 `p1-p2` 时除回去得元素个数 |
| 值传递 vs 传址 | swap 是 C4"函数参数传值"规则的**唯一通行证**：想真改实参，只能传地址再解引用 | C4 函数 | C4 结论"形参改不影响实参"在 swap2 处**不矛盾**——被改的是 *px 那户，px 自己仍是复印件 |
| 结构体成员访问 | p->成员 / (*p).成员 属 C6 | C6 结构体 | ch07 无 `->` 内容；见到结构体指针成员访问判给 C6，本单元不处理 |
| %s 整体输出 | 字符指针/字符数组可整体 %s | C3 数组 | 其他类型数组不能 printf("%d",array) 整体输出——这是字符（串）的特权 |
| 指针数组 vs 数组指针 | `int *p[4]` 是数组（4 个指针）；`int (*p)[4]` 书仅选项级 | C3 | [] 优先级高于 *：先 [] 后 * 是"装指针的数组" |
