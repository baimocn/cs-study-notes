# C1 候选池（ch01+ch02+ch03）— 数据类型、运算符和表达式

来源：《高级语言程序设计（2017年版）》郑岩，ch01 概述 / ch02 C语言基础知识 / ch03 数据类型、运算符和表达式。
口径申明：教材以 ANSI C 为标准、上机环境 VC++6.0；ch03 例3-35 的 sizeof 数字为 VC++6.0（32位）口径，ch03 正文亦有"16位PC int占2字节"表述——凡涉字节数一律注"按教材口径（VC++6.0/32位 或 TC/16位）"，不与面试真机（LP64 Linux long=8字节）混写。
