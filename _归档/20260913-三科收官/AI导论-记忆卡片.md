## 第9章 核心算法精讲（卡37-40）

```
┌───────────────────────────────┐
│ 卡37：特征交叉                 │
│  组合特征（笛卡尔积）→ 非线性     │
│  风险：维度灾难（指数爆炸）       │
│  对策：特征哈希 / 限二阶 / 统计过滤│
└───────────────────────────────┘
```

```
┌───────────────────────────────┐
│ 卡38：L1 vs L2                 │
│  L2 = 权重平方惩罚               │
│    → 趋近0不为0 → 防过拟合       │
│  L1 = 绝对值惩罚                 │
│    → 稀疏解（压到0）→ 特征选择    │
│  弹性网络 = L1+L2 混合           │
└───────────────────────────────┘
```

```
┌───────────────────────────────┐
│ 卡39：混淆矩阵                  │
│  TP真/ TN真负/ FP误报/ FN漏报    │
│  精确率 = TP/(TP+FP) 查准        │
│  召回率 = TP/(TP+FN) 查全        │
│  F1 = 调和平均                   │
└───────────────────────────────┘
```

```
┌───────────────────────────────┐
│ 卡40：AUC                      │
│  ROC 曲线下面积                 │
│  越接近 1 越好                  │
│  0.5 = 随机猜测                 │
│  对类别不平衡不敏感（黄金标准）    │
└───────────────────────────────┘
```
