## I · 概念骨架（钩子先行）

**钩子：宏＝文本代打，没括号就是裸奔。**（宏替换纯粹是字符替换，谁没括号谁在考场上失分）

1. **定位**：编译预处理＝在**正式编译之前**先把 `#` 行处理完，纯文字加工，不产生运行时代码 → **不占运行时间**。
2. **三大命令**：宏定义（#define）、文件包含（#include）、条件编译（#ifdef/#ifndef/#if…#endif）。
3. **无参宏** `#define 宏名 字符序列`：宏名是标识符（习惯大写）；**行尾不加分号**；预处理只查名换字、**不作任何检查**；双引号字符串里重名不替换；作用域到文件尾，`#undef 标识符` 随时终止；可层层引用别的宏（逐层替换）。
4. **有参宏** `#define 宏名(形参表) 字符序列`：实参常量/变量/**表达式**都行，替换时**不计算实参的值**，只把实参文本塞进形参位置。两条铁律：宏名与左括号间**不能有空格**；**所有形参 + 整个字符序列都要加圆括号**。
5. **文件包含**：预处理时把被包含文件**整份复制**粘贴到 #include 处；`"文件名"`先查当前源文件目录、找不到再查系统包含目录；`<文件名>`直接查系统包含目录（标准头文件用它）；一条命令只含一个文件；允许嵌套；包含文件改了要重编译。
6. **条件编译**：选择性编译，没被选中的程序段在目标程序里**根本没有代码**（区别于 if 语句全产生代码）。#ifdef＝已定义选段1；#ifndef＝未定义选段1（功能正好相反）；#if＝表达式非0选段1，且表达式在**编译阶段**求值，**不能是变量**；三种都靠 #endif 收尾，#else 可省。

## A · 书中核心例题

**逐层替换例（【例9-1】，P298）**：
```c
#define PI 3.1415926
#define R 3
#define L 2*PI*R        /*展开：2*3.1415926*3.0 → 18.85*/
#define S PI*R*R       /*展开：3.1415926*3.0*3.0 → 28.27*/
```
宏引宏，且展开后与 double 运算自动升级为 3.0——这是"一改全改"的可读性红利。

**【例9-3】宏版求最大值（母题）**（P300）
```c
#define MAX(a,b) ((a)>=(b)?(a):(b))    /*有参宏：括号全套*/
printf("The max is %d\n", MAX(j,k));   /*输入 23 56 → 输出 56*/
```
对照函数版 `int max(int x,int y){return(x>y?x:y);}`：同一问题两种实现——宏在编译前文本代打，函数在运行时传值。

**括号正反例（P299 原书）**：
```c
#define POWER(x) ((x)*(x))   /* POWER(a+b) → ((4+6)*(4+6)) = 100 ✔ */
#define POWER(x) (x*x)       /* POWER(a+b) → (4+6*4+6)      = 34 ✘ */
```
**空格陷阱**：`#define S (a,b)a*b`，则 `mul=S(x,y);` 展开为 `mul=(a,b)a*b(x,y);`——S 被当成无参宏，全盘报废。

## T · 触发题型 ★

- **填空**：三种预处理命令名；宏定义不是语句、行尾不加分号；#ifdef 段选中规则；`#define WID 80 / #define LEN WID+20`，`x=LEN*3` → **140**（少括号，不按"想当然"的 300）。
- **选择**：宏名代替的是**字符串**；宏替换不检查类型、不占运行时间、宏名不必大写；编译系统对宏命令的处理在**其他部分正式编译之前**。
- **改错**：#define 行尾分号；宏名与左括号间的空格；形参缺括号；#if 的表达式用了变量。
- **简答**：宏 vs 函数四区别（见 A/E）；条件编译 vs if 语句。

## E · 考场步骤（宏计算题三步）

1. **找目标**：圈出宏调用语句，写出宏定义原文（一眼核对：有没有空格带进替身？）。
2. **先替换后运算**：把实参**原样文本**塞进形参位置；整个字符序列按定义加回括号；字符串里出现的"宏名"不换。禁止在此阶段尝试求值。
3. **套 C1 优先级求值**：把展开式当作普通 C 表达式，按优先级、自增副作用、整除算出结果。
**判停**：能写出展开式→继续求值；展开式写不出来→回到第2步逐参数复查；题目问"错误原因"→直接对照 B 池失分点清单作答，不再计算。

## B · 边界与混淆 ★

**失分点**
- 形参没加括号：`#define S(r) 3.1415926*r*r`，`S(a+b)` → `3.1415926*a+b*a+b`；正确写法 `3.1415926*(r)*(r)`。形参与整体都括，一个都不能少。
- 宏定义带分号 → 分号被当作替换字符展开，编译报错。
- 双引号内的"宏名"不替换——别在 printf 字符串里找宏。
- 预处理阶段 vs 编译阶段混淆：语法检查在预处理**之后**；#if 的表达式不能是变量。
- include 路径写反（"" 与 <> 混淆）；一条命令包多个文件；递归/重复包含造成重复展开或重复编译。
- 条件编译漏 #endif；#ifdef 与 #ifndef 方向写反。

**单元混淆表**
| 易混点 | C7 本单元 | 相邻单元 |
|---|---|---|
| 表达式求值 | 宏展开**之后**才按优先级算（C1 规则） | C1：直接按优先级运算，无"先替换"一步 |
| 求最值 | MAX 有参宏：预处理替换、无类型、每次展开目标程序变长、参数有副作用会重复求值 | C4 普通函数：传值**先求实参**、定义类型、目标程序不变长、调用占时间 |
