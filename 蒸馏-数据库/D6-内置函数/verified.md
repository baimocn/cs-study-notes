## V2 新题可构造性（能否出书里没有原题的新题）

- C1 ✅：可造"表里 5 行成绩，1 行 NULL，COUNT(*) / COUNT(成绩) / AVG(成绩) 各是多少"数值题——比书里原题更贴考试。
- C2 ✅：可造 LEN('abc ')、CHARINDEX 返回值填空。
- C3 ✅：可造 YEAR(GETDATE())、EOMONTH 移位填空。
- C4 ✅：可造 CEILING(-3.2)、ROUND(76.48,-1) 负数陷阱题。
- C5 ✅：可造 CAST('123' AS int)+20、TRY_CONVERT 失败返回 NULL 选择题。

## V3' 考试杀伤力

- C1 ★★★：COUNT(*) vs COUNT(列) 是自考填空/选择高频；AVG 忽略 NULL 直接改变数值答案。失分点成立。
- C2 ★★☆：CHARINDEX>0 当条件、LEN 填空常见；REPLACE/UPPER 偏操作题。
- C3 ★★☆：YEAR/MONTH/DAY 返回 int 是经典判断点；EOMONTH 属 2012 新增，新教材爱考。
- C4 ★☆☆：CEILING/FLOOR 负数方向是唯一失分点，其余背结果即可——故只留三帧。
- C5 ★★☆：CAST 语法填空 + TRY_CONVERT 返回 NULL 是新增考点；IIF/CHOOSE 一眼题。

## 淘汰留痕（降级为术语词条，不进 frames）

| 淘汰项 | 原因 |
|---|---|
| 配置函数 @@VERSION/@@LANGUAGE/@@SPID 等（8.1.2） | 纯展示性：返回环境信息，不构成"输入→返回值"计算帧；考概率≈0 |
| 元数据函数 COL_LENGTH/COL_NAME/DB_ID/DB_NAME（8.1.5） | 同上，展示性 + 依赖系统元数据，自考未见出题记录 |
| 三角/对数/指数（ACOS/ASIN/ATAN/COS/SIN/LOG/EXP/DEGREES/RAND/PI） | 有返回值但考试杀伤力低（背表无技巧），降级术语；只留 DEGREES(PI())=180 一条冷知识 |
| 排名函数 RANK/ROW_NUMBER（8.1.8） | 教材单小节、例题依赖 OVER 子句——属窗口查询主题，塞进本单元会稀释；降级术语（RANK 并列跳号、ROW_NUMBER 连续）留给 D3/D4 复用时再展开 |
| 用户定义函数/标量函数/表值函数（8.2~8.4） | 不属"内置函数"，教材目录错置；本单元不收录（若 D7 不覆盖，由总管裁决归属） |
| STDEV/VAR/CHECKSUM 族 | 自考超纲，全书无例题 |
