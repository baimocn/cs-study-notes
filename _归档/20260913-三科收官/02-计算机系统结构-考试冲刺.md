# 计算机系统结构 - 考试冲刺文档

## 考试题型
- 单选题（约15分）
- 填空题（约10分）
- 简答题（约30分）
- 综合应用题（约45分）

---

## 一、单选题高频考点

### 1. 冯·诺依曼结构
- 核心思想：**存储程序**，程序和数据存放在同一存储器中
- 五大部件：运算器、控制器、存储器、输入设备、输出设备
- CPU = 运算器 + 控制器
- 冯·诺依曼瓶颈：取指令和取数据不能同时进行

### 2. 哈佛结构
- 指令和数据分开存储
- 两套总线，可同时取指令和取数据
- 现代CPU：对外冯·诺依曼，对内哈佛（L1指令缓存和L1数据缓存分开）

### 3. CPU性能
- CPU时间 = 指令数 × CPI × 时钟周期时间
- CPU时间 = 指令数 × CPI ÷ 频率
- CPI：每条指令平均需要的时钟周期数
- MIPS = 指令数 / (执行时间 × 10^6) = 频率 / (CPI × 10^6)

### 4. 阿姆达尔定律
- 加速比 = 1 / [(1 - 可改进比例) + 可改进比例 / 改进倍数]
- 含义：系统性能提升受限于不可改进部分的比例

### 5. 指令系统
- 指令由操作码和地址码组成
- 操作码：做什么（加、减、跳转等）
- 地址码：操作数在哪里

### 6. 寻址方式
| 寻址方式 | 特点 | 例子 |
|---------|------|------|
| 立即寻址 | 操作数在指令中 | ADD R1, #5 |
| 寄存器寻址 | 操作数在寄存器 | ADD R1, R2 |
| 直接寻址 | 地址在指令中 | LOAD R1, [1000] |
| 间接寻址 | 地址的地址 | LOAD R1, [[1000]] |
| 寄存器间接 | 寄存器中存地址 | LOAD R1, [R2] |
| 基址寻址 | 基址+偏移 | LOAD R1, [R2+100] |
| 变址寻址 | 变址+偏移 | LOAD R1, [R2+R3] |

### 7. 流水线
- 流水线级数：通常4-6级
- 加速比 = 不用流水线时间 / 用流水线时间
- 流水线冲突：数据冲突、控制冲突、结构冲突
- 解决方法：数据前递、分支预测、插入气泡

### 8. 存储层次
- 寄存器 → L1缓存 → L2缓存 → L3缓存 → 内存 → 硬盘
- 速度递减，容量递增
- 局部性原理：时间局部性、空间局部性

## 二、填空题高频考点

1. 冯·诺依曼结构的核心思想是**存储程序**
2. CPU = **运算器 + 控制器**
3. 指令周期包括：取指、译码、执行、**写回**
4. CPI的含义是**每条指令平均需要的时钟周期数**
5. 流水线的加速比受限于**最慢的那一级**
6. 缓存命中率越高，CPU效率**越高**
7. 虚拟存储器由**主存和辅存**组成
8. RISC的特点是指令长度**固定**，指令数量**少**

## 三、简答题高频考点

### 1. 冯·诺依曼结构的特点
- 程序和数据存放在同一存储器中
- 指令和数据用二进制表示
- 指令由操作码和地址码组成
- 指令按顺序执行
- 以运算器为中心

### 2. 冯·诺依曼结构的瓶颈及解决方案
- 瓶颈：取指令和取数据共用同一总线，不能同时进行
- 解决方案：
  - 哈佛结构：指令和数据分开存储
  - 现代CPU：缓存层采用哈佛结构

### 3. RISC和CISC的区别
| RISC | CISC |
|------|------|
| 指令数量少 | 指令数量多 |
| 指令长度固定 | 指令长度可变 |
| 寻址方式少 | 寻址方式多 |
| 只有LOAD/STORE访问内存 | 多种指令可访问内存 |
| 流水线效率高 | 流水线效率低 |
| 适合编译器优化 | 适合汇编编程 |

### 4. 流水线的基本原理
- 将指令执行过程分成多个阶段
- 每个阶段由独立的部件完成
- 多条指令的不同阶段可以重叠执行
- 提高CPU的吞吐率

### 5. 流水线的三种冲突
- **数据冲突**：后面的指令需要前面指令的结果
- **控制冲突**：遇到跳转指令，不知道该取哪条指令
- **结构冲突**：多条指令争用同一硬件资源

### 6. 缓存的工作原理
- 利用局部性原理
- CPU访问数据时先查缓存
- 命中：直接从缓存读取
- 缺失：从内存读取，并加载到缓存
- 替换策略：LRU、FIFO、LFU

### 7. Cache地址映射方式
- 直接映射：每个主存块只能映射到缓存的一个固定位置
- 全相联映射：每个主存块可以映射到缓存的任意位置
- 组相联映射：折中方案，先分组，组内全相联

## 四、综合应用题高频考点

### 1. CPU性能计算
给定指令数、CPI、频率，计算执行时间。

**公式**：
- CPU时间 = 指令数 × CPI × 时钟周期
- 时钟周期 = 1 / 频率

### 2. 阿姆达尔定律计算
给定可改进比例和改进倍数，计算整体加速比。

**公式**：
- 加速比 = 1 / [(1 - Fe) + Fe/Se]
- Fe：可改进比例
- Se：改进倍数

### 3. 流水线计算
给定流水线级数和各级时间，计算吞吐率和加速比。

**公式**：
- 流水线周期 = max(各级时间)
- 吞吐率 = n / (k + n - 1) × 流水线周期
- n：指令数，k：流水线级数

### 4. 缓存命中率计算
给定命中率和访问时间，计算平均访问时间。

**公式**：
- 平均访问时间 = 命中率 × 缓存时间 + (1-命中率) × 内存时间

### 5. 指令格式设计
给定操作码位数和地址码位数，计算指令可表示的范围。

## 五、必背公式

1. **CPU时间 = 指令数 × CPI × 时钟周期时间**
2. **CPU时间 = 指令数 × CPI ÷ 频率**
3. **MIPS = 频率 / (CPI × 10^6)**
4. **加速比 = 1 / [(1-Fe) + Fe/Se]**
5. **流水线周期 = max(各级时间)**
6. **平均访问时间 = h × t1 + (1-h) × t2**
7. **页号 = 逻辑地址 ÷ 页大小**
8. **页内偏移 = 逻辑地址 % 页大小**
