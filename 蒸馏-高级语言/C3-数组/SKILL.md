## I 单元骨架

**钩子：下标从 0 数，a[n] 永踩界；二维排座位按行填；字符串有尾巴 \0。**

1. 数组 = 相同类型一组**有序**数据；每个元素等同同类型变量；先定义后使用。
2. 定义三件套：`类型 数组名[长度]`；长度必须是**整型常量表达式**（`int a[n]`，n 是变量 → 错）；`int a[10], w;` 一条语句可数组+变量混定义。
3. 下标从 **0** 起：合法 0 ~ 长度-1；`int a[3]` → a[0]、a[1]、a[2]，**a[3] 越界**。
4. 越界系统**不报错**，结果不可预知（a[3]=6 破坏 a[2] 后面的字节；读 a[4] 是乱值）——保证不越界是程序员的责任。
5. 内存连续：总字节 = 长度 × 单元素字节（short a[3] → 2×3=6 字节）。
6. 引用 = 数组名[下标]，下标可整型常量/变量/表达式；定义时 `int a[10]` 的 10 是长度，引用时 `a[i]` 的 i 可变量——两种方括号含义不同。
7. 初始化规则（定义时才生效）：
   - 全部赋值 → 长度可省：`int a[]={1,2,3,4}`；
   - 部分 → 未给的自动补：数值型 **0**、字符型 **'\0'**（`int a[4]={1,2}` → {1,2,0,0}）；
   - 初值个数 > 长度 → **编译错**（`int a[4]={1,2,3,4,5}`）；
   - **完全未初始化 → 垃圾值**（`int a[5];` 里是内存残渣，不是 0）；
   - 数组名不可赋值：`x={…}`、`x=y` 全错（数组名=首地址**常量**，C5 展开指针再表）。
8. 二维数组 `类型 名[行长][列长]`；元素按**行优先**连续存放；m 行 n 列中 a[i][j] 的线性位置 = i*n+j（行、列号从 0）；可看作"元素是一维数组的数组"（x[0]、x[1]、x[2] 各是长 4 的一维数组名）。
9. 二维初始化：分行 `{{1,2},{3,4}}` / 不分行按行优先 `{1,2,3,4}` 结果相同；部分赋值未给的补 0（`{{1},{4,5}}` → 行0={1,0,0} 行1={4,5,0}）；**只能省行长不能省列长**：`int a[][4]={…12个}` → 3 行；初值 7 个/列长 3 → 行长 = 7÷3 整除 2 + 1 = 3，剩余格补 0。
10. **\0 红线（字符串是数组特例，独立反例条目）**：
    - 字符串常量末尾**自动加 '\0'**，占 1 字节、不算有效字符；`char str[8]="program"` ✓（7+1=8 恰好），`char str[7]="program"` ✗；
    - 反例①：`char c[3]={'a','b'}` → c[2]='\0'，**恰好构成字符串 "ab"**（补 '\0' 补出了尾巴）；
    - 反例②：`char d[5]={'a','b','\0','d','e'}` → 中途遇 '\0'，实际字符串只有 **"ab"**；
    - 反例③：`char str[10]="123\0ab\0ef"` → `printf("%s",str)` 输出 **123**（第一个 '\0' 后全忽略）；
    - 定义后不能整体赋值：`str="abc"` ✗，只能 strcpy。
11. 字符串 I/O 三组差异：
    - `scanf("%s",str)`：遇**空格或回车**结束、自动补 '\0'、**str 前不加 &**（数组名已是地址；`scanf("%s",&str)` ✗）；
    - `gets(str)`：**只认回车**，可含空格；
    - `puts(str)`：输出后把 '\0' 换成**换行**；`printf("%s")` 不换行、可一次多个。
12. string.h 函数（需 `#include <string.h>`）：strcmp 逐字符按 ASCII 比，相等返回 **0**，**禁止 str1==str2**；strcpy 连 '\0' 一起复制并覆盖；strcat 去掉原串尾巴 '\0' 接新串，末尾留一个 '\0'；strlen 测**有效长度不含 '\0'**。
13. **strlen vs sizeof 判据**：strlen=从第 0 格数到第一个 '\0' **前**（不含尾巴）；sizeof=数组定义总长（省长度定义时 = 有效字符数 +1）。`char a[]="happy"`：strlen=5，sizeof=6。

## A1 书中例题

**例5-4（一维数组逆序输出）**：`for(i=0;i<=9;i++) a[i]=i;` `for(i=9;i>=0;i--) printf("%d ",a[i]);` → `9 8 7 6 5 4 3 2 1 0`

**例5-7（冒泡排序，n 个数从小到大）**——核心双循环，边界条件是填空题常客：
```c
for (i=1; i<=n-1; i++)        /* 外层：共 n-1 轮 */
    for (j=n-1; j>=i; j--)    /* 内层：每轮从尾比到 i，共 n-i 次 */
        if (a[j] < a[j-1])
        { temp=a[j]; a[j]=a[j-1]; a[j-1]=temp; }  /* 相邻比较，前大后小则交换 */
```
输入 23 56 89 41 63 → 输出 23 41 56 63 89。

**例5-8（选择排序）**：外层 i:0~n-2；k 先记本轮起点，内层 j:i+1~n-1 遇 a[j]<a[k] 改记 k=j；**整轮比完才交换一次** `if(k!=i){temp=a[i];a[i]=a[k];a[k]=temp;}`。

**例5-11（矩阵转置）**：`x[3][4]` → `y[4][3]`，双重循环里一句 `y[j][i]=x[i][j];`，外层扫 x 的行（3 次）、内层扫列（4 次）。

**例5-18（字符数组过滤字母）**：双下标 i 扫原文、j 指新串尾，`if(是字母) str[j++]=str[i];` 循环结束**补 str[j]='\0'**——忘补尾巴是本题最常见丢分点。

**例5-20（strcmp 分支 + strcat）**：`res=strcmp(str1,str2);` res>0 → `strcat(str2,str1)`（大的接在小的后面），否则 `strcat(str1,str2)`。

## A2 触发题型

**★读程序写结果（二维数组陷阱）**
```c
int a[3][3]={1,2,3,4,5,6,7,8,9}, i, s=0;
for(i=0;i<3;i++) s+=a[i][2-i];
printf("%d",s);
```
a[0][2]+a[1][1]+a[2][0]=3+5+7 → **15**。陷阱：①初值表不分行，按行优先填格；②`2-i` 是副对角线，别惯性代主对角线。

**★填空（冒泡排序边界条件）**：外层循环控制变量 i 取 1~n-1（共 __n-1__ 轮）；内层 j 从 __n-1__ 变化到 __i__（每轮 n-i 次相邻比较）；若 `a[j]<a[j-1]` 则交换。数组元素下标从 __0__ 开始。

**★判断（越界与初始化）**
- "数组下标越界时系统会给出出错信息" —— ✗（系统**不检查**，结果不可预知）；
- `int a[3]; a[3]=6;` —— ✗ 越界（合法下标 0~2）；
- `int a[4]={1,2,3,4,5};` —— ✗ 编译错（初值个数>长度）；
- `int a[5];` 直接输出 a[0] —— 垃圾值，不是 0。

## E 考场步骤

**二维数组题·画格法**：①抄定义，数初值个数 → ②按行优先往格子里填，填到没初值，**剩余格全补 0** → ③省行长：行长 = 初值个数 ÷ 列长（除不尽再加 1）→ ④问 a[i][j] 就读第 i 行第 j 列（**第 0 行是第一行**，行列都从 0 数）→ ⑤遇 `a[i][2-i]` 类表达式，逐个 i 代入画对角线 → **判停：格子填完、每问都有格子可读，写答案，禁止心算跳步。**

**字符数组题·尾巴步**：①先写出数组逐格内容，**末尾画一个明确的 '\0' 格** → ②strlen：从第 0 格数到**第一个 '\0' 前**，不含尾巴 → ③sizeof/内存：数到定义长度（省长度定义 = 有效字符 +1）→ ④printf %s / puts：打印到第一个 '\0' 为止 → **判停：第一个 '\0' 的位置圈出来，strlen/sizeof/%s 三问共用这一格定位，答完即停，不重数。**

## B 边界与失分点

**失分点五连**：
1. 未初始化 ≠ 自动 0：**初始化时**部分赋值才补 0/'\0'；`int a[5];` 定义后不初始化是**垃圾值**。
2. a[n] 不是"a[0] 的另一种写法"：它是 a[n-1] 后面那格的越界元素——值不确定，写入还会破坏相邻数据。
3. 二维"第 1 行"陷阱：人话第 1 行 = 代码**第 0 行**（a[0]）；行列号全从 0 数。
4. 冒泡内层边界：j 从 n-1 **递减到 i**（不是 j<i）；写成 j>n-1 或 j>=0 都会让某一轮越界或漏比。
5. strlen 数的是"第一个 '\0' 前的字符数"，不是数组长度、不含尾巴。

**混淆表·vs C1（数据类型）**：字符常量 `'a'` 占 1 字节 vs 字符串 `"a"` 占 2 字节（多一个 '\0'）；`''`（两个单引号）非法，`""`（空串）合法但占 1 字节（只有 '\0'）；`char str[]="\0"` 合法——串长 0，数组占 2 字节。
**混淆表·vs C5（指针）**：数组名 = 首地址**常量**，不可赋值不可自增；指针变量 = 可被赋值的地址变量。`scanf("%s",str)` 对、`&str` 错；`str1==str2` 比的是地址不是内容，比内容必须 strcmp。展开边界表在 C5。
**混淆表·vs C8（文件）**：本单元读字符靠 getchar/gets/scanf %s 从**键盘缓冲**来；C8 的 `fread(buf,size,n,fp)` 从**文件**按字节块读，不自动补 '\0'、不以 '\n' 截断——"从文件读入的块不是字符串，除非自己补尾巴"。
